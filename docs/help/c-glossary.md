## 文种

| 术语 | 含义 |
|---|---|
| 公函 | 平行行文（商洽、征求意见、告知、答复），有文号、有份号位 |
| 电话通知 | 沿用函稿版式的简式通知，**无文号**、无版记 |
| 普通公文 | 无红头、无发文单位、无主送、无落款、无版记的纯正文公文 |
| 会议议程 | 会议时间地点、参会人员、议程安排 |
| 白头件（呈批件） | 内部情况报告、请示、领导呈批，无红头 |
| 红头呈批件 | 带红头、文号、首页批示栏的内部呈批件，承办条目上限 4 条 |
| 研究报告 | 按研究报告规范出 TeX/PDF，含封面元数据、交叉引用、文献、数学公式 |

## 版面部位

| 术语 | 含义 |
|---|---|
| 版头 | 红头、发文单位、文号、密级标注所在部位（纸面上部） |
| 主体 | 主送、标题、正文（纸面中部） |
| 版记 | 抄送、承办、落款、成文日期（纸面下部） |
| 红头 | 发文单位名称 + 反线，公文的视觉标识 |
| 反线 | 红头下那条横线，分隔版头与主体 |
| 版记 | 版记区的分隔短线 |
| 份号 | 公文印制份数的顺序编号 |
| 机关代字 | 文号前缀，如「办函」 |
| 函号 | 机关代字〔年〕序号号，如「办函〔2026〕12 号」 |

## 要素字段

| 术语 | 含义 |
|---|---|
| 主送单位 | 主要受文对象 |
| 抄送单位 | 抄送对象 |
| 承办单位 | 具体承办部门 |
| 呈报领导 | 白头件、呈批件的呈报对象 |
| 落款单位 | 署名单位 |
| 成文日期 | 文件署名日期，中文数字写法（二〇二六年三月十五日） |
| 密级 | 不标注/内部/秘密/机密/绝密 |
| 保密期限 | 密级标注的期限，受密级规则上限约束 |
| 指人专办 | 特殊处理标注 |
| 行文方式 | 内部/外部；单独发文/联合发文 |
| 紧缩样式 | 正常/全局紧缩/节内紧缩，压行距的范围 |

## 写作与校对

| 术语 | 含义 |
|---|---|
| 审校稿 | 起草页中央的 Markdown 正文 |
| 审校提示 | 校验命中条目，分必错/疑似/提示三级 |
| 必错 | 确定性错误，可一键替换，签发前必须清零 |
| 疑似 | 可能有问题，人判断 |
| 提示 | 风格建议，可整组关掉 |
| 待核实占位 | `【待核实】`，拿不准处先占位，落实后销掉 |
| 存疑清零 | SOP 阶段：所有待核实占位都落实 |
| 标准词库 | 单位与人员的唯一权威来源 |
| 校对词表 | 错误写法与建议写法的规则表 |
| 公文词表 | 从稿件收词、导出输入法码表的词库 |
| 省键数 | 词进用户码表比正常敲法省下的键数（`2n-4`） |

## 版本与痕迹

| 术语 | 含义 |
|---|---|
| 保存 | 写回稿件库当前内容（`Ctrl+S`） |
| 提交版本 | 固化成带名称与备注的快照 |
| 版本对照 | 任选两版比增删 |
| 花脸稿 | 送审用改稿痕迹版：删字画红色删除线、增字套蓝色方框 |
| 回退 | 把某版内容回到起草页，**不清历史** |
| 盖章扫描件 | 归档后唯一还能改的 PDF 附件 |
| 基于此公文新建 | 要素连同版式带过去，另起一篇 |

## 办文流程

| 术语 | 含义 |
|---|---|
| 六步办文 | 立稿→拟稿→核稿→送签→印发→归档 |
| SOP | 办理进度**状态表**（非向导），七阶段 |
| 拟稿 | SOP 一：有正文 |
| 要素齐备 | SOP 二：必填要素不缺 |
| 文字校对 | SOP 三：必错清零 |
| 表达复核 | SOP 四：小模型逐句查语病、称谓、标点 |
| 版式验证 | SOP 六：排版编译成功过一次 |
| 入库送审 | SOP 七：存入稿件库并固化版本 |
| 状态机 | 草稿→发布→归档，归档为唯一终态 |

## AI

| 术语 | 含义 |
|---|---|
| 修订建议 | AI 产物的唯一形态，需用户采纳 |
| 三条红线 | 不直接写正文 / 不碰要素 / 必过闸门 |
| 事实闸门 | 关键事实比对（单位/人员/日期/数字/文件依据） |
| 关键事实 | AI 不得改动的事实片段 |
| 事实变化清单 | 提案里关键事实的改动清单，逐项确认 |
| 事实单 | 材料成文等流程里**确定性拆分**出的事实条目，人确认后再起草 |
| 采纳即自检 | 接受后重跑校验，引入新问题自动回滚 |
| 仿照起草 | 载入基准稿仿写（结构仿写/同类改稿/局部更新/续期换届） |
| 知识起草 | 依据主题 + 知识库检索起草 |
| 材料成文 | 材料 → 事实单 → 确认 → 成文 |
| 大纲起草 | 先列大纲人确认，再逐节填 |
| 受控润色 | 只生成修改提案 |
| 提案审阅窗 | 左当前稿、右 AI 提案的对照窗 |
| 输出契约 | 程序内置约束的模型输出形态，用户不可改 |
| 温度锁 0 | 小模型复核用 0 温度，同输入同输出 |

## 检索与知识

| 术语 | 含义 |
|---|---|
| 知识库 | 历史成稿与参考资料的可检索库 |
| RAG | 检索增强生成：向量检索 + 重排 + 全文兜底 |
| Embedding | 文本向量化模型 |
| Rerank | 精调排序：None / 专用端点 / 用对话大模型 |
| FTS5 | SQLite 全文索引，服务不可达时的降级路径 |
| 知识库问答 | 对话式检索，回答带引用标注 |

## 导出

| 术语 | 含义 |
|---|---|
| 主干名 | 导出文件名的主干，按文种起（含函号、名称、时间戳） |
| 源码包 | `.tex` + 字体配置 + 图片附件的 ZIP，可复现编译 |
| 孤行探针 | 编译后实测坐标找孤行，生成可点击提示 |
| 成品三入口 | TEX / PDF / WORD 图标，找最近一次产出并点亮 |
| 覆盖策略 | 覆盖同名 vs 生成 `-2`、`-3` 副本 |

## 输入法

| 术语 | 含义 |
|---|---|
| 小鹤双拼 | 双拼方案之一，本应用的码表导出目标 |
| 用户码表 | 小鹤的自定义词组码表，四码定长 |
| 辅码（形码） | 辅助重排的形码表，**不随包**，自己导入 |
| 重码 | 同一编码的多个候选词 |
| 整句模型 | `lm.qj`，可选，影响长句能力 |
