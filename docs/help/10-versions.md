## 保存、自动保存、提交版本

三件事别混：

| 动作 | 结果 | 什么时候用 |
|---|---|---|
| **保存**（`Ctrl+S`） | 写回稿件库当前内容 | 随手存，关机前必存 |
| **自动保存** | 每 2 分钟存一次 | 兜底，防丢 |
| **提交版本** | 固化成**带名称与备注的快照** | 送签前、大改前、定稿时 |

保存是「现在这样」，提交版本是「这一刻留档」。版本可以回退、可以对照、可以导出花脸稿；保存只是把改动落到库。

提交版本有两个范围：**稿件版**（正文与要素）与**配置版**（词库、提示词等设置）。在版本提交窗里选范围、填名称与备注。默认名称自动起（如「第 N 版」），可改。

## 版本历史抽屉

右下状态栏点「历史」开版本历史抽屉：

- 列出所有已提交版本，按版本号倒序；
- 每条显示版本号、名称、备注、时间；
- 悬停显示改动摘要（字数增减、命中项变化）；
- 可在此**载入**某一版、**回退基准版**、发起**版本对照**。

标签栏上也有小标记：与最新已提交版本比，有未提交改动时空心圈变实心。

## 版本对照

「版本对照」是起草页的**第五个视图图标**：左栏改字、右栏看花脸稿，不用弹窗。对照范围是任意两版——基准默认跟**最新已提交版本**走，提交一版之后自动换过去，也可在工具栏的「基准」下拉里选更早的版本，看从那一版至今累计改了什么。

![版本对照：左栏是可编辑的统一 diff，右栏是花脸稿预览](images/ui-versions.png)

**左栏是编辑器，也是 diff**：

- 删除 / 被改写的**旧行以红底只读行显示在原位**（在行间开缝放进去），新增 / 改写后的行铺**绿底**，真正改掉的字再加深一档；
- 行号槽写新 / 旧行号与增删色条；只改了空行也算一处变更，显示淡色「（空行）」；
- 光标停在哪个变更块，哪块就是焦点；悬停或聚焦的变更块右上角出「**还原**」按钮，点一下把这一块换回基准版内容（`Ctrl+Z` 一次撤回）。

**右栏是花脸稿预览**，与导出 PDF / Word 吃的是同一份数据，「预览 = 导出」由构造保证。花脸稿要跑分词，停手 0.15 秒后才在后台重算，右栏允许比输入晚一拍。

两栏联动：

- 点左栏某处变更 → 右栏滚到对应块并常亮；双击 → 切回 Markdown 源码定位；
- 点右栏带标注的块 → 左栏聚焦并滚过去；
- 悬停任一侧，另一侧淡色高亮；
- `F7` 下一处、`Shift+F7` 上一处，首尾循环。

工具栏其余项：`共 N 处变更`、`第 X / N 块`、**回退到基准版**（二次确认，用基准版覆盖当前稿件）、**导出花脸稿**、**打印预览**（后台真编译一遍 PDF，在内置查看器里打开，不在导出目录留文件）。左栏顶部另有一张**要素变化**卡片，按字段列出单位、文号、日期等改动。

**已发布 / 归档的稿件只读**：左栏换成只读的统一视图，多了「折叠未改动」，导航按逐行变更算（工具栏会写「处」而不是「块」）。

## 花脸稿

**花脸稿**是送审用的改稿痕迹版：

| 改动 | 呈现 |
|---|---|
| 删掉的字 | 留在原位画**红色直删除线**，字本身也是红色（`#C00000`） |
| 新增的字 | 就地套**蓝色方框**（`#1F4E9E`、0.5pt），框内文字保持正文色 |

新增框**随正文断行**：跨行时在行尾开口、下一行接着画，左右竖边只在整段新增的首尾各一笔。一张纸就能给领导签批，不用旁注「此处删了 X 字」。

导出入口在版本对照工具栏的「导出花脸稿」菜单：「导出 PDF」「导出 Word」「两者都导」。花脸稿与定稿导出**分开记账**，不会覆盖定稿成品。

| 产物 | 文件名 | 用途 |
|---|---|---|
| 花脸稿 PDF | `...-花脸稿.pdf` | 送审签批 |
| 花脸稿 Word | `...-花脸稿.docx` | 需要 Word 改稿时 |
| 定稿 PDF | `....pdf` | 印发 |
| 定稿 Word | `....docx` | 印发 |

## 回退到版本

版本历史里选某版 → 「回退」，二次确认后：

1. 该版内容回到起草页（成为当前未提交内容）；
2. **不清历史**——版本列表原样保留，随时可以再回退到别的版；
3. 当前若有未提交改动，会先提示（怕覆盖你的活儿）。

回退本身也是一次改动，回退后记得再提交版本留痕。

## 三选确认：载入版本

在版本历史里点「载入」某个版本时，如果当前有未提交改动，弹三选：

1. **丢弃当前改动，载入该版**；
2. **先提交当前版本，再载入**（推荐）；
3. **取消**。

「提交后再切换」是安全路径：当前活儿留了痕，切到旧版不心疼。

## 盖章扫描件

稿件详情里可挂**盖章扫描 PDF**（`PdfAttachment`）：

- 稿件**归档后唯一还能改的**就是这个附件的增删；
- 批量导出 PDF 时，盖章件自动以「（盖章）」命名区分；
- 预览可在应用内直接打开看（PDF 查看器标签）。

印发环节把盖章件挂回来，归档就完整了。见 [稿件管理](chapter:19-manuscripts)。

## 退出前的汇总确认

关程序时若有未保存改动或未提交版本，弹汇总确认，逐篇列出：

- 哪些篇有未保存改动；
- 哪些篇有未提交版本。

可以选「全部保存并退出」「直接退出」「取消」。不确认就退出是不行的——防手滑。

## 启动时恢复现场

下次启动**恢复上次全部标签现场**：开着哪几篇稿件、哪些导航页、PDF 查看器，停在哪个标签，都回来。滚动位置按标签各自记忆（设置页各分区也各自记忆滚动位置）。

PDF 标签是例外：只在本次运行中保留，不写入会话恢复表——它是临时看件，不该变成常驻标签。
