## 十二个分区

「设置」页左栏十二项，分三组：

| 组 | 分区 |
|---|---|
| 模型 | 本地模型服务、AI 文字复核、知识库 |
| 输出 | 输出与录入、导出格式 |
| 外观 | 界面主题、字体、标题与列表编号 |
| 保存 | 保存与现场 |
| 规则 | 密级规则 |
| 输入 | 输入法 |
| 帮助 | 上手指引 |

主题、纸面与字体改完**立即生效**；其余各项要**保存**后才写入配置文件。

## 本地模型服务

![本地模型服务设置](images/ui-settings.png)

| 配置 | 说明 |
|---|---|
| 对话接口地址 | 起草与润色用，LM Studio `http://127.0.0.1:1234/v1`、Ollama `http://127.0.0.1:11434/v1` |
| 对话模型 | 点「测试连接 / 刷新模型」后从下拉选，**中文指令模型** |
| 生成参数 | 温度、top_p、最大长度 |
| Embedding | 知识库向量化用，**独立配置** |
| Rerank | 重排用，**独立配置** |

三项接口地址**相互独立**，不用的可以留空。Ollama 的接法见 [知识库与问答](chapter:18-knowledge)。

## AI 文字复核

| 配置 | 说明 |
|---|---|
| 接口地址 | 可指到不同端点 |
| 模型 | 小模型即可 |
| 温度 | **锁 0**，不可改 |

不配置就都走起草模型。查语病、称谓、标点不需要大模型，小模型快且稳定。见 [AI 优化、提示词与文字复核](chapter:14-ai-polish)。

## 知识库

RAG 三项配置（Embedding、Rerank、启用开关）。换 embedding 模型会提示重建索引。见 [知识库与问答](chapter:18-knowledge)。

## 界面主题

十二套主题即点即换（明色七、深色五），菜单底部也有入口。另有**纸面明暗**三档：

| 档 | 效果 |
|---|---|
| 跟随主题 | 纸面明暗跟界面主题走 |
| 白纸黑字 | 强制白纸 |
| 深色纸面 | 屏幕上省眼 |

> **注意** 纸面明暗**只影响屏幕预览**，导出一律白纸黑字红头。

## 字体

字体分四层：

### 编译字体（公文五处）

| 位置 | 默认 | 用途 |
|---|---|---|
| 标题 | 方正小标宋 | 文件标题 |
| 一级标题 | 黑体 | `#` |
| 二级标题 | 楷体 | `##`，兼正文斜体 |
| 正文 | 仿宋 | 正文 |
| 页码 | 宋体 | 页码 |
| 粗体 | 专用粗体 | `**粗体**` |
| 兜底 | 宋体 | 缺字时替补 |

勾「**使用本机字体编译**」后给五处分别选本机字体，留「内置」就继续用内置。屏幕预览同步切换，所见即所得。

> **注意** 内置 Tectonic 编译时**按文件加载**所选字体，导出的 `.tex` 拿到别的机器上**按字体名加载**——目标机器上装了同名字体才能得到一致效果。字体文件后来被删/卸载会自动退回内置，并在导出结果里提示。

**字体集合（`.ttc`）不可选**：`.ttc` 一个文件装多字面，按文件加载须指定字面序号，未在内置 Tectonic 上验证。请找单字面的 `.ttf`。列表只收 `.ttf` 与 `.otf`。

二级标题字体**同时充当正文斜体**，改它一并影响正文里的斜体。

### 兜底字体

仿宋、楷体是 GB2312（6763 汉字），人名里的「喆」「赟」「堃」没字形。程序对所有字体位置挂兜底字体：排不出的字自动换用它，**预览、Word、PDF 三端一致**，不必配置。

内置兜底是宋体，覆盖 GBK 21791 汉字，日常够用。要排 GBK 以外的字（如「𠮟」），在「兜底字体」另选字库更大的本机字体——这一项**不受**「使用本机字体编译」开关约束（它决定的是排不排得出来，不是版式）。所选字体也漏的字，仍由内置宋体接着兜。

### 界面字体

界面字体不随包：Windows 微软雅黑、Linux Noto Sans SC、macOS 苹方，可另选本机字体。与公文字体互不干扰。

### 源码编辑器 Markdown 字面

三套模板（编辑器字体 / 标题随公文 / 与公文一致）或六处自定义。只改屏幕字面，不影响导出。见 [拟稿：源码编辑与五种视图](chapter:06-editor)。

## 标题与列表编号

| 配置 | 说明 |
|---|---|
| 节内编号 | 每节从 1 重起 |
| 全局编号 | 整篇连编 |
| 列表编号 | `1.` 的编号风格 |
| 序号表格分组 | 分组行里 `（一）`、`一、` 这类编号的风格 |
| 空行规范 | 标题前后空行规则 |

公文规范与研究报告规范要求不同，按文种挑。

## 导出格式

| 配置 | 说明 |
|---|---|
| 默认勾选 | 新建稿子时 md/docx/tex 哪些默认勾上 |
| 覆盖策略 | 覆盖同名 vs 生成副本（默认副本） |

PDF 不是独立选项——有 `.tex` 就编。

## 保存与现场

| 配置 | 说明 |
|---|---|
| 自动保存间隔 | 默认 2 分钟 |
| 恢复标签现场 | 启动时恢复上次开着的标签 |
| 退出确认 | 未保存/未提交时弹汇总确认 |

## 密级规则

| 密级 | 保密期限上限 | 允许「长期」 |
|---|---|---|
| 秘密 | 10 年 | 否 |
| 机密 | 20 年 | 否 |
| 绝密 | 30 年 | 是 |

规则可按单位要求收紧，不能放宽到超标准。要素校验按这套规则卡。

## 输入法

| 配置 | 说明 |
|---|---|
| 启用应用内输入法 | 关掉就用系统输入法 |
| 双拼方案 | 小鹤 / 自然码 / 微软 / 搜狗，留空为全拼 |
| 辅码表 | **自己导入**，不随包 |
| 全角标点 | 开关 |
| 候选页大小 | 默认 5 |
| 翻页键 | `[]` / `,. ` / `-=` |

学习数据在 `config_dir()/ime/`。见 [公文词表与输入法](chapter:17-lexicon)。
