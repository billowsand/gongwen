## 校对词表是什么

「校对词表」页管**哪些写法是错的、该写成什么**。它驱动审校抽屉的命中，是确定性规则的地基——不看模型脸色。

两层结构：

| 层 | 来源 | 可改 |
|---|---|---|
| 内置 | 程序自带 `proofread-lexicon.tsv`（155 条） | 只读，程序更新 |
| 用户 | 你在页面上加的条目 | 可增删改 |

两层**合并生效**。导出 Excel 时两层一起出。

## 六组分类

| 组 | 查什么 | 命中级 |
|---|---|---|
| 错别字 | 形近、音近错字 | 多为必错 |
| 近义混淆 | 用错的近义词 | 多为疑似 |
| 语病 | 搭配不当、成分残缺 | 疑似 |
| 套话虚词 | 冗余套话、虚词堆砌 | 提示 |
| 称谓规范 | 单位与人名称谓 | 多为必错 |
| 公文用语 | 公文专门用语写法 | 多为必错 |

外加 **15 条文档级规则**（`proofread_rules`），查跨句的行文问题：

- 文号格式（机关代字〔年〕序号号）；
- 日期写法（中文数字日期 vs 阿拉伯数字）；
- 成文日期与落款位置；
- 附件说明的位置；
- 称谓前后一致（前文全称后文简称是否合法）。

## 三级判定

| 级 | 含义 | 处置 | 颜色 |
|---|---|---|---|
| **必错**（MustFix） | 确定性错误 | 可一键替换，签发前必须清零 | 红 |
| **疑似**（Suspect） | 可能有问题 | 人判断 | 黄 |
| **提示**（Hint） | 风格建议 | 可整组关掉 | 弱 |

为什么分三级：必错是「规则说错就是错」（错别字、公文用语写法），疑似是「看上下文」（近义词在某些场合对），提示是「风格口味」（套话精简）。一刀切成全拦会烦死人，全放会漏错。

## 命中条件

每条规则可以限定**什么时候命中**：

| 条件 | 含义 | 例 |
|---|---|---|
| Always | 任何时候 | 「按装」→「安装」 |
| FollowedBy | 后面跟某字才命中 | 「截止」+ 后跟日期 → 疑似 |
| NotFollowedBy | 后面**不**跟某字才命中 | |
| PrecededBy | 前面有某字才命中 | |
| NotPrecededBy | 前面**不**有某字才命中 | |
| Pattern | 正则匹配 | 文号格式类 |

条件让规则精准：「截止」本身不是错，但「截止 3 月 20 日」就该是「截至」。有了 `FollowedBy` 就能只拦这种场合。

## 用户层怎么加

页面上「新增条目」填：

| 字段 | 说明 |
|---|---|
| 组 | 六组之一 |
| 级别 | 必错 / 疑似 / 提示 |
| 错误写法 | 被拦的写法 |
| 建议写法 | 替换成什么 |
| 条件 | 上面六种之一 |
| 适用范围/说明 | 备注（可填使用说明） |

> **提示** 优先用**条件**把规则收窄，再考虑加新条目。一条带条件的规则胜过三条互相打架的宽规则。

## 建议写法的去向

「建议写法」不只是替换目标：

1. 审抽屉「一键替换」按它替换；
2. **公文词表扫描时自动并入**并置为已接受（写法是对的，不用再确认）；
3. 「错误写法」进公文词表黑名单，**既不入库也不导出**——不会把写错过的字固化进输入法。

这个设计是刻意的：写错过的字不能进输入法词库，否则下次打字还是错。

## 忽略与记忆

审抽屉里命中条目可以：

| 操作 | 效果 |
|---|---|
| 忽略 | 本条这次不管，下次校验还会上来 |
| 忽略并记忆 | **永久忽略**，重扫不再冒头 |

「忽略并记忆」是永久的。误操作可以在本页清空忽略记录（按条目或全清）。

> **注意** 「忽略并记忆」要慎点。它是为「我这就是故意的」准备的（比如引用原文里的古体写法），不是为了消掉烦人的提示。真该改就改，别忽略。

## 导出 Excel

「导出 Excel」导出**两层合并**后的完整词表，固定名「公文助手校对词表.xlsx」：

- 备份用；
- 给同事分发单位标准写法；
- 人工批量审一遍规则。

导入暂不支持——词表条目带条件与正则，Excel 里表达不全，容易导坏。要批量加条目走 [标准词库](chapter:15-vocabulary) 的 Excel（那边是数据不是规则）。

## 与 AI 的关系

校对词表是**红线三闸门**的一部分：任何 AI 产物落地前都要过词表与规则复扫。AI 建议里若引入错别字、不规范称谓，闸门拦下丢弃——不因为它来自模型就放行。

也因为如此，**词表是 AI 的裁判**：模型写得再顺，词表说错就是错。
