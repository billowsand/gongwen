## 已确认的 how 问题

1. clippy 失败：旧 UI 失去入口后，旧管理 helper 仍进生产编译。仅供旧格式回归的管理 API 移到 test 配置；真正无调用的工具说明/界面流程图 helper 移除。保留旧引擎的 disabled_ids 生产读取与旧格式回归，不恢复旧 UI 入口、不屏蔽警告。
2. 用户技能 SKILL.md 损坏时，管理页 ensure_package 因 entry.error 提前退出，无法打开原文修复。应允许安全读取包，再由保存校验阻止写坏。
3. 内置技能 TextEdit 未禁用，用户可以改出永远无法保存的缓冲；改为真正只读。
4. 管理页每帧 clone 完整包（包括二进制资源）多次；文件树/概览只取路径与大小，不复制文件字节。

5. 单条链接导致整个 user_dirs 失败；改为逐条目录保留，catalog 在读目录/入口文件之前检查链接并只标坏该项。补 junction/symlink 隔离回归。
6. ZIP 封装目录误算入技能内 8 段深度；归档封装允许有限外层，提取后再按技能相对路径严格校验，补最深路径往返测试。
7. host 静默截断到 64 份技能；取消截断，Rust 在构建快照时限制总包体积 128 MiB / 索引 512 KiB，超限明确报错。新索引损坏不再悄悄扫描兜底，仅缺少索引的旧工作区扫描自己的目录。补 65 份与损坏索引测试。
8. 通用包读目录先 metadata 再无界 read 的实际读取上限不足；换用 file_limits::read_bytes。共享包往返测试原断言漏算导出前缀，修正为逐字节比较带前缀的完整映射。
9. 原实现仅能复制内置同名副本，缺少自定义技能复制；补整包复制到新名字的 API 与界面，保留辅助文件和未知元数据，目标冲突拒绝，不改原包。补对应回归。
