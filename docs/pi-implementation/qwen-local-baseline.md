## 对统一写作设计的影响

1. 目标本地模型已有可测试端点，三类短任务的 Pi 工具执行与显式交付均走通，无须按9B参数量认定不支持智能体。
2. 窗口恰为256K，仍出现格式及字数问题，不能只以256K阈值选策略。容量与约束执行能力必须分开记录。
3. 分阶段策略应让模型处理更明确的短任务，并在阶段结束给出真实程序校验反馈；本轮尚未实现新策略，不能声称已证明它优于常规策略。
4. 5A应验证应用是否能取得 LM Studio 的实际加载窗口。标准 `/v1/models` 此次只有模型ID；需要处理容量未知的回退，不能直接假设应用已识别为262144。
5. SDK空密钥兼容问题是独立接入事项：本次靠测试占位值绕过，生产免密路径尚未修正。

尚未验证：接近窗口上限的有效事实保持、20万汉字材料、长文分节合稿、自动压缩、阶段恢复、真实知识库、本机GUI正文写入/撤销及离线安装包。窗口值是服务报告，不能当作上述能力实测通过。
