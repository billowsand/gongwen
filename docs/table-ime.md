# 词表输入法改造与交接

2026-10-02，分支 `codex/table-ime`。取代旧「拼音引擎＋音形候选」混合流程。

## 定位与数据

输入法只接受编码、查询词表、选词上屏，不区分全拼、双拼或任何输入方案。
以本项目自维护的 `assets/fuma/quan.txt` 为初始基础表，完整保留单字、词组与简码。
动态叠加稿件库中已接受的公文四码词、导入的四码表与个人词条。
词条可以自己指定编码；公文词表原有编码建议与读音维护仍保留在维护侧。

基础表与个人词条使用 1–4 个小写字母，公文表与导入的公文四码表使用四码。只做完整编码匹配，
一至三码不展开四码前缀。相同「编码＋文字」合并，保存所有来源；同词不同码保留。
默认基础表在前、公文表和新增词在后，使用者可显式排序，不自动调频。

## 已实现

- 进程内直接查表与上屏，保留 egui 焦点、光标、候选定位、横竖排、字号与翻页。
- 四码唯一候选自动上屏默认关，开启后单字与词组相同。
- 第五码顶屏默认开：有候选则先上屏高亮，再开始下一编码；无码保留原编码。
- 空格无码时不上屏字母；回车可明确原样上屏编码；Shift 切英文时也原样上屏。
- 基础表整体导入更新、上次基础表恢复；日常修改见下文第二轮（进个人层，基础表只读）。
- 公文四码表导入预览，统计新增、已有、重码、文件内重复与无效行。
- 导入表分来源启停与整批撤销；其他来源的同码同词不会随撤销消失。
- 查词查码、重码筛选、候选首选与上下移动、屏蔽与恢复、个人词条增删改。
- 正文右键「加入词表」，不改正文；新词立即可用（第二轮起自动出码）。
- 最终词表文本导出，个人词表 JSON 备份恢复，恢复前保留上次个人文件。
- 公文词表变化后延时同步，仅接受状态且最终编码为四码的词进入输入候选。
- 基础表和个人文件通过同目录临时文件替换，保存成功后才替换内存。
- 兼容旧用户音形表路径与配置中的有效短语，旧文件不主动删除。

## 第二轮：出码、提示与码表管理（2026-10-02）

五个部分，各自一次提交：

1. **自动出码**（`encoder.rs`）：从基础表反推字码（单字两码以上编码的前缀）与构词规则
   （Rime 写法，候选规则逐条在全码词组上验证，取命中最多的）。多音字按「字码在已有词组里
   被用的次数」排序。本机 `quan.txt` 推得二字 `AaAbBaBb`、三字 `AaBaCaCb`、四字及以上
   `AaBaCaZa`；留一法首选命中约 97.6%，前三命中约 99.9%。只用全码长度（表中最长码长）的
   词组推算，三简词组（三字三码）不参与，否则三字规则会被推成 `AaBaCa`。
   加词窗（`add_word.rs`）、造词（`Ctrl+Shift+A`，取选区或最近上屏的连续汉字，最多八个）、
   查码（`lookup.rs`，正文右键「查编码」）。`Ctrl+=` 已被字号放大占用，所以造词用 `Ctrl+Shift+A`。
2. **候选窗**：词后星标（沿用早先整句模型候选的四角星，表示不只在基础表里）、空码标记、
   简码提示（默认开）、词组提示（默认开，走状态栏）、逐码提示（默认关；空格只上屏精确候选，
   挪过高亮才上屏补出来的）、悬停来源、候选右键菜单（置顶 / 上移 / 下移 / 屏蔽 / 查编码）、
   `Ctrl+Delete` 屏蔽高亮候选（不组码时交给编辑器删词）。
3. **分层模型**（`ops.rs`、`history.rs`）：基础表只读，只能整体导入升级；改基础词 = 屏蔽原词
   ＋个人词条，个人词条直接替换。每次写 `tables.json` 前存一份到 `history/`（保留 20 次，
   可逐条回退，回退本身也记一笔；第一次写入前没有旧文件，不记）。升级基础表时预览差异
   （新增、删除、换位）与升级后个人层里的多余、失效记录；体检可一键清理。
4. **「输入法词表」页**（`page.rs`，`NavPage::ImeTable`）：查询与维护（编码框不走输入法、
   前缀与 `?` 通配；文字框走输入法；来源 / 码长 / 字数 / 重码 / 不符规则筛选；虚拟滚动、
   右侧详情）、查码、导入与来源（含构词规则改写）、体检、修改记录。设置页只留开关与入口。
5. **公文词表统一编码**：`LexiconTerm::code_with` 优先用输入法出码器的候选；人工标音只在候选里
   挑一个，标音算出的码不在候选里（基础表不是小鹤方案）就用首选。出不了码时退回拼音出码。

真机待验：加词窗与造词的实际手感、候选右键菜单弹出时焦点是否保住（代码里菜单打开期间每帧
把焦点还给编辑框）、词表页在小窗口下表格与详情的宽度分配。

## 注意

### 2026-10-24：公文词表默认不重复列出输入法已有词

公文词表的审阅列表与概况默认排除已在其他输入法来源中有效收录的同名词，按完整文字判断，
不要求同码；可勾「显示输入法已收录词」临时查看。只隐藏视图，不改接受/拒绝状态，也不改变导出。
匹配范围为基础表、个人词条、已启用导入表，并排除屏蔽项；不能用来源显示名判断（导入表可与
「公文词表」同名），也不能把公文词表自己同步到输入法的记录算作已收录。

`Table::rebuild` 建独立来源词集合并更新 revision，公文词表仅在词表或筛选变化时重查；
移除、恢复、导入启停和撤销都走同一失效机制。先排除再按列表上限截断，防止前 500 个都是
已有词时把新词挡在后面。「接受列出的全部」仅作用于当前可见列表。
实现位于 `ime/table.rs`、`ime/session.rs`、`lexicon.rs`、`app/lexicon_jobs.rs`、`lexicon_ui.rs`。
验证：新增回归覆盖独立来源、屏蔽/启停、来源重名、自己同步、截断前过滤、统计和批量接受；
`cargo test --locked review -- --test-threads=1` 为 193 通过、2 忽略，
`cargo test --locked lexicon -- --test-threads=1` 为 44 通过；fmt 与 clippy 全目标检查通过。

### 2026-10-24：词表维护界面改为快速操作

本轮按实际维护习惯重做，取代上文第二轮的五标签、常驻右侧详情与独立体检摘要：

- 内容外留 20–28 像素，主工作区改为整页虚拟表格；常驻标签只留「词条」「检查」。
  查码、导入与来源、修改记录与同步公文词表收进「更多」。候选排序在行尾「…」按需打开。
- 一个搜索框识别文字或编码：纯字母与 `?` 按编码前缀/通配，其余按文字包含；
  来源常驻，码长/字数/重码等折叠进「更多筛选」。默认列表不显示已屏蔽词。
- 双击文字或编码就地编辑，Enter 保存、Esc 取消；个人词直接删除，其他来源移除时屏蔽候选。
  复选多条可一起移除，Delete 不在文本编辑时触发词条移除。
- 加词窗口默认只显示文字、编码与添加/连续添加；自动出码，候选、逐字码与首选选项按需展开。
- 检查项采用可滚动表格，支持直接改码、选中多项一次处理、逐项清理及本次运行忽略/重新显示；
  不再暂存、审核、确认再应用。多码/重码只提示，不认定为错误。
- 导入和导出有各自菜单；公文表导入显示短预览并允许导入有效条目、跳过无效行。
  基础表替换与个人备份恢复保留一次覆盖说明和确认，文件保存失败不丢弃预览。
- `src/ime/undo.rs` 保留本次运行最近 20 次成功保存前的个人层快照，按总量 32 MiB 裁剪旧记录
  （至少保留最近一次，单份仍受个人文件 64 MiB 上限约束）。一次批量操作只保存一次、撤销一次；
  首次加词也能撤销；撤销失败保留快照。撤销本身只写磁盘历史，不重新压入运行时栈。
  基础表更新清空运行时撤销栈，旧基础表继续走独立恢复入口；退出后仍可用最近 20 次磁盘记录。
- 修正界面帧尾清掉本帧 dirty 标记的问题，保证保存/撤销后结果与检查能重新计算。
  `Ctrl+N` 在词表页加词，其他页面仍新建稿件；`Ctrl+F` 不再被稿件快捷键提前吃掉。

新增界面模块：`src/ime/page/quick.rs`（快速表格）、`src/ime/page/checks.rs`（检查与直接修订）。
设计取舍与效果图保存在本机生成物 `output/ime-table-redesign/`，不纳入版本控制。
真机重点验收：不同缩放与窄窗口的编辑行/菜单不截断，实际输入法组码时 Enter/Esc 与行内编辑焦点，
导入文件选择及 Windows 文件替换失败后的提示/重试。

本轮验证：`cargo fmt --all -- --check`、`cargo clippy --locked --all-targets -- -D warnings`、
`cargo build --locked` 通过；正常文件权限下 `cargo test --locked --all-targets -- --test-threads=1`
为 2333 通过、0 失败、70 忽略（沙箱中原子替换文件会报拒绝访问，不为此改测试）。
