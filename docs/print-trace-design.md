# 印制追溯码（2026-11-06 首版）

## 已确认口径

- 目标是识别生成副本时登记的印制单位，不是防复印、阻止流转或认定泄露责任。
- 不从主送、抄送、发文或接收单位取值；设置页独立填写「印制单位」。
- 外观采用横向长方形黑白点阵码，小巧，位于每页右下角的底部页边距。
- 标识作为前景叠加层，不占版心、不改变正文换行、分页、版记和既有页码。
- 下方两行小字为印制单位、可人工抄录的印制编号。

## 本次实现

设置在「设置 → 导出格式 → 印制追溯码」，默认关闭。开启后必须填写不超过 60 字的单行单位名称。
本轮产出的每个 PDF 生成独立随机 16 位十进制编号，数据库唯一键防重复；四位一组显示。
码内只有连续 16 位编号，无正文、单位名或网址。采用标准 Data Matrix ECC 200 的 8×32 码制，
四周各留一模块静区，矢量输出，不拉伸模块。不是 ImageGen 示意图，也不依赖联网服务。

小幅透明标识通过 `assets/typst/print-trace.typ` 在内存编译为 24×11mm PDF。
码含静区宽 22.1mm、高 6.5mm；两行文字 4.2pt，单位过长时只横向压缩，不换行增高。
标识整体右边距 10mm、底边距 7mm；以阅读器显示方向定位，兼容 Typst 横页的 `/Rotate 90`。
`src/export/print_trace.rs` 将其作为 Form XObject 叠加在原 PDF 内容之后，保留原正文内容流。

登记在现有稿件库的 `print_trace_exports` 表，沿用现有 SQLCipher、双槽隔离和全量备份。
记录编号、单位、生成时间、题名、原稿（要素 + Markdown）SHA-256 与最终 PDF SHA-256。
记录独立于稿件删除，不进入稿件同步包；不是不可篡改的审计证据。设置页可按编号查询或看最近 20 条。
编号/记录不是逐份纸件流水：同一 PDF 打印多份仍是同一码。
生成标识或写登记失败时，报错并移除本轮 PDF，不将无标识文件冒充带码成品。

首版覆盖：起草页普通导出、PDF 快捷导出、另存为、起草页「打印」生成的 PDF、
以及同轮生成的签收记录单/传发任务单。Markdown、Word 与 Typst 包不受影响。
目前不覆盖稿件库批量 PDF、送批材料合并、花脸稿和已存在 PDF 的直接打印；
不改已有 PDF 附件，避免破坏签名或扫描件原貌。

## 验证与样张

- `cargo test --locked print_trace`：码制编码/解码、旧设置默认关闭、单位校验、
  叠加前后页数/页面尺寸/原正文内容流一致、重复叠加拒绝、登记持久化与编号唯一性。
- `cargo test --locked typst_samples_print_trace -- --ignored --nocapture`：
  使用真实公文导出链生成 `output/pdf/print-trace/印制追溯码-真实样张.pdf` 与无标识对照。
- 实际打印机可打印区、复印后识别、手机扫码软件兼容性仍需真机测试；不承诺系统相机均可识别。
