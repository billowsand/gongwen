## 公文助手 v0.6.3

本版本上线「应用内帮助中心」，并补齐正文序号表格、纸面配色家族与若干边界修复，让「看得见的成品」与「用得顺的写作」两端都更稳。

### 应用内帮助中心

- **F1 打开、标签栏常驻**。把 21 章 + 3 附录完整图文手册搬进标签栏的新「使用帮助」页，菜单与 `F1` 都能开；点目录换章、回到章首、跨章链接、快捷翻页与配图放大层都跑在标签里。设置页「上手指引」末尾的「打开完整图文手册」按钮直达第三章，省一次菜单。
- **离线可用**。章节正文、配图与界面截图都用 `include_*` 打进二进制，不联网也能读；图源 `docs/help/diagrams/*.drawio` 单独随仓库托管，方便以后再改图。

### 正文序号表格

- **表前一行标记即自动编号 + 整行合并靠左**。在表格上方加一行 `<!-- [序号表] -->`：首列按组自动编号（数据行首格留空即可，增删行后不用手维护），首格写标题、其余留空的行整行合并、靠左、并按设置里的「序号表格分组」补 `（一）`/`一、` 之类编号；表头首格留空自动补「序号」。手写的 `（一）`、数字、`1.`/`1）` 都清掉重排，`||||` 等价整行跨度仍生效，与 `^^` 纵向合并互不打架。
- **三端同源**。归一化在解析层做一次，Word / PDF / 预览共用一个渲染器。编号与合并只在版式里出现，源码不写回。研究报告（mdx）路径不识别整行合并，该路径下序号表不生效。
- **配套 UI**：设置页「表格编号」组新增「序号表格分组」；功能区「表格」下拉新增「插入序号表格」「设为 / 取消序号表格」。

### 预览与纸面配色家族

- **「跟随主题」更克制**。把每个界面主题绑一组「纸面家族」：明色按冷暖取本色 / 宣纸白 / 雨青灰，深色按冷暖取夜墨蓝 / 檀黑棕，让屏幕上的公文纸面与界面主题协调，但不复制主题的强调色，避免公文看起来像普通换肤界面。「白纸黑字」「深色纸面」两档显式档不变，导出仍是白纸黑字红头。
- 实时编辑与预览都吃这套规则；切换主题与纸面均立即生效。

### 密级与密级件期限

- **「内部」件不再标注保密期限**。期限下拉与默认期限改为空；带期限（含旧稿的「长期」）会提示清空；版心、DOCX、LaTeX（`\SecurityLine`）在期限为空时不再画「★」；模型回显剔除时按同一规则识别「内部」。

### 输入法（字在上游同步）

- **辅码筛空时整串上屏**。回车 / 没有候选时按空格，把敲过的字母连同辅码键原样上屏：`rust` 之类被读成「`ru` + 辅码 `st`」的英文词不会再只剩 `ru`；整串是英文词表里的词时，会在候选里出现（排在辅码筛出的字后面）。
- **整句候选右上角带小星标**（✦），与词库现成词在视觉上区分。

### 表格与导出（TeX / Word）

- **修复 tabularray 2022A 整行合并格的宽度缺陷**：内置 bundle 钉在 2022A，它的整行合并格按首遍窄宽度算文字框，于是分组行、`||||` 整行合并的内容都在整行中间折行。`to_longtblr` 只对整行合并格把内容套进 `\parbox[c]{\dimexpr\linewidth-...}{...}`，让文字按整行宽度排；部分横向 / `^^` 纵向合并不动；写法对 2023A+ 也是无害冗余，无需掀打包与 bundle。
- **整行合并格内文字按设置对齐**：盒内补 `\raggedright` / `\centering` / `\raggedleft`，与 Word、预览一致；普通表格居中的「合计」整行在 PDF 里不再靠左。
- **窄表（全是定宽列）不撑满版心**：避免 `\linewidth` 套盒子把表撑出表外。
- **序号表边界**：别的列在该行起头往下 `^^` 合并时不当分组行，否则整行跨度会顶掉纵向合并、下面那格静默丢失；全角数字（`１`）与 `1)` / `1）` 也认作手写行号，不当分组标题。
