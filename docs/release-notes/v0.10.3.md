## 公文助手 v0.10.3

本版本给程序**加了一把机器上的锁**：可设访问密码，闲置自动退回锁屏，还能设一个进空白系统的第二密码；启用后稿件库整库加密、配置文件与接口密钥整份加密，磁盘上不再是一堆可读的明文。同时把**模型通道收敛成两个用途**（写作与文字复核），删掉一路用不上的「辅助模型」设置；智能写作（Pi）第一次能直接调用内网只读数据接口，长结果可分页续读；Pi 写正文改成「写入前自动留一版 + 直接覆盖」，不再有单独的 AI 工作稿层。

### 应用锁：机器上的数据自己看门

- **启动要输密码**：启用后冷启动先弹约 380 × 250 的小窗，只留密码框与「解锁」按钮；解锁后恢复上次的工作区窗口大小、位置与最大化状态。外壳把工作区尺寸另存一份，启动小窗关闭不会覆盖它。
- **闲置自动锁定**：设置页可选「永不 / 5 / 15 / 30 分钟 / 1 小时」，超时没有任何键鼠输入就退回锁屏；菜单里也有「锁定窗口」随时手动锁。
- **锁定前先保存**：锁定时把**所有已修改或新建的稿件与配置**都保存一遍（不受自动保存开关影响）；有任务在跑或保存失败时**不丢弃工作区**，状态栏说明原因。
- **锁屏遮住工作区**：运行中锁定时用当前主题的抽象三栏底图加高斯模糊与雾面遮罩挡住工作区，看不到原文内容，也不读取、不缓存真实页面像素；解锁后约 300 毫秒淡出，期间清空键盘事件并重置指针。
- **第二密码（诱饵系统）**：输第二密码进入的是一套**界面相同、数据完全独立**的空白系统，两套数据互不越界；锁文件形状恒定，看不出是否设了第二密码，设置页也只能「设置（覆盖）」与「清除」两个盲操作。
- **全库加密**：启用后稿件库迁移为 **SQLCipher 密文**（文件头不再是 `SQLite format 3`），`config.json`、记住的稿件包密码、接口密钥文件三份整份加密；数据密钥随机生成并被主密码派生出的包裹密钥保护，**改密码只换包裹，数据零重加密**。备份包与磁盘同形态，也是密文。停用密码保护时在锁屏输一次密码即可解密回明文。
- **解锁不再每次都在「正在加密」**：库头嗅探 + 只读第一页判断，槽位已是密文就直接带密钥进工作区；两套密码交替解锁仍按命中槽位隔离。

### 模型通道：收敛成写作与复核两个用途

- **删掉「辅助模型」整块设置**（模型 / 备用 / 温度 / 思考深度 / 输出 / 窗口 / 超时）。知识库问答、检索重排、数据接口 AI 调用、任务助手识别这些一次性调用统一用**写作模型**（未选 Pi 时回落旧的文字起草模型）；**文字复核**是唯一保留的专门小模型，只留启用、模型与检查器开关。
- **写作模型配置损坏时如实报错**，不再悄悄回落旧起草模型；独立文字复核也不依赖写作模型配置。
- **Pi 知识库检索的重排改走写作模型**，不再先借辅助模型或复核小模型。

### 智能写作（Pi）：读内网接口，直写正文

- **Pi 写作能调只读数据接口**：新增 `api_search`（按用途搜只读接口，返回 id、说明与参数签名）与 `api_call`（按签名填参，调用前按 JSON Schema 校验，不合格不发请求）；只开放「只查询 + 允许 AI + 配置受支持」的接口，会改数据的一律拒绝。返回条目登记进证据台账，随本轮来源落盘。
- **长结果可续读**：`api_call` 把完整条目留在本轮缓存并返回 `result_id`，新增 `api_read` 列出全部条目、按 `item` + `offset` 分页读单条全文；缓存同时落盘到运行目录，恢复后仍能续读。单条资料被截断时如实上报 `text_truncated`，不再把片段伪装成完整结果。
- **接口请求不再跟随重定向**：3xx 按失败处理，密钥与请求体不转发；清理工作区时只有确认运行记录不存在才算孤儿，清理锁持有到删除完成。
- **停止后不再有慢工具在跑**：工具入口与慢工具阶段边界复检取消信号，迟到结果丢弃、不写证据；域工具在途槽位上限 4，满时明确失败，避免反复停止重开无限叠加线程、连接与模型额度。
- **写入前自动留一版，正文直接覆盖**：正文非空且稿件已入库时，AI 写入前自动提交一个「AI 写入前 MM-DD HH:MM」版本，成品直接覆盖正文，找回与看差异走「版本历史 / 版本对照」；正文为空、未入库或与最新提交版相同则不提交。**去掉了单独的「AI 工作稿」预览层**，候选只报进度。
- **宿主 0.3.5 对齐交付通道**：五个正文技能只能 `submit_document`、提炼技能只能 `finish_report`、风格学习只能 `submit_style`，两侧都拒错；恢复只认启动前已存在的同类回执。分阶段依赖改由宿主自动补齐，模型不再手填 `uses`；读工具按本次预算声明上限，修掉长材料被二次截断的问题。
- **内置技能补边界**：当前日期只帮助解释相对时间，不是事项发生日期；风格档案只描述样稿反复出现的写法倾向，样稿未出现不等于禁止。

### 界面与打包

- **锤子稿纸主题把正文与 AI 工作稿并到同一张纸**，用贴边纸签切换，不再从稿纸掉到木纹上。
- **输入法展开网格与候选条字号协调**：汉字统一取候选条的 95%，切换不再突兀。
- **修复设置页打开输出目录的空列表崩溃**（未打开任何稿件时索引越界）。
- **macOS DMG 保住随包 Pi 运行时的哈希**：不再 ad-hoc 重签 `bin/node`，避免签名改写文件后与随包清单不符导致智能写作整条链不可用；补拷缺失的 NUCLEO 许可证；`.sha256` 只写文件名，别人下载后 `shasum -c` 能直接过。
- **CI 兼容 clippy 1.99 的新 lint**（`chunks_exact` → `as_chunks`）。

### 文档

- **README**：AI 一节改写为 Pi 口径（写作入口、七个内置技能、直接写正文但可整次撤回、接口与风格），补上「应用锁」条目，代码行数与自动化测试数按本版重数（约 31.3 万行 / 2890 项）。
- **使用帮助**：第 20 章「设置全解」补「应用锁」整节（启用、启用之后各项、锁屏行为），分区数由十一改为十三并按实际分组重排；第 21 章补「启用应用锁后的磁盘形态」与备份包为密文的说明；第 1 章补上锁与数据只在本机的口径；附录 B 补三条常见问题（密码忘了、备份包在别的机器上打不开）；附录 C 补「应用锁」术语一组，并把 AI 术语表改成 Pi 口径。
- **手册目录**（`docs/manual.md`）同步第 20 章的分区数。

### 质量检查

- 三平台 CI 门禁（格式、clippy、2890 余项自动化测试）全部通过；Windows、Linux ARM64、macOS arm64 各自跑 fmt / clippy / test。
- 本版新增的关键测试：解锁时槽位按文件头嗅探、诱饵槽不触发真槽加密卡片、锁定前保存（含关闭自动保存与保存失败两种情形）、错误密码保持蒙版、反复锁定解锁后单实例收件队列不丢、密文库备份与恢复、密封文件往返、真实临时库的知识库调用链。

### 已知限制

- 应用锁与全库加密**待真机验收**：Windows / Linux / macOS 上的锁屏绘制、窗口位置恢复、300 毫秒过渡、真实大库迁移耗时与空间占用都要在真机上过一遍。
- Pi 的只读接口调用与长结果续读**待内网接口联调验证**。
- 旧引擎代码尚未退役；要素抽取与「辅助模型」已退役，仅保留历史兼容路径。
