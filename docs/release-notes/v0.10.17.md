## 公文助手 v0.10.17

本版本重整了起草页的视图与输出菜单，把发文登记簿做成独立页面并接入起草页取号，同时修正功能区布局与锁屏配色。

### 起草页：视图与输出

- **视图分区退役，显示开关交给状态栏**。状态栏右端两个入口接管「源码显示」与倍率，右上角只留四种预览模式，Markdown 模式下不再追加目录 / 缩略图；统计标签精简为「X 字 · 页数」，英文词数与口径进悬停提示。旧配置里的 `"View"` 标签加 serde 别名，避免整份配置被当作损坏文件重置。
- **输出改成点哪种导哪种**。去掉统一导出与格式勾选，PDF / Word / Markdown / Typst 包点哪个导哪个，导完按格式打开或定位，右键可另存、复制、定位；「成品」菜单与标题栏导出入口一并删除。
- **Word 导出放开**。此前设置页强制禁用、实际仍能导出，现统一为可导出，格式名统一叫「Word」。设置页「导出格式」改名「导出」，删掉不再起作用的格式勾选与未接线的自动导出开关。
- **新增 ⌘P / Ctrl+P 打印**；导出目录入口正名为「最近成品」。
- **插入分区精简**。按用户确认下线词库词条、中文日期与拼音符号入口，「待核实」作为正文占位语法保留。

### 发文登记簿

- **登记簿改为独立页面**：池栏、表格、详情与补录 / 状态 / 备注形成闭环，占号 / 已用 / 废号语义按池区分，单位归一化池与后台同步一并补齐。
- **起草页文号行新增取号卡**，可从登记簿直接取号。

### 主题与锁屏

- **默认主题改为月白**，明暗跟随系统——浅色系统用月白、深色系统用北欧。月白重做配色（月白冷底、墨蓝文字、青瓷强调，朱砂只留给风险与待核实）；旧的 `Claude` / `Celadon` 等主题名按别名回退，旧配置无需迁移。删除按主题分套的应用图标，只留默认品牌标一套。
- **锁定后密码框不再退回内建黑底**：`lock_now` / `enter_workspace` 不再整体重置 egui 内存，只清控件记忆，保留明暗偏好、自定义样式、界面缩放与原生标题栏跟随；锁屏与「正在验证密码」每帧按系统明暗校正配色，密封配置后下次启动仍能决定登录框配色。

### 功能区布局

- **修掉分区卡逐帧下沉铺满整窗**的回归：把整行包回 `ui.horizontal`，行高收到 `interact_size.y`，不再被 `right_to_left` 撑到全部剩余高度。新增 30 帧回归测试断言分区卡行贴顶不下沉。
- **窄窗口下分区卡与右侧视图按钮不再叠压**：右侧按钮先贴右缘占位，左侧「文档要素＋分区卡」放进横向滚动区，溢出裁掉；新增 720 / 1200 宽度下控件不相交的回归测试。
