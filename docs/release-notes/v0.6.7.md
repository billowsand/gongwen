## 公文助手 v0.6.7

本版本把**预览从「整篇每帧重排」改成「按内容缓存 + 只画可视区」**：60 页左右的花脸稿与红头呈批件，从每帧 6–15 ms 降到 0.1 ms 上下，鼠标移动、滚动与光标闪烁不再付全篇重排的代价。同时把应用内拼音输入法的**辅码提示**与**公文词表来源标记**做细，并修掉 Windows 启动时的空白闪屏。

### 预览：按正文哈希缓存 + 只画可视区

- **每帧不再重新解析整篇 Markdown**。预览新增 `preview::memo`，按「正文 + 字号 + DPI + 配色 + 字体图集代」做键缓存 Markdown 解析与切块、研究报告的二次解析、附件切分、紧缩标题标志与文档标题。每类留最近 4 份，多块预览同时存在（版本对照右栏、对照窗）时不互相挤掉。花脸稿的预览实测约 1.2 ms/帧 → 每帧基本只付一次哈希查找。
- **只画可视区附近的正文块**。新增 `preview::cull`：每块画完记下高度与它在页边号栏里记下的行，按「块内容 + 标题编号计数器 + 缩放 / 版心 / 字面」做键缓存。远离视野（可视区上下各放宽一屏之外）的块只按记录的高度占位、不排版；看得见的块照常现排，并顺手更新记录。
  - 跳过的标题照样推进编号计数器，后面的编号接得上；
  - 页边行号按记录的行补回，整篇一路数下来的号码不变；
  - 导航刻度回查的标题矩形照样登记；
  - 锚点所在块总是现排（要铺底色、要滚过去）；
  - 块的指纹不含源码绝对位置，前面增删字、块整体挪位仍能复用。
- **红头呈批件走独立的打印分页器，每帧也分页缓存**。`preview::memo` 把分页结果按输入缓存（正文、编号样式、表单 JSON、呈报领导 / 承办单位 / 落款的显示值、要素标注、缩放、像素密度、配色版本与字体图集代），版面里存着 galley，字体一重建字形坐标就作废，新增 `memo::font_epoch` 用探针 galley 识别重建；可视区上下各放宽一屏之外的纸只占位不画；开着页边行号时照画（号码整篇一路数下来），锚点待滚动的那一页照画；附件纸上的块与普通公文一样走 `preview::cull`。60 页的红头呈批件预览实测 6.4 ms → 0.12 ms/帧。
- **拖动版本对照分隔条不再每帧换字号重排**。把这套逻辑从起草页预览抽成 `preview::freeze`（`ScaleFreeze` + `show_frozen`），起草页、版本对照右栏、稿件管理对照窗三处共用；起草页行为不变。
- **研究报告标签与稿件库标题改按封面口径取文件名称**。旧行为曾把研究报告标签和稿件库标题落到内部编号上，导致导出后切换 Tab 找不到原稿；现在取封面口径（研究报告取 frontmatter 的 title，其它文种取 `DraftInput` 的 title）。

### 应用内拼音输入法：辅码提示与公文词表来源标记

- **候选右上角按辅码进度提示「还要敲的码」**。同步上游 `feat(windows): 候选右上角标辅码，新增学码档` 的内核改动，`vendor/qingjian/core/src` 与上游逐字一致。只敲了辅码首码时，首码对得上的候选在词后右上角用淡色小字标出第二码（`栏ˢ`），对不上的不标；两码敲满后已严格过滤，不再标。候选窗：辅码小字跟在词后同一行、顶格对齐，候选窗高度不随它跳；整句星标让位。
- **新增学码档档位**。设置页「双拼辅码」下加「候选显示辅码」下拉：`typed`（默认）/ `always`（学码：没敲辅码也标完整两码）/ `off`；装了码表才可选。
- **公文词表带进来的词在候选窗序号后带一个弱化色小圆点**。基础词库（`dict.qj`）里同一读音查不到的词，序号后加灰色小圆点（`3 · 综合处`），一眼看出这是本单位词表里的词；「公文」这类基础词库本来就有的词不标。
  - 按「词 + 读音」比对：人工标了新读音的多音词，只有新读法带标记，基础词库原来那个读法不跟着标。
  - 只标词库词，整句、快捷候选、英文不标；标记放在词前，右上角留给整句星标与辅码。
  - 同步词表、引擎重新装配后都重算标记集合；没同步过词表时不标。
- **使用帮助同步更新**：辅码提示（17-lexicon）、「候选显示辅码」档位（20-settings）、公文词表来源标记（17-lexicon）。

### Windows 启动：不再闪出空白窗口

- **eframe 建窗先隐藏、首帧画完再显示**，但 winit 在 Windows 上给隐藏窗口最大化 / 全屏会直接 `ShowWindow`，导致启动时闪出几次空白窗口。建窗时摘掉恢复出来的这两个状态，改在首帧之后用视口命令补发。

### 界面细节

- **功能区选项卡间距收紧**，提示词列表项标题占满行宽、「内置」标签固定行尾；输出栏成品图标尺寸统一。
