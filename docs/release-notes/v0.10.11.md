## 公文助手 v0.10.11

本版本让起草页不必导出就能看到实际排版结果，状态栏持续报告写作模型是否可用，加密工作区自动启用内置输入法。

### 起草页：内存 PDF 预览

- **「输出」区的 PDF 单击就是预览**。不再是先导出再打开：当前正文与表单要素在后台按正式版式排版到内存，开一格只读预览标签页；尚未保存的修改也能看。预览不留明文文件，也不需要导出密码。
- **查找在后台扫描**。`Ctrl+F` / `⌘F` 打开查找，按 PDF 文字层逐页检索、忽略空白与大小写，显示「命中页 N / 总数」，上一处 / 下一处直接跳页；检索期间仍可翻页，关闭面板或改词即取消上一次扫描。
- **预览与稿件同步**。稿件或要素改过后页内提示「稿件已修改，请刷新预览」；刷新重新排版并沿用原有的阅读模式、缩放与所在页。关闭稿件标签会一并关掉它的预览；预览标签上的 `Ctrl+W` 关闭已覆盖。
- **切换工作区前先收尾**。锁定前若排版仍在进行，先等它退出再切槽位，避免读到别的槽位的资源；排版期间不写盘，加密模式下同样可用。
- **导出入口收进下拉**。「导出 PDF 并打开」、导出到…、复制文件与在文件管理器中定位都保留；Word 与 Typst 包的单击导出不变。

### 状态栏：写作模型健康

- **模型名换成状态胶囊**。状态栏中间显示写作模型是否可用：模型未选择 / 配置不可用 / 待检测 / 服务在线 / 模型未列出 / 检测失败，鼠标停留看具体说明与原因。
- **启动与改配置后立即探测，之后每分钟复检**。只请求所选提供商的模型清单，5 秒超时、在后台线程执行，不卡界面；服务商表单收起或离开「AI 管理」页后按新地址与密钥重测，旧结果立即失效。
- 「服务在线」指服务能连上且清单里有当前模型，用来提前发现「配置看着对、模型其实没加载」的情况。

### 加密工作区与输入法

- **加密工作区固定启用内置词表输入法**。应用锁启用后的工作区始终用内置输入法，设置页的「启用」开关置灰并说明；普通工作区仍按原来的开关，退出加密后设置不变。
- 修正内置输入法不再接管键盘时未归还系统输入法的状态残留。

### 安全维护

- **ZIP 依赖升级到 9.7**，修掉加密稿件包的完整性问题：WinZip AES 条目在数据提前结束或内容为空时不校验 HMAC（RUSTSEC-2026-0545），能改密文的人可以让导入方拿到被篡改的明文而不报错。程序自有的 ZIP 与随仓库的 anydoc、rust_xlsxwriter 一并升到 zip 9。
- docx-rs 最新版（0.4.22）仍锁 zip 8.6，但它关掉默认特性、只开 deflate，只用 ZipWriter 写 DOCX、`by_name` 逐条读，不调用 `extract` / `ZipStreamReader`，也没有 AES 与 legacy 解码路径；相关公告按路径写进 `.cargo/audit.toml` 的豁免说明，等上游升级后删除。
- zstd 已随 jieba 的 include-flate 升到 0.14.3（zstd-safe 8.2.0），删掉对应的三条过期豁免；本机 `cargo audit` 无漏洞项。

### 工程与维护

- 新增写作模型探测的单元测试：启动即测与失败后按同一间隔复检、改配置替换目标并丢弃旧结果；输入法另有「加密工作区启用、普通工作区沿用原开关」的用例。
- 修掉 Linux 外设监控里未使用的导入，Linux 变体重新通过 clippy；定期依赖漏洞扫描补上 `issues: write` 权限，不再因无权创建维护状态 issue 而在最后一步变红。

### 质量检查

- 本机 `cargo fmt --all -- --check` 无输出，`cargo clippy --locked --all-targets -- -D warnings` 零警告，`cargo test --locked --all-targets --no-fail-fast -- --test-threads=1` **3162 通过 / 0 失败 / 91 忽略**。
- 起草页 PDF 预览的界面测试覆盖：不导出、不设导出密码也能排版并出预览，全程不在输出目录、图表缓存或配置目录留下文件；刷新会重新排版并丢掉旧结果；关闭稿件标签与锁定前台排版中不会切走工作区；功能区单击「PDF 预览」开预览、下拉里保留「导出 PDF 并打开」；研究报告同样在内存里排出。查找按文字层匹配已用单元测试验证。
