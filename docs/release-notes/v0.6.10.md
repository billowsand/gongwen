## 公文助手 v0.6.10

本版本给起草页加了三样写稿工具：**标题聚焦编辑**、**候选区**、**Markdown 源码目录与全文缩略图**；研究报告里的**公式**扩展到标题、引文、文框、表格与封面题名，**引文与文框可一键生成**；同时修正了红头呈批件与公函预览里几处与 TeX 不一致的版式问题。

### 起草页：写稿工具

- **标题聚焦编辑**。光标放进一节（正文或标题行都行），点「开始」「格式」里的「标题聚焦」或按 `Ctrl+Shift+H`（macOS 为 `⌘⇧H`），把同一上级下的兄弟标题集中到一个对话框里统一修改，改完一次写回正文。编号只读，只改标题文字，`#`、手写旧编号与研究报告行尾锚点原样保留；显示字数并标出与同组中位数相差较大的条目，可单条还原；可切到全文这一级。`Enter` 跳下一条、`Ctrl+Enter` 写回、`Esc` 取消。
- **标题聚焦的「大字」模式**，供投屏时给领导看着改：标题按纸上的公文字体放大、对话框铺宽，字数与正文开头不显示，改过的条目编号变为强调色；开关写入配置，下次打开沿用。
- **候选区**。暂时用不上又舍不得删的文字，选中后右键「移入候选区」或按 `Ctrl+Shift+X`，移到编辑区底部的候选区（源码、实时排版、分栏三种模式都有），整段移走后多余空行自动合并，并记下来源小节与时间；展开后可拖选、双击选一句、三击选一段，「插入选中」（`Ctrl+Enter`）插回正文光标处，也可整条插入。移入、插入、删除、清空都可在折叠条上撤销。候选按稿件各存一份，随稿件保存，不进版本、不进离线同步包、不进导出文件。编辑框同时新增右键菜单（剪切、复制、粘贴、移入候选区），右键时保住选区。
- **Markdown 源码目录与全文缩略图**。源码模式左侧显示标题目录，与预览目录共用标题、编号与层级规则，点标题跳到原文，可按父子关系收起展开；右侧全文缩略图按编辑器实际换行绘制，长稿可在缩略图内滚动，固定高度的可见框支持点击与拖动定位，触边拖动手感也做了改善。两列可分别收起，窗口过窄时临时让出正文宽度。
- **审校显示方式切换不再残留高亮**：从 Markdown 对照模式切回单栏后，光标跟随高亮不再一直留着，刚编辑的位置也会滚回视野、焦点恢复到编辑框。
- **Markdown 分栏的选区与预览同步高亮**：选中一段文字后两栏改用独立的选区颜色标出对应范围，跨行选择不再把未选中的整行染亮；图片、表格等无法逐字对应的版式块以轮廓提示。
- **面板外框统一**：候选区、目录、缩略图、源码编辑框统一为同一套面板外观。
- **标题仿宋合成加粗与正文预览设置同步**。

### 研究报告：公式与引文文框

- **公式排进更多位置**：标题、引文、文框、研报表格单元格里的行内公式排成公式；居中、居右区与引文、文框里整行 `$$…$$` 排成独立公式；封面题名里的 `$…$` 也排成公式（分行时公式不拆开）。标题与题名里的公式书签写源码。公文文种与 Word 照旧印源码。
- **引文与文框一键生成**：光标在空行上点按钮插入模板并选中占位，选区可一键包成引文；引文里再点去掉标记，文框里点同名去除、点异名就地改名。
- 修正表格单元格转义时 `\textbackslash{}` 的花括号被重复转义的问题；小四文框与表格里的上下标不再因缺字形中断编译。

### 版式：预览与 TeX 对齐

- **红头呈批件预览补上附件的 `#` 标题**：此前附件正式标题不显示，与白头件不一致。
- **红头呈批件预览的落款与 TeX 一致**：少于 5 字的落款单位字间留空、分散对齐到 5 字宽；成文日期居中于「落款单位 + 签字空间」整段，不再偏左。
- **公函预览的抄送多行时，「（共印 x 份）」落在最后一行行末**，按三字符悬挂缩进排抄送，最后一行放不下时另起一行，与 TeX 一致；此前它固定在第一行。
