## 公文助手 v0.6.2

本版本把红头呈批件的首页版式收齐：标题与红色横线对齐、首页正文不再冲出批示栏、文号不再压红线；附带一份 Windows 安装包修复——向导字体走中文 UI 字体，中文显示不再乱码；研究报告那条线把数学公式、构件分区与 `#` 作报告题名串成一条完整路径。

### 红头呈批件：首页版式收齐

- **红色横线现在真的「横」着**：红线浮动表的行高之前给的是 1 缇，Word 把它当不可见对象整段丢弃，只剩批示框的右段漂在空中；改成 20 缇（0.35mm）后稳定渲染，且远低于标题顶沿，不参与绕排。
- **标题字面顶沿对齐横线**：版心顶端往下 48 mm 处画红线，标题字面顶沿落在横线下方 7.4 mm——之前用 `par\vspace*{55mm}` 硬塞一行，Word 行盒把小二字面压低约 4 mm；2902 缇是同一份稿件 PDF 与 Word 各渲染一遍、量着对齐后取的值。
- **抬头高度反映进标题段前间距**：密级/发文机关/文号各自用固定行高排，累加时漏算了 `before`，标题位随选项不同上下漂；现在三段 `before` 都进了累加，标题位与红线不再随发文机关/文号的有无抖动。
- **首页正文让出红线留白**：把红线往下挪 4 mm、字号压回二号，正文首行不再从红线下面探出来；Word 里横线与标题之间的间距也修回 LaTeX 那一侧的视觉。
- **首页以【…】开头的段落不再冲出批示栏**：之前这串字被认成主体之外的标注，整个缩进脱开段落流；现在随其它段落一起进正文流。
- **预览侧同步**：红头、文号按基线定位而非顶部，预览窗口与最终导出同源。

### 安装包：Windows 向导不再乱码

- **修掉「中文安装向导一片方块」**。`scripts/ChineseSimplified.isl` 是 Inno Setup 6.5+ 的中文翻译，但仓库里一直存的是无 BOM 的 UTF-8——Inno 6 在非 Unicode 模式下把无 BOM 的 ISL 按 ANSI 解码，中文字节全部解析成乱码。文件加 UTF-8 BOM 之后，编译期就能拿到正确的中文消息。
- **向导字体锁到 Microsoft YaHei UI**。`[LangOptions]` 里之前注释着 `DialogFontName` / `WelcomeFontName`，落到系统默认字体；少数精简版 Windows 上默认 UI 字体不带 CJK 字形，中文显示为方块。现在强制 YaHei UI，9 号正文 + 10 号欢迎页，向导字体与 Windows 文件管理器同源。
- **`LanguageCodePage` 从 936 改为 0**：向导字体已经走 Unicode 渲染路径，写具体代码页反而限制字符集；置 0 让 Setup 自己按 Unicode 处理，覆盖 GBK 之外的字符也不会再出错。
- **`package-installer.ps1` 补上 Inno 6 实际安装路径**：官方 Inno Setup 6.x 默认装在 `%LOCALAPPDATA%\Programs\Inno Setup 6\app\ISCC.exe`，旧脚本只查顶层 `ISCC.exe`，本机找不到就报错；现在每个候选路径都补一份 `app\ISCC.exe`。

### 行内忙碌指示：宽度自己说了算

- **不用 egui 自带的 Spinner**：它的尺寸吃 `spacing.interact_size.y`（本主题 30px），塞进标签页内容行（28-8=20px）会把行撑高、标题被挤下移；其它窄行同样会溢出。
- **`theme::spinner(ui, size, color)` 显式吃 `size × size`**：调用处按邻座图标给值（标签页 14px、状态点 8px），忙与不忙之间布局纹丝不动。
- 画法也比自带稳：自带 Spinner 扫过角是 `sin(t)`，一伸一缩地抽搐；新版扫过角恒定 280°，匀速转，尾巴用 24 段透明度渐隐，头尾各补圆点收口；线宽 1.5~3px 跟直径走，14px 上也保持可见度。

### 研究报告：数学公式与构件分区

- **研究报告预览渲染数学公式（latex-rust）**。`$...$` / `$$...$$` 在预览里直接出字形（用 STIX Two Math 实体），不用先去 PDF 看一眼再回改。
- **研究报告导出同步支持数学公式**。mdx 升到 v2.16.2，texbundle 带上 amsmath/mathtools 与研究正文字号的 CM 数学实体字体，PDF 与预览在公式区能对得上；mdx v2.16.3 进一步把交叉引用检查失败的具体原因带回来，再也不用「cross-reference undefined」一眼看不出是哪一条。
- **texbundle 补回公文链缺失文件**。`gongwen-texlive.ttb` 之前漏了公文链的几个文件，公文导出偶发失败；现在补齐并把完整重建流程写进 runtime 文档，下次再有人改 mdx 清单不会重蹈覆辙。
- **研究报告正文 `#` 作报告题名**：不再依赖 frontmatter 的报告题名，正文里第一个 `#` 标题就是题名。
- **构件另置分区卡**：图、表、公式、引用、脚注五类构件各自有专用分区卡，不再挤在「批注」里；表题独占一行、不再粘在段落里。
- **候选清单改按需算**：之前把全部引用候选都塞进内存，启动时一并展开；现在按用户当前位置算，内存与启动都收敛。
- **锚点 / 引用 / 脚注工具与校验齐备**：`d70611c` 那一条把研究构件三件套（锚点跳转、引用解析、脚注上标）的工具与校验补齐。
