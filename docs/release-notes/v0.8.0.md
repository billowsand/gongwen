## 公文助手 v0.8.0

本版本换掉了两根地基：PDF 排版从 Tectonic（TeX）整体换成**进程内的 Typst 引擎**，公文与研究报告都不再需要外部排版环境；应用内输入法从拼音内核换成**可维护的词表输入法**，并新增「输入法词表」页。随包中文字体统一为覆盖 GBK 的方正系列。

### 排版引擎：Typst 取代 Tectonic

- **PDF 全部由进程内的 Typst 引擎排出**，一份公文几十毫秒，完全离线，不依赖本机装任何排版软件。公文模板 `assets/typst/gongwen.typ`，研究报告模板 `assets/typst/research.typ`；`typst-layout` vendor 进仓库并打上按 xeCJK 限定的标点收缩补丁。
- **Tectonic 与整条 TeX 链路移除**：删除 `texcompile`、`export::latex`、`gonghan-gwa.cls`，以及 vendor `mdx` 的全部 TeX 输出（`md2tex.cls`、模板与预热文件）。
- **导出格式去掉 `.tex`**：勾选项变为 Markdown / Word / PDF 三项，PDF 成为独立勾选项（旧配置里的 `tex` 字段按别名读入，不用手改配置）；功能区成品按钮只留 PDF 与 Word。
- **研究报告也走 Typst**：封面、罗马页码目录、摘要、部分与章节、跨页续表、插图、引文与文框、脚注、GB/T 7714 文献逐项对照 `md2tex.cls` 实测；公式仍由 `latex-rust` 排成 SVG 嵌进 PDF。
- **修复研究报告公式里的中文渲染**（`\text{中文}` 等）——排版阶段缺字形导致整条公式排不出来的问题，改由随包字体按数学基线与字宽拼回。
- 花脸稿、稿件库批量导出、送批材料统一走同一套 `export::write_pdf`；打包与 CI 不再携带 Tectonic、TeX bundle 及其许可证，发布冒烟改为用随包 runtime 排遍各文种。
- 实时排版模式因此下线（它与 Typst 排版器并存会带来两套版式度量）：**视图从五种减为四种**——源码、版式预览、分栏、版本对照。

### 字体：统一为方正 GBK 系列

- **中文字形改为覆盖 GBK 的方正系列**（方正仿宋 / 方正楷体 / 方正黑体 / 方正书宋 / 方正小标宋）。原来随包的中易五支（仿宋_GB2312 等）不再随包，**「喆」「赟」「堃」这类 GB2312 之外的字直接就能排**，不再依赖兜底字体补字。
- **西文与数字走独立拉丁子集**：`GWFangSongLatin` / `GWSimSunLatin`（各约 10 KB，由 `scripts/make-latin-subsets.py` 从仿宋_GB2312 与宋体抽取）置于回退链最前面，正文西文数字保持仿宋字面、页码数字保持宋体字面，符合国标观感。
- 预览（egui）与 PDF 字形同源；DOCX 仍按原名引用中易字体，Word 端零改动，粗体回落名钉死为「黑体」。
- 研究报告字体（方正书宋 / 黑体 / 楷体 / 小标宋 + TeX Gyre Termes + JetBrains Mono）合并到同一组方正系列上。
- 安装包体积从约 70 MB 降到约 62 MB，随包字体从 77 MB 降到约 65 MB。

### 输入法：可维护的词表输入法

- **引擎换成按编码精确查表**，不再使用全拼、双拼、辅码、整句模型、自动调频，也不再有独立进程；候选来自基础表、公文词表、已启用的导入表与个人词条，同码同词合并并保留来源。旧的 `dict.qj`、`lm.qj` 与拼音学习数据不再需要。
- **新增「输入法词表」页**（主菜单与状态栏可进）：查询维护、查码、导入与来源、体检、修改记录。
- **基础表只读，日常修改进个人层**：加词、屏蔽、调序都记在个人层，可逐条回退；换回上一版用「撤销上次基础表升级」，升级前先列出与当前表的差异（新增 / 删除 / 换位）以及升级后个人层里会失效的记录。
- **自动出码**：从基础表反推每个字的编码与词组的构词规则（Rime 写法），用全码词组逐条验证选命中率最高的一组；多音字按「该字码在已有词组里被用过多少次」排序，其余列在「其他可能」里一键切换。换成五笔、郑码这类表同样适用。
- **加词窗重做**，新增造词与查码；候选窗加简码、逐码与词组提示，空码标记，候选右键可调序与屏蔽，词表来源改为词后星标。
- **公文词表改用输入法出码器出码**：只加载已接受且为四码的词，导出生成公文四码词表（原「导出小鹤码表」入口随之更名）。

### 公文引用

- **正文可插入公文引用**：从稿件库按名称或完整发文字号搜索，源码保存引用标记，分栏 / 版式预览与 Word / PDF 都显示 **《公文名称》（发文字号）**，插入时自带快照。
- **引用与来源解耦**：快照随稿件保存，来源后来改名换号不会自行改写本篇；「本篇引用」面板可再次插入、定位、打开来源、重新核对、更新、编辑快照、替换来源，或全部转为普通文字。更新先看新旧预览再确认，本篇各处一起变更。
- **随版本与同步走**：版本对照、稿件合并、离线 ZIP 往返都认识引用，引用快照随包带走；另一台电脑没有来源原稿也能正常显示与导出；AI 闸门与跨稿复制同样处理引用。

### 起草页与导出细节

- **下线起草页的「办理进度」状态表**（七阶段 SOP）：它的判据全部落在别处已有的信号上（要素区「缺 N 项」、抽屉必错与待核实、状态栏孤行提示、标签 ● / ○ 标记），且会出现与标签相反的结论。帮助第 04 章改为一张「你要看的 → 去哪儿看」对照表。
- **状态栏显示中英文统计与实际页数**：中文按汉字、英文按单词计，统计标题、正文、表格、图题与附件正文；页数来自完整定稿的 Typst 实际排版（含封面、目录与空白页），停笔后后台更新，排版失败可悬停看原因、点击重试。
- **导出文件与目录改用提交版本名称后缀**：文件名不再带分到分钟的时间戳，改用实际对应的提交版本名称（如「送审稿」「定稿」），尚未提交或提交后又有改动用「待提交」；载入历史版本且未修改时用该历史版本的名称。

### 打包与维护

- **runtime 收敛为单一 `runtime.zip`**：字体与许可证本就平台无关，原来按平台拆 4 份 SHA256SUMS 与 2 个 zip 属重复分发，现合并为一份清单 `SHA256SUMS.txt`；`release.yml` 与 `ci.yml` 三处下载同步简化，CI 的 runtime tag 与 release 一起升到 v0.8.0。
- **修正随包字体更名后遗留的打包校验**：`package-deb.sh`、`package-linux-tar.sh`、`package-dmg.sh`、`package-macos.sh` 仍在校验旧名 `FangSong.ttf`，会让 deb 打包与冒烟整段失败；一并改为 `FZFangSong.ttf`。
- **依赖随包字体的测试在没有 `runtime/fonts` 的环境（CI）下跳过**，与仓库原有的 `sample_tests` 口径一致；有字体的环境（本机与发布冒烟）仍然照旧真排 PDF。
- 移除已不使用的输入法内核与 4 个 vendor crate，`THIRD_PARTY_NOTICES.md` 同步。
- 依赖升级：分词库、表格导出库、Excel 导入与 TLS 安全补丁（含 `calamine`、`rust_xlsxwriter` 一线），并核对连续片段、文本偏移与大词表回读行为不变。
