## 公文助手 v0.10.14

本版本把 Release 口径切到 Windows x64 非 AI 版，并修掉加密导出、备份恢复与导入链上几处数据安全缺口。

### 发行版：非 AI 版

- **Release 改发非 AI 版**。安装包为 `gongwen-assistant-no-ai-0.10.14-win-x64-setup.exe`：起草、排版、校对、版本、稿件包、送批材料、销毁审批表等本地功能全在；AI 全版不再随 Release 发布，需要时从源码构建。
- **网络代理与检查更新只留在 AI 全版**。设置页的网络代理分区、关于窗的「检查更新」入口与 `net` / `update_check` 模块都跟随 `ai-workbench` 特性编译；非 AI 版的更新检查地址缺省留空，旧配置字段保留兼容。
- **非 AI 版不再编译 HTTP/TLS 依赖链**。`reqwest` 改为 `ai-workbench` 下的可选依赖；同时按产品确认关闭 eframe 的 accesskit 无障碍适配（不做屏幕阅读器支持），锁文件减少 45 个包。
- **稿件包默认打开方式**。非 AI 版安装时也把 `.gwx` 设为默认打开方式（此前只有 AI 版登记默认值），双击稿件包直接进入导入流程；两版同机安装时以最后安装者为准。

### 应用锁

- **首次启用改成两种明确选择**。可以「设置密码并启用加密」，也可以勾选「我已了解明文保存风险」后以普通模式进入；设置访问密码与第二密码都要求二次输入一致。
- **从旧明文工作区升级不再要求密码**。升级后直接以普通模式打开原有数据，不再被首次设置弹窗挡住。

### 加密导出与词库

- **词库加密导出先要导出密码**。加密工作区里「导出加密 Excel…」改走与文档、送批材料、销毁审批表相同的出口：先输导出密码，再开保存框；普通工作区仍是明文风险确认，不重复提示。
- **锁定过渡按 fail-closed 处理**。应用锁已启用但没有密钥（锁文件为 Locked / Broken）时，导出与保存函数不再按普通工作区写明文。
- **清理上一次明文导出的残留**。加密出口按最终文件名更新导出清单，并删掉被 `.7z` 取代的旧源码包 / 份号清单——只动清单登记过的文件。
- **词库导入限 32 MiB**（原用 256 MiB 的文档上限），解压声明总量同源校验，避免超大表把配置撑大、拖慢每次启动与保存。
- **读得了别家写的加密工作簿**。新增 msoffcrypto-tool 生成的 Agile 加密词库夹具，读取端不只认本程序 writer 的输出；等长篡改加密参数（SHA512→SHA256）会明确拒绝。

### 导入、备份与送批

- **稿件包导入先验证工作区**。提交前校验 `vault::workspace_matches`（未停写、槽位未变、DEK 相同），锁定或切槽后会整批回滚；知识库导入在每个文件前自检，不再往旧库继续写。
- **备份恢复期间停写**。关库后立即置写屏障，晚到的后台线程不会把旧数据写进正在替换的配置目录；恢复失败先复位屏障再重新开库，后续保存不受影响。
- **附引用词库失败不再阻断送批材料**。词库是附属件，生成失败（单位 / 人员数据冲突等）只降级为状态栏提示，主件与随行件照常导出。
- **公函版记承办行限 8 行**。表单「＋ 添加一行」到顶即停用，校验器对旧稿或导入稿超限给出「版记会超出页面或跨页拆开」的警告。

### 文档

- README 平台表、快速开始与 CI / Release 说明改为非 AI 版口径，安装指南同步到 v0.10.14；`AGENTS.md` 与发布 skill 记录当前只发 Windows x64 非 AI 版、AI 全版手工出包。

### 质量检查

- 本机 `cargo fmt --all -- --check` 无输出；`cargo clippy --locked --all-targets -- -D warnings` 与关闭 AI 特性的同一条 clippy（`--no-default-features --features task-assistant,linux-gtk-dialogs`）均零警告。
- `cargo test --locked --all-targets -- --test-threads=1` **3184 通过 / 0 失败 / 94 忽略**；关闭 AI 特性的整套用例 **2131 通过 / 0 失败 / 63 忽略**。
- 发布工作流只编译并打包非 AI 版二进制：先用 `--build-edition` 断言版本，再以 `-Edition no-ai` 组装暂存目录（断言没有 `runtime/pi`、`skills` 等 AI 资源），最后出 Inno 安装包并附 SHA-256。

### 下载

- Windows x64 非 AI 版安装程序：`gongwen-assistant-no-ai-0.10.14-win-x64-setup.exe`

安装包附带 SHA-256 校验文件。本次只发布 Windows x64 非 AI 版；AI 全版按《安装指南》从源码构建。macOS、Linux ARM64 与 Arch / Omarchy 的打包作业保留在发布工作流里（当前停用），需要时再启用。
