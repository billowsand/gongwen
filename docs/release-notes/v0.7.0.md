## 公文助手 v0.7.0

本版本把「送批材料」从方案推进到完整可用：白头件、红头呈批件可挂随行件、面板逐件状态可见、按提交版合并成一个 PDF、归档钉版、同步 ZIP 连清单随行件一起带走；同时把研究报告的数学公式从「能编译」推进到「中文也能看」，成品按钮、起草页快捷查找、Mermaid 中文排版一并收尾。

### 送批材料：五期完整落地（白头件 / 红头呈批件）

> 随行件不是附件：呈批件正文里 `<!-- [附件] -->` 标出的附件仍是主件的一部分；随行件是稿件库里的独立稿件，不在正文里标注、不加「附件 N」标识，版式与单独导出时完全一致。

- **数据层与面板**（一、二期）。三张表（清单、导出记录、记录明细）幂等建表；清单增删、重排按稿件 UUID 引用并连同别名解析，本机找不到的也保留在清单里；引用规则：主件限白头件与红头呈批件，不能挂自己、不重复、只有一层；主件归档后清单只读。起草页「开始」分区在呈批件下加「送批材料」入口；稿件库详情卡显示清单与管理入口，被引用的稿件会列出引用它的呈批件；删除确认：被已归档呈批件引用的不给确认、批量删除跳过这类稿件。
- **按提交版逐件编译并合并成一个 PDF**（三期）。`send_package_plan` 生成导出计划（主件在前、随行件按清单顺序，取钉住的版本或最新提交版的完整快照）；`src/manuscript_io/send_package.rs` 逐件编译、可选目录页、`lopdf` 合并——继承的 Resources / MediaBox 先落到页面上，奇数页起由后续件补同尺寸空白页（最后一件不补）；任一件失败整体失败，临时文件改名落盘、不动已有同名文件。目录页按公文走现有管线，序号 / 名称 / 文种 / 版本 / 页数一张表，密级沿用主件。面板先显示确认清单（版本、未提交修改、待处理分支、不能进包的原因），确认后后台线程编译合并并显示进度；成功后写导出记录并在应用内 PDF 标签打开，失败原因完整显示在面板里。每件对比上次导出版本、有新版本时提示并可打开版本对照（花脸稿）；底部列出历次导出记录。
- **归档钉版与同步携带清单**（四期）。主件归档时把清单里的各件钉在归档那一版的版本号上——「一律用最新版」的唯一例外。同步包：主件记录新增可选字段 `send_package`（随行件 UUID 顺序、钉版、主件钉版），呈批件一律带上、空清单也带（为空时不写出，旧包记录序列化与指纹去重不变）；ZIP 密码框加「连同呈批件的送批材料一起导出」（默认勾），随行件并入导出范围、导出前一并保存它们开着的工作稿；不勾时只带清单。导入：新建原样带清单（归档主件连同钉版）；另存副本带清单不带钉版；采用导入版与合并按 `take_package` 决定——清单增删不产生版本、分不出谁新，默认只在导入版较新或本机清单为空时采用；清单在整包稿件落库后于同一事务内统一写入。导入预览：两边清单不同时给勾选「送批材料清单也采用导入版」，跳过 / 暂存时给说明。已归档主件的面板说明改为取钉住的版本。
- **使用帮助与 README**（五期）。新增帮助章「22 送批材料」：概念、入口、增删排序、各件状态、合并导出、导出记录、归档钉版、删除保护与同步携带；登记进 `CHAPTERS`。功能区、稿件管理、术语表三章补交叉引用；手册章表 25 章。
- **真机验收待补**：TeX 编译 → 合并整条链、同步 ZIP 往返这两类还需要在真机上走一遍（详见 `docs/send-package-design.md` 末尾）。

### 研究报告：数学公式与中文混排

- **`\text{中文}` 混排**：STIX Two Math 没有中文字形，latex-rust 排版阶段即报缺字形；顶层 `\text` / `\mbox` / `\textrm` / `\textbf` / `\textit` / `\textsf` / `\texttt` 里含中文的段由预览层拆出，用随包仿宋经 usvg / resvg 光栅化，按数学基线拼回位图，字宽与基线用 `ttf-parser` 同字体实测；段间不加胶（TeX 里 `\text` 是 Ord 原子），行尾控制空格触发 latex-rust 悬空反斜杠报错的问题用补空分组绕过。
- **数学字体回退与任意深度嵌套**。`vendor/latex-rust` 升到 2.0.1（上游修了上下标画成全尺寸等 8 个缺陷），给 `MathFont` 加回退 face：主 face 缺的字（CJK）按回退 face 取度量与轮廓，glyph id 高位标记、光栅化按回退字体的 unitsPerEm 换算；MATH 查询对标记位做了防护。应用侧 `math_render` 回到纯 latex-rust 渲染，`font()` 给 STIX 挂上随包仿宋当回退，上一版的分段 / 合成代码全部删除。嵌在分数、上下标里的中文 `\text` 也能渲染（找不到随包字体时退回无回退的占位框行为）。
- **TeX 编译失败给出可读错误提示**。解析 tectonic 输出的出错文件、行号与具体命令，把 `Undefined control sequence` 翻译成人话：未内置宏包命令（如 mathrsfs 的 `\mathscr`）给出可操作建议，其余命令提示当前内置范围（内核 + amsmath / mathtools / amssymb）；缺文件类错误同样带定位；识别不了时维持原始日志输出。
- **导出内置 amsfonts 与 lmsans 数学字体**。`gongwen-texlive.ttb` 手工并集 amsfonts 包（amsfonts / amssymb、umsa / umsb.fd、msam / msbm / eufm 各设计字号 TFM 与 PFB）与 lmsans 8–17 号 OTF，并补齐 cm 字体族缺的 5–9pt 与粗体档；`md2tex.cls` 随之加载 amssymb，预热文档两种字号都排 `\mathbb` / `\mathfrak` / `\mathsf`。`\mathbb`、`\mathfrak`、`\varnothing`、`\leqslant`、`\therefore`、`\mathsf` 等命令导出 PDF 直接可用。

### 起草页：细节交互

- **审校提示支持逐条右键复制与整份复制**。抽屉标题右侧加复制按钮，一次带走导出失败原因和全部要素、版式提示（每条一行）；能定位正文的提示左键是跳转，复制放右键菜单，普通提示也一并挂上。
- **新增快捷查找**。`Ctrl+F` 之外的快速面板：输入即查、按稿件 / 设置 / 帮助分组、跳过去就开标签。
- **选中文字拖动与落点提示**（v0.6.11 已上线、本版本继续打磨）。
- **成品按钮右键支持复制文件与导出到指定位置**。TeX / PDF / Word 三枚成品按钮的右键菜单新增两项：复制文件（macOS 走 NSPasteboard、Windows 走 CF_HDROP、Linux 借 wl-copy / xclip）；导出到…弹出保存框另存。

### Mermaid：图表排版收尾

- **优化中文排版与超大图警告**。新版排版的中文节点不再被字宽估算切碎；超出版心宽的图给出明确警告，导出记录同步显示。导出用例正文补图引用 `{@fig:flow}`，让正文中能链回图。
- **测试 CI 兼容**（`test: 修 Mermaid 字号与甘特重叠测试在 Linux CI 字体丢字上的环境假设`）：CI 上的最小 Debian 容器里 usvg 把 merman 的中文文本节点丢光、只剩路径占位，断言硬红；收紧为「在当前环境能拿到文字节点时才校字号 / 标签」，stderr 留说明。
