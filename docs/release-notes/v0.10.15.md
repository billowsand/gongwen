## 公文助手 v0.10.15

本版本把「发过什么文、哪篇里写过什么、这些人怎么联系」收成一套本地台账：新增发文字号台账与发文登记簿、稿件正文检索、通讯录导出与制度有效性提示，并让加密导出直接用已保存的密码。

### 发文与登记：发文字号台账

- **发文登记簿按池记账**。稿件管理页「发文登记簿」按「单位 + 编号方案 + 年度」三个池登记文号，稿件建、删、改自动同步；纸质件可手工补录（类型、单位、代字、年度、序号、日期、标题、密级、备注），重号按池汇总提示，断号列出缺哪几号。
- **登记簿可导出 Excel**。编号复用统一文号规则，单位名取标准词库全称；走独立导出密码或明文风险确认，后台生成不卡界面。
- **会议纪要的代字随发文单位带出**。词库单位新增纪要代字，表单只读展示，换发文单位就带出或清空；纪要编号支持有代字与无代字两种写法，预览、Word、PDF 共用同一套排法。
- **制度有效性**。登记簿条目可标「现行有效 / 已废止 / 被替代」，并记替代文件与生效、废止日期（旧库启动时幂等补列）。起草时「本篇引用」命中已废止或被替代的制度会当场提示，可直接转到登记簿编辑状态。

### 检索与通讯录

- **`Ctrl+K` 查找稿件正文**。全局查找在标题、页面、词库之外追加正文命中：中文分词加汉字二元组建本地 FTS5 索引，随稿件建删改维护，旧库启动后后台补建；命中带上下文片段，选中即打开该稿并把查找条定位到那一句。
- **通讯录两个号码分列**。标准词库的人员拆成办公电话与手机，旧词表里的单个号码按形态迁移、旧 Excel 单列照常导入；承办联系人、收件人与校验统一办公电话优先、手机回落。
- **导出通讯录 Excel**。只出至少有一个号码的人员，办公电话与手机分两列，与词库导出同一套加密出口与体积上限。

### 稿件管理：合并成一册

- **勾选即合并**。批量操作新增「合并为一篇 PDF」：按列表顺序在后台逐篇编译，用送批材料的合并链合成一个文件，打开即可在应用内打印，不必逐篇导出再手工拼接。

### 加密导出

- **加密导出不再逐次输密码**。已解锁且已保存导出密码时直接取用；缺密码、设置损坏或失钥仍拒绝导出，且不弹框。
- **设置页可查看已保存的密码**。点开显示 30 秒后自动隐藏，手动隐藏、保存新密码、锁定或设置损坏即释放；复制仍走剪贴板风险确认。词库与输入法词表导出同步改为直接开保存框。

### 校对

- **裸发文字号也认**。正文里不带书名号、写成「（某函【2026】12号）」这样的发文字号，此前既不算公文引用也没有一键改法；新增 `RULE-NUMBER-BRACKET` 识别带机关代字、四位年份与「号」的括号年份，只把年份那一对括号规范成〔〕，代字与序号不动；书名号里的名称、已有引用、代码与公式跳过，同一处不重复报。

### 工程与维护

- **平台内核**。新增 `src/platform/`：单位编码、人员通讯录、编号方案与统一文号、稿件元数据与密级契约先落地（F0/F1），稿件库开库与迁移契约统一到 `Db::open`，日期解析与检索取词挪进平台层；`platform::search` 的取词不再按 AI 特性裁剪，非 AI 版照常编译。

### 文档

- README 补 Ctrl+K 正文检索、发文登记簿与制度有效性、通讯录导出、合并成一册、加密导出密码直用与查看、纪要代字与裸发文字号校对；代码行数与自动化测试数按本版重数。安装指南版本号更新至 v0.10.15。

- `cargo test --locked --all-targets --no-fail-fast` **3220 通过 / 0 失败 / 95 忽略**。
- 新增测试覆盖：正文索引随建删改维护与旧库补建、查询串转义；文号池重号与断号分组、手工补录行不被同步覆盖；纪要代字带出与无代字编号；通讯录只输有号码人员、两列号码；登记簿 Excel 导出的编号与单位取全称；保存密码的查看超时与锁定释放；裸发文字号只改年份括号。
