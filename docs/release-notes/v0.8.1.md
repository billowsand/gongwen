## 公文助手 v0.8.1

本版本把「引用」这件事做到底：正文里的《名称》（发文字号）**本身就是引用**，不再需要插标记、粘富文本，并能靠新建的**公文登记簿**按名称与文号当场比对；研究报告的文献引用重做，下拉即选、预览与 PDF 逐条一致。字体侧，公文仿宋/楷体换成 GB2312 非汉字合成字体，研究报告西文统一 Termes。

### 公文引用：正文纯文字 + 登记簿

- **引用就是正文里的普通文字**：《名称》（发文字号）即引用本身。移除 `{{公文:UUID}}` 标记、文末 `gongwen-reference` 快照定义与富剪贴板；合并、同步、导出、花脸稿不再对引用特判，稿件从此是纯 Markdown。
- **确定性识别**：书名号后紧跟可规范为「代字〔年份〕序号号」的括号即认作引用；只有名称的，须与稿件库或登记簿中某份无文号文件同名才算，`（试行）`「（征求意见稿）」之类不算。年份写成 `[2026]`、`(2026)` 也认。
- **新增公文登记簿**：把本机发过的公文连名称、文号、正规写法攒在一起（含更正前写法），按文号与名称实时比对来源，提示写法不规范、与来源不一致、来源已变与未登记。
- **引用面板改版**：列表只显示插入后的样子；本篇引用按文件合并，给出一键处理。源码编辑框给引用画虚线（有问题画橙色），悬停卡片可改规范写法、改来源写法、登记或打开来源。
- **校对新增引用写法必改规则**（`RULE-CITATION-NUMBER`），规范写法是确定的，给一键改法。AI 闸门与事实锁定按规范写法保护引用名称与文号，AI 改动引用即整条丢弃。

### 研究报告：文献引用重做

- **新增 `export::bibliography`**：biblatex 解析 `.bib`，hayagriva 按 GB/T 7714—2015 顺序编码制排著录（与 Typst 同库同样式），按内容缓存。
- **「文献引用」下拉照交叉引用的版式重做**：已引 / 未引两组带计数，行内序号、作者年份、题名、文献类型，悬停显示整条著录；可搜索、键盘选行、勾选多条插成一组 `[@a; @b]`，光标在已有引用里时并入那一组；底部提示缺键、`.bib` 出错行与缺参考文献区段。
- **预览排出参考文献表**：排在参考文献区段标题下（无该区段则全文末尾），序号与著录和 PDF 一致。源码里 `[@key]` 画虚线，缺键橙色，悬停弹出著录卡。
- 文档要素参考文献栏显示条数与引用统计、`.bib` 出错行，支持重新读入；审校报告 `.bib` 解析错误及行号。

### 字体：国标字面对回纸面

- **公文仿宋、楷体改用合成字体** `GWFangSong.ttf`（公文仿宋）与 `GWKai.ttf`（公文楷体）：汉字与全角标点取方正仿宋_GBK / 方正楷体_GBK，GB2312 里的全部非汉字（西文、数字、①–⒇、弯引号、破折号、省略号等 443 个字形）取仿宋_GB2312 / 楷体_GB2312，度量与方正原版一致。名字表由 `scripts/rename-merged-fonts.py` 改成新名，免得与本机装的方正原版撞名。
- 正文、表格、仿宋标题、列表编号、主送机关、括号楷体的西文数字都由字体本身给出国标字面，不再挂 `GWFangSongLatin`（移除）；页码数字仍走宋体字面。段内列表编号由解析器标出，「(1)」「（1）」这类编号不再被当成括号注释排成楷体四号（PDF 与预览一致）。
- **研究报告西文与数字一律 TeX Gyre Termes**：章 / 节 / 部分标题、目录章条目、图表题标签、文框标题、封面黑体字与小标宋大标题用 Termes Bold，正文、页码、列表序号、表头用 Regular。楷体改用公文同一支 GWKai。纸面预览新增 Termes 研究报告字体族，不再受设置页页码字体影响；公式预览的汉字回退改为方正书宋，与导出一致。
- 随包 runtime（`gongwen-runtime` v0.8.1）去掉 FZFangSong、FZKai、GWFangSongLatin，加入 GWFangSong、GWKai；`runtime/SHA256SUMS.txt`、runtime README、五个打包脚本与 `release.yml` 的字体存在性检查同步。

### 起草页与界面

- **候选区空时不再占位**：没有条目时整个面板不画，编辑区底缘不留空条；第一条候选移入后面板与状态栏入口同时出现。状态栏右侧图标随展开状态翻转，悬停文案带条数，只在源码 / 分栏两种有源码编辑框的模式下出现。
- **移除「输出 → 导出设置」入口**：按钮只会跳到设置页且不选中分区，看到的还是上次停留的位置；剩余设置项通过设置页左栏导航即可，多一个定位错的入口反而误导。同步移除 `DraftAction::OpenSettings`。
- **浮层里的列表筛少后长不回原高度**（修）：egui 浮层按上一帧尺寸给内容留地方，滚动区取剩余空间与 `max_height` 的较小者，内容一变少浮层就跟着变矮、再也撑不回去。新增 `theme::popup_scroll` 把最小滚动高度也设成 `max_height`；设置页字体下拉改用 `dropdown_button` + `Popup`，避开 ComboBox 自带、从外面改不了的滚动区。快速查找、标题聚焦编辑一并改用。
- 交叉引用与词库下拉的滚动列表改用 `theme::popup_scroll`。
