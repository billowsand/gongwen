## 公文助手 v0.6.12

本版本把 Mermaid 图表的版式与渲染链收拢到一套：原本分两套引擎渲染的七种图回到 merman 0.7 单引擎，分类色、线宽、字号在各图种间统一；起草页的 Markdown 缩略图改回按字形分段绘制，三万余字稿件每帧绘制耗时压到 0.16 ms 左右；同时完善公文写作工具的细节交互。

### Mermaid 图表：单引擎、统一风格、五种图

- **回到 merman 单引擎**。序列、甘特、饼、时间线原由新增的 mermaid-rs-renderer 接管，两套引擎配色、线宽、字号各成一路——撤掉那一套，全部交回 merman 0.7 渲染（Zed Markdown 预览同款），SVG → PNG / PDF 管线不变，画布缩放与缓存链跟着统一，缓存键 STYLE_VERSION 升到 v5。
- **五种图全部由 check 接入**：flowchart / graph（泳道用 `subgraph` 分组）、sequenceDiagram、gantt、pie、timeline。桑基图与雷达图曾接入但版式不成熟（桑基节点柱过细、雷达轴标签贴边），check 明确拒绝并提示后续开放。
- **风格统一**：框用节点线宽 + 主色边框，线用连线线宽 + 线色，标题大一档（16 px 排版），刻度小一档。甘特的关键任务改用强调色、不再填红，已完成退成分组框浅底；饼图扇区按分类色循环、不叠透明度；时间线去掉按分段上色的彩色底线、分期框同主色边框，主轴与虚线同线色线宽；序列的备注用判断框强调色，`loop` 框同子图浅色虚线。
- **分类色统一为浅中调**，覆盖饼图扇区、桑基节点、雷达曲线、时间线分区；红只留给红头、套红与修订标记。
- **甘特按版心宽排版**，`useWidth` 取版心宽换算的排版 px，字号与其他图一致；网格浅色细线、刻度默认「月-日」、隐藏随日期漂移的今天线。
- **饼图固定 450 px 高画布**；研究报告里的 md 雷达与桑基样例暂不放出。
- **菜单与设置页的「流程图样式」改称「图表样式」**，配置键 `AppConfig::diagram_theme` 不变；预览与花脸稿占位同步改名。
- **新测试**：`every_kind_follows_the_palette`（配色覆盖每种图）、甘特样例覆盖 done / active / crit。

### 起草页：Markdown 缩略图

- **缩略图改回按字形分段的色块**。真实字形缩小到 1–2 像素无法辨认，线性采样还会把笔画变成噪点，每帧复制可见行网格开销也大；改为只读共享布局里的字形位置与颜色，连续非空白字形合并成实心块：标题整行强调色加粗、正文取语法高亮色、空白处断开以保留缩进与词形。三万余字稿件每帧约 0.16 ms（原约 1.26 ms）。
- 可见框高度、缩略图与正文双击 / 拖动定位沿用既有行为。

### 工程与维护

- `Cargo.toml` 移除 `mermaid-rs-renderer` 依赖；`src/mermaid.rs` 收回为单引擎实现，导出 hook（TeX / Word / 预览）行为不变。
- 设计与测试覆盖同步重写为单引擎，新增「各图种统一」一节，记录配色、字号、线宽、作用域 CSS 与升级 merman 时须重跑样图的检查点。

### 文档

- README 校对行的文档级规则数从「20 条」修正为「25 条」（与 `src/proofread_rules.rs` 中实际 25 个 `RULE-*` ID 对齐），代码规模与测试数更新为「约 13.5 万行 Rust，1426 项自动化测试」。
- 使用帮助「校对」与「校对词表」两章同步改为「25 条文档级规则」；`assets/help` 与 `docs/help` 已核对一致。

### 质量检查

- 两平台 CI 门禁（格式、clippy、1426 项自动化测试）全部通过。
- 新增「每种图都遵循同一套配色」的回归测试（`every_kind_follows_the_palette`）。
