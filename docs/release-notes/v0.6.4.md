## 公文助手 v0.6.4

本版本让研究报告真正用上「公文版的表格规矩」：序号表、横向 `||` 与纵向 `^^` 合并单元格在研究路径下走与公文同源的编号与合并，红头呈批件续页表格按真表格分页、续页重复表头、不越过版心下沿；同时补齐 Linux 安装与启动链路上的若干「一打开就闪退」类问题。

### 研究报告：序号表与合并单元格

- **表格与公文同一套写法**。研究报告走 mdx，之前把 `<!-- [序号表] -->` 标记剥掉、表格按普通表排，跟公文对不上。这次让研究与公文共用 `NumberingConfig`：首列自动编号、分组行整行合并靠左（按设置里「序号表格分组」补 `（一）` / `一、` 之类）、表头首格留空自动补「序号」，手写 `（一）` / `1.` / `1）` 都清掉重排；合并单元格按 MultiMarkdown 写法（横向 `||`、纵向 `^^`），mdx 解析时按 `||` 紧邻、`^^` 与上方格同宽才算合并，宽度对不上的保留原文——避免手写出错时静默吞内容。
- **三处同一份编号**。编号与合并只在版式里出现，源码不写回；写源码包、TeX、Word 三条路都从 `markdown_with_frontmatter` 一处出发，在交给 mdx 前把 `NumberingConfig` 的结果写回源码（`table_markdown` 与 `parse_cells` 互逆），预览与导出来自同一份编号。标记行本身交给 mdx 不落版面，纸面上不会出现「序号表」字样。
- **TeX 端按合并单元格排**。mdx 输出的 `longtblr` 用 `\SetCell[r=..,c=..]{对齐}` 表达合并，整行合并格套 `\parbox[t]`（按首行基线对齐，避免 tabularray 2022A 触发未安装数学字体的中断）。Word 端输出 `gridSpan` 与 `vMerge`，跨列统一判定对齐。
- **红头呈批件续页按真表格分页**。原版把呈批件表格压成单行伪文本（用全角「│」拼接单元格），现在按真表格分页：表格按行切段，每段重画表头，纵向合并的几行不拆开、绝不越过版心下沿、不进首页批示窄栏。40 余行的大表实测一页放不下就在行间断开。

### 应用崩溃诊断

- **崩溃原因落到磁盘上**。桌面双击打开没有终端，panic 或窗口建不起来只表现为闪退，原因全丢。本版在 `main` 入口最开头装 panic hook，把版本号、系统、图形会话环境变量、出错位置与调用栈写到配置目录的 `logs/crash-<时间戳>.log`（最多留 20 份）；`run_native` 返回的启动错误同样记录。下次启动在状态栏提示上次的崩溃日志路径，只提示一次。
- **帮助附录 B 新增「一打开就闪退」**，并更正数据章 Linux 配置目录为 `~/.config/gongwenassistant/`（与代码本体一致，旧文沿用 XDG 默认路径名）。
- **`smoke-launch-linux.sh` 检测到崩溃日志即判失败**并打出内容；`ci.yml` 与 `release.yml` 在 Ubuntu 20.04 实装 deb 后用 Xvfb 真正启动一次，窗口出现且无 panic 才算通过——把「dlopen 的库缺失、GL 上下文建不起来、首帧 panic」这一类一打开就闪退的故障挡在 CI 里。

### 标题断行

- **词性打分的全局最优分行**。公文标题在 jieba 词边界换行的同时补齐回行规矩：标点不落行首、开括号 / 开引号不落行尾、短括注（≤ 12 字）整体不拆、`的 / 之 / 等 / 了` 不起行、`第` 与数字、数字与量词不分家；断点打分按词性——「的」之后与连词介词之前最好，名词接名词（多半是复合词）最差，西文空格是天然断点。
- **分行：在最少行数与多一行之间穷举**，代价 = 断点分 + 各行偏离平均的总量 + 多一行罚分；同一行数内「首行不短于末行」优先。原先的逐行贪心在长括注前后会排出空行，一并解决。
- **封面题名三处同断**。研究报告封面题名（一号字、题名框 150 mm、每行 16 字）由公文助手按同一套规矩算好分行，经 frontmatter「题名分行」传给 mdx：TeX 以 `\\` 换行、Word 用行内换行符、预览直接调同一个函数，三处断在同一处；题名改过而分行不匹配时回退整段自动折行。

### 研究报告封面（已在 v0.6.3 末段上线，本版随表格改动把文档同步跟上）

七种文件类型共用一张 A4 封面网格（页边 25 mm）：密级与编号、文种、标识行、通栏反线、题名与稿次、专属信息格、落款，位置字号一致；项目类（立项论证、建设实施、技术实现、项目总结）单反线 + 落款上方四格阶段条（当前阶段加粗），研究类（战略咨询、专题研究、外文翻译及其余）一粗一细双反线 + 落款上方署名行；公开件不标密级，稿次加全角括号，日期写成汉字数字（二〇二六年九月）。研究报告放开 Word 导出，走 mdx research 转换器。`docs/help/05-profiles.md` 已同步更新。

- `ci(release)`：新增 `scripts/verify-deb-install.sh`，在干净的 Debian buster / Ubuntu 20.04 / Ubuntu 24.04 三档系统里实装打好的 deb、ldd 检查主程序与 tectonic 的依赖；release 任务依赖矩阵任务，包名写错或 glibc 过高直接失败。

- `fix(deb)`：Depends 写成新旧包名二选一（`libgdk-pixbuf-2.0-0 | libgdk-pixbuf2.0-0`、`libgcc-s1 | libgcc1`），修复麒麟 V10 装不上；dpkg-deb 固定 `-Zxz`，新版默认 zstd 与 buster 自带的 dpkg 不兼容的问题同步修。
