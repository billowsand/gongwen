## 公文助手 v0.5.2

本版本让生僻字不再从纸面上消失，把研究报告的标题编号在三端对回纸面，并改版词表与校对页；README 也重写为面向读者的版本。

### 字体：生僻字兜底

- **「喆」「赟」「堃」这类字不再丢字**。仿宋_GB2312 与楷体_GB2312 只有 GB2312 的 6763 个汉字，人名里的生僻字在它们上面没有字形：此前 PDF 照样生成、纸面上却少一个字，日志里只有一行 Missing character，预览则是一个方框。现在类文件开 `\xeCJKsetup{AutoFallBack=true}`，给八个 CJK 字体族声明后备字体，默认用随应用分发的内置宋体（覆盖 GBK 全部 21791 个汉字）；研究报告的排版后备用书宋（它的标题字体方正小标宋同样只有 GB2312 字库）。不增加打包体积。
- **设置 →「公文编译字体」新增「兜底字体」**，可另选本机字体，用来排 GBK 以外的字。这一项不受「使用本机字体编译」开关约束——它决定的是一个字排不排得出来，不是版式；所选字体漏掉的字仍由内置宋体接着兜。
- **预览同步兜底**：每个公文字体族末尾都挂上兜底字体，egui 逐字回退，屏幕上看到的和编译出来的 PDF 是同一支字体。顺带给字体加载加了按文件去重，同一份字体只在内存里留一份（加粗与一级标题、兜底与页码常是同一支）。
- **修掉两处路过发现的 TeX 钩子缺陷**：加粗钩子把带 `##` 的 `\renewcommand` 直接写进 `\AtBeginDocument` 的参数，LaTeX 2020 起的钩子不做 `##` 归并，执行时留下一个裸的 `#`——选「使用专门的粗体字体」时编译必然失败；改为先 `\def` 再由钩子调用。两处钩子用 `\ifx\GwaFontPath\@empty` 判空，而 `\providecommand` 声明的空宏是 long macro，比较永远为假，导出的 `.tex` 拿到别的机器上会误入按文件加载的分支去找并不存在的字体文件；改用 `\detokenize` 判空。

### 研究报告：编号与导航

- **标题编号三端统一到纸面**。同一份稿子此前几个号：版式预览与 TeX 排「第1章」，DOCX 排「第一章」，右缘导航拿公文那套计数器排「一、」。现在章号统一用阿拉伯数字，DOCX 端去掉 `chinese_chapter`（`number_to_chinese` 仍归公文用）；章标题字号回到小二（18bp），与封面上那个二号的「研究报告」拆成两个常量；章号与章名的间隔改成 ctex `chapter/aftername` 的一个汉字宽，节号那档改用半角空格，此前两档都用全角，"1.1" 后面宽出了一倍；DOCX 的附录标题同样改成「附录A　」。
- **导航不再自己算号**，改由新增的 `preview::research::outline` 复用排版那一遍遍历：纸上印什么，刻度上就写什么。
- **标题里的交叉引用与文献引用改成纸面编号**：「1.1 相关工作，见第1章 [1,2]」，不再把内部 id 与 BibTeX key 整段抹掉。
- 导航条目的字体改由收集方指定：两套模板的层级含义不同，同样第 3 级在公文是楷体、在研究报告是黑体。

### 词表与校对页

- **词表页改版**：标题后面那串顿号连成的小字拆成概况卡——总词条、已接受、待确认、已拒绝、已扫篇数各占一格，待确认单独着色；词表上千条时，这一页唯一要盯的数就是它还剩多少。导出卡的结果改成几枚标签（每轮省键、重码、截断、编码失败），补救办法留在悬停里，原先连排四段的红字只剩一条色条提示。
- **筛选与来源收进分段选择器**，搜索框、加词框与同行按钮严格等高；校对词表页同样加概况卡（全部词条、启用中、自建、已改内置），「常被忽略」「不再提示」两条需要动手的提醒收进 `theme::notice`。
- **修掉字体下拉的筛选框点不进去**：默认的 `CloseOnClick` 把弹层里任何一次点击都当成「选完了」，点进筛选框的那一下就先把弹层关掉；改为 `CloseOnClickOutside`，选中后由 `ui.close()` 收尾，弹层打开即聚焦筛选框，改筛选词后列表滚回顶部。
- `theme` 新增 `CONTROL_HEIGHT` 与 field / caption / metric / divider_v / hairline / notice / segmented 一套常用件，并把 `interact_size.y` 提到控件高度：egui 拿它当横向布局的行带，默认的 18px 兜不住中文行高与 5pt 按钮内边距，矮的控件会被顶到行的上沿。
- **修掉标签的关闭按钮被行带顶到右下角**：行带高度提到控件高之后，普通按钮的 `min_size.y` 被拔到 30px，超出标签内区便按行顶对齐，`×` 压到右下角，横向流里的 `item_spacing` 又把它右推 4px、与悬停判定区错开；改为把按钮放进钉死在关闭位上的子 Ui，并用 `.small()` 跳过拔高。

### 预览

- **源码行的底色照字框取中**，不再贴着字的上沿。egui 把基线钉在字体 ascent 上，「行距减字高」的余量整块留在字的下面，底色照行框铺满时下面会空出小半行色带；新增 `row_tint_offset` 按这一行真正的字框算出上提量，普通预览、红头预览与源码片段三处统一走它。
