## 公文助手 v0.4.3

本版本把预览右缘的导航重做了一遍——分条底衬换成一块定宽的「亚克力板」，指针划过时整列字号不再忽大忽小，字体也跟着公文层级走；并修掉悬停高亮压住首行缩进两个全角空格的老毛病。

### 预览导航

- 分条底衬换成一整块板：圆角、一道极淡的描边、向左下的投影，底色压到 0.94 把正文挡住，板上撒一层颗粒补材质，四边收边免得漏到圆角外。原先每条标题各带一条底衬、各有各的左缘，长短不一的标题排下来左边是一排参差的舌头，越往外越碎。
- 板宽定死不随最长的标题走——宽度跟着内容变的话，焦点在长短标题之间跳一下，左缘就跟着晃。淡入时整块从右缘滑出 16pt，是「推出来」而不是凭空浮现。
- 条目文字改左对齐并按层级缩进：右对齐是分条底衬时代的产物，那时右边是唯一一条直的边；板铺开后左缘才是那条直边。
- 可点范围从「文字那几个字」扩成整条横带——板是不透明的，板下的正文本来就选不中，再让行间空档穿透只会造成点了没反应。横带到刻度带左缘为止：刻度那一条仍归刻度，它答的是「文中什么位置」，与大纲的第几行不是一回事，盖住就会出现指着这条刻度、跳到另一条标题。
- 去掉导航列的按指针远近放大：指针沿刻度带划过去，整列的字忽大忽小，看着晃眼，而且被放大的那条未必是要找的那条，眼睛还得在变动的字号里重新定位。大纲是照着往下读的，读的东西不该在读的时候动。现在字号只是层级的函数，一次列出全篇；指到哪一条由底衬高亮说明，正在读的那一节用主色标出来。
- 装不下时才滚：绝大多数公文装得下，整列居中、指针怎么动都一帧不动；排不下才把指针就近认到的那一条带到刻度带正中，整列夹在两端之间，滚到头就停住，不会在上下留出空板，滚动带插值。排不进板的行整条不画，不让半截字切在板沿上。刻度仍覆盖全篇，再长的稿子每一条也都够得着。
- 修：原先整列内容依赖 `focus`，指针一移出预览区它就变回 `None`，板是当场消失而不是淡出。

### 导航字体与底衬

- 导航字体跟公文走：二级黑体、三级楷体、更深仿宋，取自版式预览的 `heading_family`，文档标题与附件标题用方正小标宋。不另立一份映射——两份迟早走岔，而走岔的表现是导航里「一、」是黑体、纸上却排成楷体。公文的层级本来就靠字体区分，字形对上，层级不读字也认得出来。字号比用界面无衬线时整体抬了半档，楷体、仿宋的笔画细得多。
- 长标题不再被正文透穿：底衬原先只有一层薄色，横向渐变按整列的包围盒归一化；长标题把包围盒往左撑宽之后，靠左那几个字正好落在渐变最透的一端——那里的不透明度是零，等于没有底衬，正文直接从字缝里透上来，标题越长糊得越厉害。现在渐变按每一行自己的长度算，拆成三层：
  - **薄雾**：整列一层极淡的底，只负责把标题列和纸面分开一层。
  - **行板**：贴着每行文字自己的左端铺，字的正后方压到 0.93，只在文字以外才向左化开；相邻两块以中点为界首尾相接、强度取两行的平均，整列的浓淡连续变化，不会在焦点行与邻行之间横出明暗台阶。
  - **颗粒**：一张固定种子的 64×64 灰噪声平铺其上。纯色半透明看着像塑料贴纸，有颗粒才有材质感。
- 外圈各档同时逐档收窄，只有焦点那条用满宽；文字的透明度梯度抬了一档，行板的强度按开方取，所以外圈的字可以淡到快看不见，底下的板仍挡得住正文，不会变成和正文搅在一起的灰影。四边仍旧是化开的，「没有边框、浮在纸上」没有丢。
- 说明：这仍不是真的毛玻璃——egui 取不到已画好的画面做高斯模糊；但让人看得清的是底色和颗粒，模糊只是锦上添花。

### 预览高亮与首行缩进

- 修：悬停与命中高亮原先按整段命中范围画底色，首行缩进的两个全角空格也在范围内，行首因此拖出一截空框。新增 `first_ink` 找出一行里第一个非空白字形，命中与点击范围照旧，只有底色从第一个实字起笔；六文种正文段落与红头呈批件打印页两条逐行高亮路径都接上。
- 标题与编号列表原先走整块矩形高亮，同样盖住缩进：改由新的 `clickable_content_block` 统一分发，段落、标题、列表按行贴着文字高亮，表格与图片等图形块仍按块矩形。`heading_job` 从 `heading_block` 抽出复用，避免标题编号计数器跑两遍。

### 测试

- 导航集成测试改成钉「稳」：指针停在刻度带上方 15% 与 85% 各跑一遍，同一条标题的行高必须分毫不差。
- 导航单元测试钉字号只依赖层级、大纲短稿恒定而长稿夹在两端、横带无缝铺满板面且不侵占刻度、字体逐级对上纸面。
- 底衬新增两条测试钉住回归点：无论标题多长，第一个字的正后方必须是满强度；最外一档的行板不得淡到挡不住正文。
