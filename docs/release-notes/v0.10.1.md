## 公文助手 v0.10.1

本版本给**排版补上一件欠了几版的东西**——图与表的题注现在自动流水编号，公文与研究报告同一写法，预览、Word、PDF 三端共用一次编号分配；**材料检索不再依赖模型**，知识库新增本地全文检索，不配模型也能按关键词翻原文、看高亮、复制片段；编辑器补齐表格内换行、列表层级 Tab 与行首点号三处手感问题；输入法的找字面板按层次重排，候选来源的四角星换成业务词加粗。

### 排版：图表题注全文流水编号

- **公文六个文种有图表题注了**：表题写在表格紧邻的一行（`表：题名`），排在**表上方**；图题写图片的替代文字，Mermaid 图写在结束围栏下一行（`图：题名`），排在**图下方**；黑体标签加仿宋题名、四号居中。新增 `src/export/caption.rs` 做**一次编号分配**，预览、Typst PDF、Word 三端共用同一份结果，不再各排各的。
- **表与图各自从 1 起全文连续编号**，不按章节。研究报告废除原先的 `1.1` / `A.1` 章节式编号，交叉引用显示自动跟随；没写题注的表和图不编号、不占号；题注里手写的旧编号（「表1」「图 1.1」）会被剥掉重配，不会和自动编号叠在一起。
- **Mermaid 物化的矢量图也编号**：先前按「PDF 附件」规则被跳过，现在正常参与编号；物化与插图解析统一按 base 目录走，图不再因为相对路径不同而丢。
- **修掉表题不居中**：表题块原先没占满版心，居中等于相对半行居中，题名短时明显偏左。
- 技能包（`markdown-syntax.md`、`research-report.md`、`SKILL.md`）、提示词与 `docs/typst-engine.md` 同步这套规则；旧稿里手写的题注编号不用改，导出时按新规则重编。

### 知识库：无需模型的本地全文检索（新增）

- **不配模型也能查原文**：知识库新增独立的 SQLite FTS5 表 `knowledge_local_fts`，导入时自动建索引，旧材料在打开知识库页时后台补建（进度走原来的知识库任务条），第一次搜索还会再检查一遍缺失项兜底。「全文检索」按钮与 `Enter` 走本地路径，原语义检索改为显式的「语义检索（需模型）」，问答流程不变。
- **中文按词与字一起收**：每篇全文按 jieba 分词建索引，另补**连续汉字单字与二元组**，专名内部和分词边界都不会漏；分词候选逐个加引号后参数绑定查询，用户输入不会被当成 FTS 运算符。
- **多词、短语各有规则**：空格分隔的几组要求同时命中，汉字组内允许部分词命中、按 BM25 排序；纯英文与文号这类编号组要求各词同时命中；**双引号包起来按连续短语核验**（先按原文核验再截数量，不会先 LIMIT 后过滤导致漏搜）。最多返回 50 篇。
- **高亮落在原文上**：命中片段从原文字面匹配算出来，不用分词偏移，英文按 ASCII 大小写不敏感；定位不到的词不伪造高亮。结果可复制片段、打开只读原文并跳到命中处，或另开全文版式预览。
- **查询与过期结果**：查询最长 256 个字符，检索、分词、索引补建都在后台；输入或文种过滤一变就清空当前结果，晚到的后台结果按 `query + kind` 丢弃。
- **索引与向量互不牵连**：本地全文索引与 `knowledge_chunks`、向量 BLOB、embedding 状态完全分开，重建向量覆盖不到它；删文档由触发器清条目。

### 编辑：表格内换行、列表层级与行首点号

- **表格单元格里按 `Enter` 换行**：光标在实际单元格内按回车插入 `<br>`，仍留在同一格，**一次 `Ctrl+Z` 就能撤销**；`Shift+Enter` 仍插入 Markdown 源码换行。分隔行、表格边界与输入法组句 / 确认不由这条快捷键接管，用系统输入法与内置输入法都不会误插换行。
- **空编号与空标题用 Tab 调层级**：写完 `1. 第一项` 回车得到空 `2. ` 后按 `Tab` 变成第一项的子项，输入内容回车继续同级；空子项按 `Enter` 或 `Shift+Tab` 提升、顶层空项 `Enter` 退出，后续同级编号跟着调整，一次 `Ctrl+Z` 恢复整次动作。空 `## ` 标题按 `Tab` 成为 `### `、`Shift+Tab` 提升回来，主标题不参与，最深到 `#####`；非空正文、段内编号与代码围栏里不触发。
- **行首数字后自动补半角点号**：在行首写 `1`（可带空格或 Tab 缩进、1–9 位数字）再打全角「。」或「．」，入库就是 `1.`，不用切输入法；正文句号、小数（`1.2`）、日期与十位以上数字不动，代码围栏内也不动，数字与点号在同一个事件还是分两次上屏都能认出来。

### 输入法：找字面板重排与业务词加粗

- **扩展选词面板分出了层次**：还要打的码从「像注音一样压在字上方」改成字**右上方的独立标签**，格与格之间加行线，表头显示「单字候选」与收起箭头，底栏显示候选数量与操作提示（窄面板只留数量）；选中与悬停分开着色，数字键仍按高亮所在行选，四行可见、翻页与上屏规则不变。
- **网格宽度把滚动条算进去**：列宽按全部候选里最长的辅码量定，出现滚动条时列不再跳变；表头与网格不再互相撑宽。
- **来源星标改为业务词加粗**：普通候选条（横排、竖排）与找字网格不再在词后画来源四角星，改为**仅加粗扩展候选文字**——公文词表、导入表与个人词条沿用原来的来源判定，同码同词既在基础表又在扩展表时仍加粗。序号与简码提示不加粗，完整来源继续在悬停说明里看。
- **加粗不换字体、不加宽**：沿用预览那套合成粗体做法，同一个字形向右微移 0.4 倍缩放叠绘，字号与主题缩放跟着候选字号走，候选不会因为加粗而错位或撑开。

### 发布与打包

- **本机打 Arch 包一条命令**：新增 `scripts/package-arch-local.sh`，在 Arch / Omarchy 上依次跑「编译（`linux-portal-dialogs` 变体）→ 组装便携目录 → `makepkg` → `pacman -U` 安装 → 静态校验」，口径与 CI 的 Arch job 一致，依赖名由 `pacman -Qoq` 反查；已装同版本时自动把 `pkgrel` 加一（可用 `GONGWEN_PKGREL` 指定），否则 `pacman -U` 会因版本相同直接跳过。提权优先免密 `sudo`，没有就走 `pkexec`。
- **macOS DMG 打包脚本修一处 `set -u` 崩溃**：`/bin/bash` 3.2 在 UTF-8 locale 里会把紧接变量名的全角标点吞进变量名，`"$var（"` 直接报 unbound variable，打包在 SHA-256 校验一步就中断；改为 `"${var}"` 写法（`package-dmg.sh` 4 处、`package-deb.sh` 1 处），输出与行为不变。
