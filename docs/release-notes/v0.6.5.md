## 公文助手 v0.6.5

本版本把「版本变更与花脸稿」改造推进到第 ③ 期：起草页的版本对照变成**左栏可编辑统一 diff + 右栏花脸稿预览**，改稿痕迹改为**红色直删除线 / 蓝色方框就地标注**，每个变更块可以一键还原。同一版里还落地了网络代理、AI 技能包、PDF 查看器单页翻页、正文居中 / 居右、导入编码自动识别等一批用户可见能力。

### 版本对照与花脸稿（第 ① — ③ 期）

- **花脸稿改为就地标注**。删掉的字**留在原位画红色直删除线**（`#C00000`，字本身也染红），新增的字**就地套蓝色方框**（`#1F4E9E`、0.5pt，框内保持正文色）；新增框**随正文断行**（跨行在行尾开口、整段新增只在首尾各一笔竖边）。删除的标题、列表项不再排成标题 / 列表行，避免自动编号重复。预览、Word、PDF 三端样式一致，并有「预览片段序列 = DOCX run 序列 = TeX 片段序列」的三方一致性测试锁住。
- **新增视觉 diff 引擎**（`src/visual_diff/`，纯函数，不碰存储与 UI）：jieba 分词，日期、数字 + 单位、文号、公式各作一个整体 token；先抵消相邻「删 X、增 X」，再按区域吸收夹缝、在句读处切开、做整句归并；段落移动识别并出「移来」注记；标题与列表编号不参与比较；表格逐格 / 整行 / 整表；公文要素整体替换。除逐条规则的单元测试外，另有生成式不变式——400 组真实公文句子随机增删改，逐字核对「去新增 == 旧版、去删除 == 新版」。
- **版本对照视图重做**。左栏**既是编辑器也是 diff**：删除 / 被改写的旧行以红底只读行画在原位（布局器在 `TextEdit` 的 galley 里开空隙塞进去），新增 / 改写后的行铺绿底，真正改掉的字再加深；行号槽写新 / 旧行号与增删色条；只改空行也算一处变更，显示淡色「（空行）」。每个变更块右上角出「**还原**」，一键换回基准版内容，`Ctrl+Z` 一次撤回。右栏是**花脸稿预览**，与导出 PDF / Word 吃同一份带哨兵 Markdown，「预览 = 导出」由构造保证。
- **两栏联动与工具栏**：点左栏变更 → 右栏滚到对应块并常亮，双击切回 Markdown 源码定位；点右栏带标注的块 → 左栏聚焦；悬停互相淡色高亮；`F7` 下一处、`Shift+F7` 上一处，首尾循环。工具栏含基准版下拉、`共 N 处变更`、`第 X / N 块`、**回退到基准版**（二次确认）、**导出花脸稿**、**打印预览**（后台真编译 PDF，用内置查看器打开，不在导出目录留文件）；左栏顶部另有「要素变化」卡片。**已发布 / 归档的稿件只读**，左栏换成只读统一视图（多一个「折叠未改动」，导航按行计）。
- **边改边看不卡**。基准快照与备注只在换稿件 / 换基准版时读一次库；代码 diff 按正文哈希与要素变化重算；花脸稿首帧同步算，之后后台线程 + 150ms 防抖，结果按「稿件 + 基准版 + 正文哈希」收取，过期结果丢弃。2000 段、100 个变更块的实测：进对照模式首帧 255ms（提速前 13.9s），打字帧中位 22ms。
- **一轮真实稿件实测后的修正**（括号里是新增的回归测试）：移动识别混用下标导致越界闪退；研究报告 TeX 后处理的「新增里带行内公式编译失败 / 加粗只粗第一个字 / 改过的独立公式印出源码」三处；删除侧的公式被转义成字面字符；研究报告 Word 标记在加粗、公式处中断；PDF 里删掉的字是黑色；加 / 删一个标题把下面没动的正文整段删了又加；远处删一段与增一段被拼成一处整句替换；新增框竖边与字断开到两行、四角合不上。

### 网络代理

- **设置页新增「网络代理」分区**（智能助手组）。起草、文字复核、知识库 embedding / rerank 与模型探测统一走 `src/net.rs` 构建的客户端，代理只在一处生效。三种连接方式：**直连**（环境变量也不认）、**跟随系统**（默认，先读 `HTTPS_PROXY` / `HTTP_PROXY` / `ALL_PROXY`，没设再读 Windows 系统代理；不支持 PAC）、**自定义代理**（`http`、`https`、`socks4`、`socks4a`、`socks5`、`socks5h`，可带用户名密码，另有「不走代理」的域名 / IP / 网段列表）。
- **本机地址始终直连**（`localhost`、`127.0.0.0/8`、`::1`），本地 LM Studio / Ollama 不受代理影响；自定义代理没填地址时直接报错，不静默退回直连；代理改完不必保存就能点「测试连接」验证。设置版本对比里地址中的密码打码。

### AI 技能包（Agent Skill）

- **把起草页的 Markdown 公文子集、七种文种的正文规则、行文规范、各文种模板与一个自检脚本打成 `gongwen-markdown` 技能包**，装进外部 AI 工具后，它们写出的 `.md` 可以直接粘到起草页，预览与导出与手写稿件完全一样。设置页「上手指引」可导出单文件 `gongwen-markdown.skill`（zip）或技能文件夹，安装包里也随附一份（macOS 在应用包的 `Contents/Resources/skills/`）；帮助文档给出 Claude Code、Codex、OpenCode、pi 等工具的 skills 目录对照表。
- 文档锚点语法改为 `{#id}`、行内脚注改为 `[^id]:(内容)`；`skill_pack::FILES` 登记新增文件，测试检查文档与清单两边一致。

### 研究报告：目录与页码

- **目录改由 `<!-- [目录] -->` 标记触发**（研报分区新增「目录」按钮，已在稿中则不重复插入），排在标记所在位置、另起一页，**单用大写罗马页码 I、II、III**，不占正文页号。目录插在摘要与正文之间时，**摘要改用小写罗马页码 i、ii、iii**，目录之后正文从 1 起；目录在最前时正文从 1 起；目录在正文中间时接着目录之前的页号数。AI 润色提示同步要求原位保留目录标记，公文路径忽略该标记。
- **Word 版补齐页码**，与 PDF 同一套分节编号：封面不编页码，各节页脚居中「— N —」（四号），目录大写罗马、摘要小写罗马、正文阿拉伯；目录改写成段落里的 TOC 域（打开后按提示更新域即可生成条目）。目录在正文中间时页码靠域公式接续，Microsoft Word 能正确显示，LibreOffice 等不支持嵌套域公式的软件显示不对。

### 排版与编辑器

- **正文支持居中与居右整行标记**（`<!-- [居中] -->` / `<!-- [居右] -->`，也认 `右对齐` 与英文 `center` / `right`）：标记下方**直到空行**为止逐行成行、不缩进，只认行内格式；功能区「格式」分区新增「居中」「居右」按钮，选中几行即插标记、再点取消，光标在区内按钮亮起。预览、Word、PDF 三处排法一致，各文种（含红头呈批件、研究报告）都支持。
- **研究报告导出支持反斜杠转义**：`\_`、`\*` 不再印成 `\textbackslash{}`，`\$价格$` 不再被拆成多余反斜杠加一个公式；行内公式的配对规则与起草页预览对齐，行内 `$$x$$` 整体按文本处理。anydoc 0.2 导入的 Word 正文带 `\$` 这类转义，此前最容易碰到。
- **anydoc 升级到 0.2.4**：导入 Word / PowerPoint / OpenDocument / RTF 时公式转成 `$…$` 行内与 `$$` 块（0.1.7 整个丢掉且不报错，正是研究报告支持的写法）；表格数字按单元格显示格式输出（`0.1234` → `12.3%`、`25000` → `25,000`）；Markdown 转义更克制。

### PDF 查看器

- **新增单页翻页模式**，与「连续」并列：一屏一页，**窗口够宽时从左到右并排多页**（最多 6 页），翻页按整屏步进。触控板滑过一格才翻页（零头会清掉），鼠标滚轮一格一页，另有 `PageUp` / `PageDown` 与方向键；翻页后短时间内屏蔽残余平滑滚动，免得新页一出来就被余量带着走。
- 渲染仍是多线程：文件只读一次、解析惰性，一页要一两秒的重页不堵住后面的轻页；纹理总量设上限（256 MiB）并按最近使用淘汰，138 页的扫描件不会把显存吃光。

### 导入与工程

- **外部文本文件自动识别编码**：有 BOM 按 BOM（UTF-8 / UTF-16LE / UTF-16BE），整份是合法 UTF-8 就按 UTF-8，否则交给 `chardetng` 判定（顶级域提示给 `cn`，GBK 与 Big5 拿不准时偏向 GBK）。导入 txt / csv / md、研究报告文件夹合并、frontmatter 与表单里选的 BibTeX、知识库 Markdown 导入、辅码表导入都走这里——GBK、UTF-16 的老文件不必先另存为 UTF-8。程序自己写出的配置、TeX 与埋点仍按 UTF-8 读，不被「猜」掩盖真损坏。
- **校对提速**：字面词条按写法去重后编成 Aho-Corasick 自动机，正文只扫一遍即拿到全部命中，同一写法挂多个条目时逐条过前后文条件；结果与逐条扫描逐项一致（新增以旧实现为对照的 matcher 测试），自动机构建失败时退回逐条扫描。
- **版本 diff 提速**：手写 LCS 换成 `similar` 的 Myers 实现（线性内存，每次设 200ms 期限），删掉 O(n·m) 二维表与「超预算整段退化成删 + 增」的分支——长段落上也只标真正改动的字。
- **本地 post-commit 钩子**：`scripts/install-git-hooks.sh` 装好后每次提交自动跑 `cargo build --release --locked`（Linux 主机自动加 `--no-default-features --features linux-portal-dialogs`），失败只告警不阻塞提交。
- `fix(scripts)`：打包脚本在缺 `Get-FileHash` 的精简镜像（本机 PowerShell 5.1 就是）上加 .NET SHA-256 兜底，并给脚本加 UTF-8 BOM，避免 `-File` 模式下按无 BOM 解析报错。
- `feat(ime)`：新增 `ime-builtin-xiaohe` 编译开关（**默认关闭**）。开启时设置页「输入法」多一个「使用内置示例小鹤辅码」按钮，按下弹二次确认、明确告知版权约束并要求使用者声明已从方案作者处取得授权，确认后才复制到配置目录并加载，绝不在启动时自动加载。**对外发布的构建仍不含辅码表**。
