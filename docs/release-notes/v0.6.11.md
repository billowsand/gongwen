## 公文助手 v0.6.11

本版本把预览与导出的版式细节对齐到一处：标题、附件标题、居中表格格按导出规则分词均衡换行，多出 1–2 字时按字形横向压缩保持单行；红头呈批件、白头件补上双面打印页码，红头呈批件联系人姓名在导出件里留空供手写；起草页加上了选中文字拖动与落点提示，公函与红头呈批件的几处与 TeX 不一致的版式一并修正。

### 预览：标题、附件、表格格的换行与压缩

- **按导出规则分词均衡换行**。预览判定直接调用 `export::title` 的 `title_plan` 与 `cell_plan`，主标题、附件标题、红头呈批件首页窄栏标题与居中表格格都按版心宽度（标题）或导出智能列宽（表格）判定，断行处与 Word / PDF 一致，不再各排各的。
- **居中表格格抽出共用判定**。`export::table::centered_cell_plan` 给 TeX 与预览共用，姓名列的判定 `name_column` 给 Word 与 TeX 共用；`TableColumn` 带上导出列宽 twips，预览不再从比例反推。判定结果按内容缓存，避免每帧重跑分词。
- **多出 1–2 字横向压缩字形**。egui 字体没有原生横向缩放，`fit::squeeze` 把排好的 galley 按比例收窄（字形网格、字位、行宽、外框），以中线为不动点，压完仍居中；底色、花脸稿标记、点击命中读同一份收窄后的 galley。压缩比例取导出的 `compressed_scale_percent`，主标题、附件标题、红头呈批件首页标题与居中表格格均生效。
- **预览三号字按 15.75 bp 排**。与 `gonghan-gwa.cls` 的 `\zihao{3}` 与版心 156 mm 对齐，恰好容 28 字一行，与 TeX / Word 完全一致；之前 16 pt 每行会少一个字。

### 红头呈批件、白头件：双面打印与联系人留空

- **红头呈批件、白头件补上双面打印页码**。导出（Word / PDF / TeX）与预览一致按 GB/T 9704—2012 编排，双面时奇偶页码分置外侧；白头件要素表单里新增「打印方式」选项（单面 / 双面），与红头件共用同一开关。
- **红头呈批件导出时联系人姓名留空**。TeX 与 Word 导出不印联系人姓名，联系人栏加宽到 9 em，联系人与电话之间留出手写空位；预览仍显示所选联系人，方便经办人核对。同步更新帮助说明。

### 公函与红头呈批件：版式细节

- **公函抄送区按真实行高排版**。多行抄送时第二行不再压在细线上；「（共印 x 份）」按三字符悬挂缩进排抄送，最后一行放不下时另起一行，与 TeX 一致。
- **红头呈批件落款单位分散对齐到 5 字宽**。少于 5 字的落款单位字间留空；成文日期居中于「落款单位 + 签字空间」整段，不再偏左。
- **红头呈批件预览补上附件的 `#` 标题**。此前附件正式标题不显示，与白头件不一致。
- **红头呈批件补上 Markdown 选区到预览的文字高亮**。按避头尾插入的硬换行剔除后再映射，避免每行漏掉一个字。

### 起草页：写稿工具

- **选中文字拖动与落点提示**。源码编辑器里选中的文字可直接拖到别处：按下后短暂停顿再拖，原选区随鼠标移动，鼠标下浮出一张摘录小卡把拖的内容显示出来作为落点提示；松开时若落点在编辑框内的某行行间空白，就地插入，被拖走的文字从原处移走；落在原选区内（含两端）则不改正文。实时排版模式的软换行与可见区域外侧都按鼠标位置就近落点，跨行拖动不会塞进错位的字符。`Ctrl+Z` 整体撤销。
- **查找替换条开着时不再把光标锁在命中处**。原先每帧发现高亮不是当前命中就重新选中命中，点击别处也被抢回；现在只在命中序号、查询词或大小写 / 正则开关变化时才重新选中。
