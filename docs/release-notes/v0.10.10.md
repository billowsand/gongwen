## 公文助手 v0.10.10

本版本新增外设安全感知与紧急锁定，加入经认证的 IS903 与实体光盘交付，并集中加固稿件管理。

### 外设安全感知与紧急锁定

- **环境安全检测收敛为外设感知**。监测设备到达、介质就绪、功能变化与移除，按移动存储、便携设备（WPD / MTP）、HID、图像采集与其他外设分类，复合设备逐功能判定；存储必须有实际可读介质，空读卡器、空光驱与内部磁盘映像不算移动存储。设置页可只观察，也可强制锁定。
- **网络采集与网络策略已移除**。平台后端不再订阅或枚举网卡、链路、地址与路由，设置页撤掉网络策略、网络状态与对应锁定原因；联网、切换 Wi‑Fi / VPN、调用内网或远程模型都不再影响准入与外设检测。
- **命中策略即刻遮蔽正文并锁定**。违规在绘制与分发输入前处理：先遮蔽窗口、停止工作区交互，再取消可取消任务、收敛后台终态、保存已有修改，最后释放工作区与密钥句柄；保存失败时持续遮蔽并自动重试，可二次确认退出（明确放弃未保存修改），或验证访问密码后把策略回退为默认关闭。拔掉违规设备后仍需重新输入密码解锁。
- **IS903 授权只豁免唯一匹配的移动存储功能**。同一设备新增的 HID、便携设备等功能仍按各自策略检查；普通外设不会因为升级时已插入或曾在观察阶段出现就自动获得授权。
- **默认关闭，且只在启用应用锁、数据库加密已生效的工作区可以开启**。旧配置里的网络策略字段兼容读取并忽略，后续保存不再写出。首批先在只观察状态验证本机键鼠、扩展坞、读卡器与光驱，再决定拦截范围；三平台真实外设热插拔、休眠唤醒与联网模型调用的联合验收仍待完成。
- Windows 的窗口捕获排除继续作为可选项独立生效，运行期间每 5 秒复核，保护被移除即触发锁定。

### 光盘与 IS903 交付

- **加密工作区可直接交付到认证 IS903 或实体光盘**。起草页导出新增设备入口，成品与 ISO 9660 / Joliet 镜像全程在内存，不留明文刻录临时文件；空白 CD-R、DVD-R、DVD+R 单会话封盘，回读验证成功才报告完成。
- IS903 在「设置 → 导出格式」按工作区认证，选择介质与写入前都重新检查授权。macOS 需单独安装签名并公证的 `gongwen-is903` 助手（`scripts/package-macos-is903.sh`），Linux 包安装专用助手并声明可选运行依赖。
- **修正 Windows 烧录成功判定**。以 `IDiscFormat2Data::Write` 成功为准，不再用封盘状态位把已写好的盘误报为失败；写完设备重新枚举时改用只读句柄复检并回读，未通过时明确提示「已写入，但回读校验未通过」。
- 打包把 IS903 助手改为硬链接：Arch 包从 193 MB 回到 141 MB，安装占用从 526 MiB 降到 398 MiB。

### 稿件管理

- **大附件与导入导出加固**。归档与添加 PDF 附件改后台读取，统一 100 MB 单件、512 MB 合计上限并校验 PDF 文件头；稿件包导入确认与导出准备移到后台，导入附件去重不再逐个重复读 BLOB，导出用只读快照固定内容。
- **版本与归档更稳**。导出前固化同步检查点，避免后台快照写库与多机往返丢共同祖先；归档与全部 PDF 附件在同一个 SAVEPOINT 内完成，任一附件写入失败就整体拒绝，不留半归档状态。
- **删除与列表**。删除稿件时把未保存新稿正文纳入图片引用，回收不再误删共享图片；确认框提示将随删的送批材料与导出记录。列表密级改 SQL 提取、搜索加 180 ms 防抖，详情页待处理分支改为缓存，附件增删刷新更新时间，分栏列表按实际宽度选紧凑列，归档失败保留已选文件。
- 查看、编辑与删除入口重新理顺，版本操作保护与提示文案一并补齐。
