## 公文助手 v0.9.5

本版本把**导入**补成一条完整的链：旧稿里的标题、列表、图片一并带进来（EMF / WMF 矢量图转成高清 PNG），导入端新增**清洗**分区；写作侧支持**独立列表下缩进子项**；导出侧新增**可编译的 Typst 包**；另补上**检查更新**、**首启示例稿**、**界面缩放**与**数据安全三件套**（配置损坏兜底、崩溃日志、一键备份恢复）。主题精简为六套，egui 升到 0.36.2，两平台 CI 恢复全绿。

### 导入：文档里的图片与版式都带得进来

- **Word 等文档里的内嵌图片会被取出入库**：此前解析时只留下 alt 文本（Word 里通常为空），图片导入后悄悄消失。现在 PNG / JPEG（及 GIF / BMP / WebP）按文件头识别后原样入库，同一份字节只存一次；段落里的图拆成独立段，标题、表格、列表里的图挪到块后；alt 留空，免得研究报告把自动替代文字编成图题。
- **EMF / WMF 矢量图转成 PNG**：Visio 图、旧版 Office 图表与剪贴画在 Word 里以图元文件存放，此前只能在原位留注释。新增 `src/metafile.rs`，`emf-core`（WMF 转交 `wmf-core`）转 SVG，再用画 Mermaid 的 resvg 与随包字体光栅化；图里的字体名按名字归到方正黑体 / 公文仿宋 / 方正书宋，缺字再按字形回退；画布留白后渲染、再裁掉空白边，统一放大到长边约 2400 像素。解析失败或画面为空时原位留注释写明原因，转换包在 `catch_unwind` 里，坏图不让程序崩。
- **取不出的图不阻断导入**：TIFF、SVG、链接到外部的图片在原位留 `<!-- [图片未导入：原因] -->`，导出不印，状态栏汇总张数；写图片失败不阻断导入。PDF 里的图片仍取不出来。
- **导入端按版式还原标题与列表**（确定性处理，不调用模型）：段首「一、」「（一）」取第一句或冒号前短语作标题，其余作正文；「1.」「（1）」按版式定性转标题或列表，「①」一律转列表；Word 自动编号与带编号的标题样式按编号重排层级；开头像公文标题的段落升成一级标题；单独一行的「附件」「附件N」加标题改成附件标记；纯文本按一行一段读，拿不准的段落原样保留。
- **导入端新增结构清洗**：CJK 与数字间空格、半角标点、全角数字、目录 / 链接 / 内联锚点 / 脚注 / 代码围栏 / 分隔线，以及表格列数、`<br>` 与空表头一并规范化；「第X章 / 节 / 部分」「1)」「字母编号」等层级补齐，标题多行与「（征求意见稿）」后缀处理，附件同行 / 折行标题与说明行、文首版头与文末版记剥离，「一是 / 二是」枚举拆行加粗、「第X条」加粗、无编号短标题加粗，并按实际用到的层级压紧、避免跳级。
- **PDF 导入增加并段修复**：按加粗编号、主送冒号、附件 / 抄送、落款 + 日期、列表短句重切段落；txt 按有无空行区分「一行一段」与「折行文本」；`.md` 导入复制正文引用的图片。
- **新增「清洗」功能区**：公文编号与 Markdown 编号互转、去 Markdown 标记、清全部编号，以及空格 / 标点 / 转换残留 / 表格清理与一键整理。
- 真实公文导入样例回归：8 份 docx / txt / pdf 样例（通知、请示、办法、带标题样式的方案、Word 导出 txt、折行 txt、讲话稿反例、两页 PDF）各配一份 `.expected.md` 完整对照，样例可用 `generate_samples.py` 重新生成。

### 写作与排版

- **独立列表支持一层缩进子项**：独立列表项下面比它多缩进两格写的列表行，认作这一项的子项——不另起段，按段内列表的编号样式接在父项后面（`1.主要任务：①完善制度；②强化督查。`）。解析器按缩进把连续列表行分成父项与子项，子项编号记入 `generated_prefixes`，预览、导出（Typst / Word）、花脸稿据此还原版式；子项的末尾标点另成一组统一，父项原样保留（引出子项的冒号不动），最后一个子项落父项那一级的标点；研究报告 Word 与 PDF 共用同一套正文解析，起草页回车续写也支持缩进子项。设置里的「一级列表（段内）／二级列表（独立）」改称「段内列表／独立列表」。
- **修复内置英文模式仍输入中文标点**的问题；中文标点补上「`\\` 出顿号」（微软拼音等通行约定），半角模式原样输出符键。

### 导出

- **新增可编译的 Typst 包导出**：包里是模板、`doc.json` 与数据（插图 / Mermaid / 公式 SVG / `references.bib`）打成的 zip，不含字体；解压后 `typst compile gongwen.typ`（研究报告 `research.typ`）即可编译。模板的字体角色同时接受字符串与数组。

### 界面与体验

- **锤子主题的公文预览加便签纸面装饰**：双线页框、四角收口、顶部轻压暗与柔和投影；预览、呈批件与电话记录单共用同一套纸底绘制，装饰只用于屏幕预览，不进入导出。
- **界面主题精简为六套**（Claude 奶油、MDEX 纸墨、锤子稿纸、北欧、复古暗、MDEX 夜墨）：移除曝光浅、拿铁、复古浅、德古拉、东京夜；旧配置里的这些主题名仍能反序列化，统一回退到 Claude 奶油。
- **界面缩放 80%–175%**：设置页拖完立即生效，不影响导出的公文版式；高分屏字太小或窗口装不下两栏时先调这里。
- **首次启动自动载入两篇示例稿**（一篇公函、一篇白头件），可直接改可删，预览直接成篇。
- **关于窗新增「检查更新」**：后台线程查 GitHub releases/latest（5 秒超时、走系统代理设置、地址可在设置页改），结果内联展示，离线优雅降级。

### 数据安全与设置

- **数据安全三件套**：配置解析失败不再静默丢配置（原文件改名留底 `config.json.损坏-<时间戳>`，启动弹模态提示）；上次异常退出的崩溃日志从状态栏一行字升级为启动模态框，可复制路径、可打开日志目录；设置页新增「数据备份」分区，一键全量导出 ZIP（排除日志与瞬态文件、WAL 检查点后打包）、校验后恢复（当前目录改名留底、条目名净化防 ZipSlip、关闭 SQLite 连接、解压失败回滚、恢复后引导重启）。
- **自动保存间隔做成真配置**：默认 120 秒、限 30–600，设置页可调即时生效。
- 修复备份一致性与任务互斥问题，补齐更新检查的唤醒路径。
