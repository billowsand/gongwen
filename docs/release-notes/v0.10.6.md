## 公文助手 v0.10.6

本版本把任务助手的 AI 全面接到 Pi 智能体上，同时收口安全复审遗留问题、升级 SQLite 依赖，并把三平台测试环境的不确定性清掉。

### 任务助手：材料整理与表单填写改由 Pi 执行

- **两条 AI 路径改成智能体作业，不再是一次性补全调用**。材料整理走 `gongwen-task-extract`、单任务填表走 `gongwen-task-fill`；两条都是内置技能，可在「AI 管理 → 技能」停用或复制改写。作业在 Pi 的加密工作区里读材料、按需检索已有任务，最后用 `submit_task` 交一份 JSON，由程序复核后交给任务页。
- **放出原先为「一次请求完成」设的门禁**：不再只把最近 50 项任务塞给模型，改用只读工具 `task_search` / `task_read` 按需检索；材料按 512 KiB 分块读取，单份上限 4 MiB，候选上限 100 条；任务作业不占写作门禁，可以和 Pi 写作同时跑。
- **确定性复核一条没少**：摘录必须逐字出现在原文、期限必须有原文支撑、候选类型与目标任务 ID 必须真实存在；采纳前仍然只写候选，不碰任务库。长材料不再因为一次请求放不下而整体失败。
- 任务页显示作业的实时进度与「停止」，恢复数据库时会请求停止后台作业并丢弃迟到结果。

### AI 侧栏与 Pi 运行时

- **修复 Pi 1.5 升级后侧栏活动行与候选稿刷新静默失效**：会话视图监听器的参数形状变了（直接给 `(value, ops, context)`，不再是 `{kind:"value"}` 事件），旧的判断让所有活动行、工具结果与候选稿事件都不再产生。现在恢复「模型正在生成 / 等待模型返回」、读写工作稿、工具结果与候选稿刷新。
- Pi 上游 chord / pi-ai / pi-durable 升到 1.5.0，host 升到 **0.5.0**（协议仍为 4）；补齐打包期的 host / 协议版本对账与运行时许可证收集，旧 host 不再能在原工作区续跑。
- 优化 Pi 侧栏的进度与工具结果展示。

### 安全与加密

- **修复 SQLite 静态分析告警（RUSTSEC-2026-0459 / CVE-2026-119375）**：`rusqlite` 升到 0.41、`libsqlite3-sys` 0.39.1，随包 SQLCipher 换到修补后的 SQLite 版本。
- 按安全复审继续收紧明文落盘与加密生命周期：无密钥时拒绝写明文，停用应用锁前核对另一槽、失败时明确提示可能已有部分明文；旧根目录 `apis.json` 纳入密封、迁移、停用解密与备份名单；帮助手册 PDF 改放缓存目录，备份排除系统元数据。
- 外部打开与逐次打印确认补齐；公开帮助图片不再进入备份；Pi 旧文件树迁移有明确预算。
- 避免 Wayland 窗口被遮挡时误报「应用无响应」。

### 导出与界面

- 随机生成的导出密码改为**可拼读的强口令**，仍然独立于登录密码。
- 修复 egui 0.37 升级后的交互回归：右键菜单不再因弹层抢焦点丢失选区，剪切 / 复制 / 移入候选区照常可用；界面测试恢复 0.36 的语义。
- 修复稿纸对齐与界面测试在 0.37 下的回归。

### 工程与维护

- 清理 TeX 链路与已移除主题留下的孤儿文件、过期工作流与脚本副本。
- 三平台测试作业先下载随包字体，避免预览与稿纸几何断言落到不同系统字体上误报；测试串行执行，消除 vault 全局密钥状态带来的跨用例污染。
- 移除 Ubuntu 20.04 / Debian buster 不支持的 `curl --retry-all-errors`，保留对 5xx 的重试。
