## 公文助手 v0.9.8

本版本集中在**应用内输入法的词表**：初始基础词表纳入版本管理、随包携带并按公文口径清理了一遍口语与冗余词；「输入法词表」页按实际维护习惯重做成快速操作（就地编辑、批量移除、撤销、直接改码）；「公文词表」审阅默认跳过输入法已经能输入的同名词，不再重复确认。

### 输入法：基础词表

- **安装包不再缺初始基础表**。初始词表 `quan.txt` 纳入版本管理（`.gitattributes` 按字节存取），打包脚本统一把它复制为 `runtime/ime/base.txt`，所有平台随包携带同一份；首次运行优先用户目录已有的 `ime/base.txt`，没有才用随包这份，旧版导入的音形表仍可迁移。
- **剔除口语词条**。删掉 2,130 条编码行，涉及 1,664 个口语化的多字词（聊天应答与语气词、方言口语、亲属口头称谓、拟声象声、网络俚语、表情符号）与 59 个粤、吴方言单字；单字表、公文常用词、专业术语与成语典故保留。
- **按公文口径再清理 5,798 个词**。用本机小模型对 40,970 个多字词逐个判定是否收进公文输入法，模型判删 6,800 个，再人工逐批复核救回 1,208 个（政务、法律、经济、军事、医疗、农林、环保、网信与计算机术语、成语典故、标点排版术语、单位与企业平台名、地名姓氏等），最终删除 5,798 个词、移除 6,605 行，全表 57,874 → **51,269 条**（单字 12,304 / 双字 25,605 / 三字 3,240 / 四字 9,000 / 四字以上 1,130）。两个「全表下限」测试的阈值相应由 55,000 降到 50,000，仍能挡住误截断。
- **维护侧拆成五个分表**。`assets/fuma/quan/` 下按字数分为单字、双字、三字、四字、四字以上五份，`quan.txt` 由 `scripts/merge-ime-tables.py` 合并生成（UTF-16 LE + BOM + CRLF）；加载器与打包脚本不变，随包仍然只有 `quan.txt` 一份。基础词表统一为这一份正式来源，macOS 不再优先 `mabiao.txt`（只作旧机后备）。

### 输入法词表页：改为快速操作

按实际维护习惯重做，取代原先的五个标签、常驻右侧详情与独立体检摘要：

- **只留「词条」与「检查」两个常用页**，整页是虚拟滚动的表格。查码、导入来源启停、构词规则、最近 20 次修改记录与「同步公文词表」收进「更多」；候选顺序与查码在行尾「…」按需打开，不再占常驻侧栏。
- **一个搜索框认文字或编码**：纯字母与 `?` 按编码前缀/通配查，其余按文字包含查；来源下拉框常驻，码长、字数、重码等折叠进「更多筛选」，默认不显示已屏蔽词。
- **就地编辑与批量操作**：双击文字或编码直接改，Enter 保存、Esc 取消；复选多条可「移除所选」，或按 Delete 移除。个人词直接删除，其他来源的词只在个人层屏蔽，切到「已屏蔽」可恢复。
- **检查页不再「审核后再应用」**：编码不符规则的词可直接「改用建议码」，也可双击手改，多条建议一次处理；冗余与失效记录逐项清理；多码与重码只提示、不认定为错误；「忽略」只对本次运行有效，可「重新显示」找回。
- **导入与导出各走各的菜单**：普通导入直接导入有效词条、无效行明确提示跳过；更新基础表与恢复个人备份先看覆盖范围再确认；文件保存失败不丢弃预览。导出默认给生效词表，也能导出当前筛选或个人设置备份。
- **新增本次运行的撤销**：点提示旁「撤销」或按 Ctrl+Z 撤回最近操作，批量移除与批量处理各按一次撤销；首次加词也能撤销；输入框内 Ctrl+Z 仍用于撤销正在输入的文字。撤销最多保留 20 次并按快照总量裁剪，退出后仍可从「更多 → 修改记录」恢复个人层历史；基础表更新会清空本次撤销栈。
- **加词窗简化**：默认只显示文字、编码与「添加 / 连续添加」，输入文字自动出码、手改编码也行；逐字码、其他可能码、已有候选与「设为该码首选」展开放进「候选与更多选项」。
- 修正界面帧尾清掉本帧 dirty 标记、导致保存或撤销后结果与检查不重算的问题；词表页 `Ctrl+N` 加词，`Ctrl+F` 不再被稿件快捷键提前吃掉。

### 公文词表：不再重复审阅输入法已有的词

- **默认隐藏输入法里已经能输入的同名词**，按完整文字判断（不要求编码相同，简码也算），基础表、个人词条与已启用的导入表都参与判断，已屏蔽或停用的不算；「待确认」等概况统计同样排除这些词。勾「显示输入法已收录词」可临时查看，隐藏不等于拒绝、不改原有审阅状态，完整码表导出不受影响。
- **先过滤再截断**：列表上限截断在去重之后发生，避免前 500 条全是已有词时把后面的新词挡掉；「接受列出的全部」只作用于当前可见列表。在输入法里增删词、启停来源或撤销后，回到本页自动更新。

### 编辑器

- **源码区空稿提示语跟随正文排版**：不再按界面默认字体与行高贴在行框顶端，改为复用 Markdown 排版与对齐逻辑按正文原点排一遍，字号、字面、主题、源码与对照两种模式都是同一副样子；空目录面板图标的悬停提示共用同一句文案。

### 文档

- **使用帮助第 17 章「公文词表与输入法」**：补「默认隐藏输入法已收录词」的口径与开关，重写「输入法词表页」一节为「词条 / 检查 / 导入…导出… / 更多」与撤销规则，加词窗、查码入口、同步公文词表的位置全部按新界面改写；设置章与常见问题同步。
- **README**：输入法一节改按新界面描述（快速增删改、就地编辑、批量移除、撤销、检查直接改码、更多菜单），硬数字同步为约 **25.2 万行** Rust、**2337 项**自动化测试。
