## 公文助手 v0.10.9

本版本完善维基知识库的分类口径、独立排版与双栏阅读，精简设置与入口，并升级 SQLCipher 修复已知 SQLite 漏洞。

### 维基知识库

- **主题与分类支持「分类口径」**。框架管理页改为左树、右详情，可编辑节点名称及最多 600 字的收录范围、排除条件和易混淆资料归属；AI 再次归纳会参考已有口径，页面整编与更新也会读取所属口径。
- **条目页有独立排版与双栏阅读**。正文不再套用普通公文或研究报告的纸面样式，可在 Markdown 源码与排版结果之间对照阅读；依据标记、双链与版本历史继续保留。
- **分类口径经过程序化校验与持久化**。Pi host 与 Rust 两侧同步检查字段类型和字数，节点删除时对应口径级联清理，避免模型交付绕过约束或留下孤立数据。

### 界面与设置

- **退役应用内使用帮助**。删除帮助正文、截图、菜单入口与 `F1` 快捷键；旧版帮助文件只保留备份排除和跨槽兼容，不再维护随包手册。
- **AI 技能包入口迁入 AI 管理页**。原设置页「上手指引」一并撤下，`gongwen-markdown` 技能包仍可从「AI 管理 → AI 技能包」导出。
- **设置页收纳备份与导出说明**。传输题名改为弹窗管理，空字典配置仍可保存；修正长题名和密码状态提示，密码框关闭系统输入法。
- 检索增强相关文案统一更正为「资料库」，与当前导航和功能名称一致。

### 安全维护

- **SQLCipher 升级至 4.20.0 / SQLite 3.54.1**。通过 rusqlite 0.42 与 libsqlite3-sys 0.40 引入修复版本，消除 RustSec `RUSTSEC-2026-0502`（CVE-2026-119375）报告的已知漏洞；本地 `cargo audit` 已无漏洞项，其余已豁免的维护状态警告不变。

### 文档

- README 补充维基分类口径、独立排版与双栏阅读，移除已退役的使用手册入口，并重新统计为约 **33.6 万行 Rust、3103 项自动化测试**。
- 安装指南更新至 v0.10.9；Windows 安装包名称、校验文件与平台发布口径保持不变。

### 质量检查

- 本机 `cargo fmt --all -- --check` 无输出，`cargo clippy --locked --all-targets -- -D warnings` 零警告，`cargo test --locked --all-targets --no-fail-fast -- --test-threads=1` **3103 通过 / 0 失败 / 90 忽略**。
- SQLCipher 升级后重新运行编译与测试，确认数据库相关改动未破坏现有行为。
