## 公文助手 v0.10.7

本版本新增「知识库（维基）」——把资料库里的原文整编成有人工审核、有依据、能互链的条目页，供写作与问答取用；同时把复制粘贴拆成应用内与系统两条通道，并按复审结果修掉维基整链上的一批治理与界面问题。

### 知识库（维基）

- **原「知识库」改名「资料库」，新增维基式的「知识库」页**。资料库照旧管原文、索引与检索；知识库把原文整编成「主题 → 分类 → 页面」的条目页，一页只归一个分类，主题与分类各带一篇导览页。两者同存 `manuscripts.db`，启用应用锁时一并加密，资料库里的原文不搬动、不删除。
- **框架两条路**：`gongwen-wiki-frame` 作业用只读工具翻资料库，交回主题 / 分类与依据文档的提案，通过确定性校验后由用户确认才写入；也可粘 Markdown 大纲导入，或沿用语料库页的树交互手工增删改移。规模上限 30 主题 × 20 分类，重名、孤儿分类、第三级直接报错。
- **页面整编与更新都是 Pi 作业、都只交提案**：`gongwen-wiki-write` 按分类读料拆题成页（一次至多 10 页、单页 2 万字、依据说明 200 字），`gongwen-wiki-update` 按新资料改写已有页（至多 5 页，不改名、不改类型、正文必须确有变化）。结构、标题、归属、依据是否真实存在由 Rust 与 host 两侧确定性复核；不占写作门禁，可与 Pi 写作并行。
- **审核台**：左可编辑 Markdown、右版式预览或「变更对比」，底栏「退回 / 采纳并入库」，可整批「全部退回」。采纳由界面线程写库，链接按标题解析登记，依据落成资料文档确认标记；改过的版本标「经人工编辑」。基线版本变了要退回重发，不在旧版本上盲写。
- **链接、版本与治理**：`[[页面名]]` 双链与红链、改名按 UUID 全库跟随、被引用页面禁止删除（含版本历史一起删的二次确认）；版本列表、任意两版对照、回滚生成新版本；缺口清单分「需复核 / 缺导览页的节点 / 待建页（红链）/ 还没有条目页的分类」，建页后红链自动收敛。
- **资料库联动**：列表新增「维基」列（未整编 / 已用于维基 N 页）与筛选，可圈选资料整编；新资料标题命中维基页面时给「按新资料更新」提示。
- **写作与问答接入**：Pi 写作新增 `wiki_search` / `wiki_read` / `wiki_links` / `wiki_doc_read` 四只只读工具（独立 12 次/轮额度，命中自动进证据台账），取料顺序是「先维基语义导航 → 再按依据清单读原文 → 兜底资料库检索」，任务助手的作业同样可用。资料库问答改为维基优先双层：先取至多 3 篇已审核条目页（每篇 3000 字），原文片段补细节，答案卡片列「维基依据」可点回原页。

### 知识库工作区与 AI 状态栏

- **六个工作区重做**：浏览、框架整编、原始资料整理、待审收件箱、人工审核、版本历史各占一个完整工作区，取代原先挤在浮窗里的归纳、审核与版本界面；作业进度不再只有一条最新记录。
- **AI 工作状态栏**：右侧栏固定显示作业名称、状态、耗时与停止入口，最近动作常显、历史活动按时间排列、工具结果按需展开；「正在停止 / 已停止 / 失败」给重新发起入口，「已交付」给查看框架提案或打开待审批次。主区仍可继续阅读核对，资料库与知识库之间切换可找回同一作业。
- 阅读器与审核台走同一条正文排版链，页面内链与依据编号可点；右栏在阅读时显示「被引用 / 依据」，运行时优先显示工作状态，窄窗口可折叠。

### 剪贴板：应用内与系统分开

- **`Ctrl+C` / `Ctrl+X` / `Ctrl+V` 改为应用内剪贴板**：跨稿件与输入框使用、粘贴保留原文，锁定或切换工作区时清空；不再读取也无法触碰系统剪贴板。
- **外部粘贴改走 `Ctrl+Shift+V`**（或正文右键「从外部粘贴」）：后台读取系统剪贴板并清洗转换，Word / 网页 / Excel 的标题、编号、列表、表格与图片照旧转成 Markdown；普通表单字段只接收清洗后的文字。
- **外发先确认**：选中文字按 `Ctrl+Shift+C` 或「复制到系统剪贴板」，确认后才写入系统剪贴板；旧的「改为原样粘贴」入口随之撤除。
- 为隔离绘制结束后才生成的复制命令，`egui-winit` 改为仓库内 vendor 的 0.37 版本——粘贴快捷键由应用自己路由，窗口后端不再在主线程读系统剪贴板；不新增系统依赖。

### 修复

- **备份密码弹窗改为全局浮窗**：设置页点「导出备份… / 恢复备份…」时密码框就在当前帧的窗口层，不必切回稿件库页才看得见。
- **维基全流程复审**（存储 / 作业 / 界面）：节点建立、改名、删除后回填链接（修掉导览页反链丢失导致删除保护失效）；自动取证只认当前版本有现存依据的页面；FTS 查询词转义双引号并限词数；页面标题与正文上限、重名歧义、大纲缩进与规模落到存储层；补齐页面改名与删除入口；审核台与版本历史 diff 限高并缓存、采纳双击防抖、版本窗按页面重置 A/B、缺口清单可滚动；作业期间禁改框架；问答维基层失败进降级提示。
- **host 侧校验前移**：整编 / 更新作业的结构上限（页数、标题 100 字、正文 2 万字、依据与变更说明 200 字、依据条数、〔E编号〕交叉登记）在 `submit_task` 当场打回，模型轮内即可改正，不再跑完整轮才被 Rust 拒收。
