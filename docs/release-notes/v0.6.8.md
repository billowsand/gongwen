## 公文助手 v0.6.8

本版本把**知识库从「只能导 Markdown」扩成「和起草页同一套导入」**：Word、电子版 PDF 等文档可直接进库，导入与建立索引分成两步，导完先在库里躺着、想用检索时再建索引。同时内置 PDF 查看器支持**文本光标、拖选与复制文字**，研究报告的**插图宽度**改为按比例自动定、交叉引用下拉按位置分组，并修掉带前导空格的图片锚点被静默丢弃、引用处印成 `??` 的老毛病。

### 知识库：导入 Word / 电子版 PDF，导入与索引分开

- **导入复用起草页的 `anydoc` 文档链，格式完全一致，另收电子版 PDF**。Word（docx / doc）、Excel、PowerPoint、OpenDocument、RTF、EPUB、CSV、纯文本与 Markdown 都能进库；电子版 PDF（能在阅读器里选中文字）也能进，版式不保留，检索只用文字。
  - **扫描版 PDF 整份拒收**（哪怕只有个别页），并提示哪几页是扫描件——缺页的内容进了库会被当成「原文没有」，误检比拒收更糟；
  - 字体没内嵌文字映射、提取出来是乱码的 PDF 拒收，提示改用原始 Word；
  - 设了密码的文件拒收，提示先去掉密码；
  - 拒收是一份一份判的，一批里坏的那份不影响好的。
- **导入只存正文，不依赖 embedding 服务**。导完文档立刻出现在库内文档列表，标着「未索引」；**新增「建立索引（N）」按钮只处理待索引文档**，原地替换切块、文档 id 不变，已建索引的文档不会被重复处理。
- **没套标题样式的 Word 公文也能按章节切块**。导出器认的是标题样式，而实务里「一、总体要求」「第 X 章」常只是独立成段的加粗短句；导入时程序把这类短段补成 `##`，让切块按章节分。Markdown 原文按作者写的结构来，不做改动；文档没有大标题时以文件名作标题。
- **建索引的前置条件提示改挂在知识库页**，不再写进该页根本看不到的状态栏。

### PDF 查看器：文本光标、拖选与复制

- **新增 `pdf_text` 文字层**：另走一遍页面内容流，收集每个字的位置与 Unicode，按行（竖排按列）归组，提供命中测试、插入点定位、选区高亮与取文字。文字层只占内存、不占显存，纹理被淘汰时保留。
- **交互**：悬停文字显示文本光标；按住拖动选字，跨行跨页都行；拖出视口自动滚动；`Shift` 加选，`⌘C` / `Ctrl+C` 或右键「复制」取走，`Esc` 或单击取消。
- **复制出的文字可读**：西文词间按间隙补回空格，中文之间不补——从扫描件说明、页眉里抄一段话不用再手动补空格。

### 研究报告：插图宽度与交叉引用

- **插图不再一律铺满版心，按「占多大面积」定宽**。新增 `mdx::figure_size`：按面积定宽（每张图约占版心面积 38%），再用版心宽、版心高 60%、位图 150 DPI 三条硬上限兜底，最后量化成四档（版心宽的 100% / 80% / 60% / 45%）。竖图（手机截图、整页扫描件）不再高过版心，小图标不会被拉到发糊；PDF 附件是矢量图，不受 DPI 那条限制。**TeX、Word 与预览三处共用同一函数**，同一张图三处一样大，图一律居中。
- **图题、表题与表格正文对齐纸面口径**。图题表题改用与 PDF 一致的标签黑体 / 题名宋体小四、标签后空半个字；表格正文从误用的公文仿宋四号改回宋体小四 18 磅；补上图与图题、表格与后文之间的间隔。
- **「交叉引用」下拉按锚点所在位置分成「结构 / 图 / 表」三组**，结构组按层级缩进，每条列出纸面编号与题名（如「第 1 章 研究背景」「图 1.2 总体架构」），点一下插入。分类只看锚点挂在哪一块上，编号与纸面同源；挂在不编号标题、无图注图片或普通段落上的锚点没有号可引，不列出，下拉底部只报个数。
- **修复：图片行尾带前导空格的 `{#id}` 锚点被静默丢掉**。起草页「锚点」按钮插入时带前导空格，原先图片行尾只认紧贴写法 `![](a.png){#id}`，锚点一丢引用处就印成 `??`。现在图片锚点和题名、表题同一口径都容许前导空格，并补了 crossref 校验的回归测试。

### 界面细节

- **校对词表行与 AI 提示词卡片整行可点**：新增 `theme::clickable_card`，整张卡片是点击区，悬停显示手型指针、底色淡入悬停色并加深描边，按下再压一档；选中项在强调色淡底上同样变化。卡片内关掉 `selectable_labels`——标签不再吞点击、不再冒出文本光标，复选框等子部件仍优先响应。校对词表行加圆角、标题左对齐，AI 提示词卡片去掉冗余的「点击编辑」悬停提示。
- **稿件表格列内容与表头统一居中**：新增 `centered_header` / `centered_cell_text`，数据列表头与单元格一律居中；勾选列与操作列保持左对齐，按钮个数不同时各行仍对得齐。新增 `empty_cell_placeholder`——单元格正中画一段淡色细线表示「无」，替代原先粗细、颜色随字体走且贴左的「—」，文号、成文日期为空时也显示。知识库「已入库」圆点加文字按整组宽度居中。
- **编辑器标题字号收窄、行距略放宽**：Markdown 模式下标题原先按 `#` 数量放大到 1.30 / 1.16 / 1.07，与正式预览（标题字号统一等于正文、只切字体）差距太大，编辑时看着比实际排版夸张。倍率收窄到 1.06 / 1.03 / 1.0，层级主要靠字体、颜色和粗细区分，字号拉平后统一加一点行距不显挤。
- **研究报告文件类型用内嵌下拉箭头**，与其它下拉控件高度统一。

### 文档

- **使用帮助**：第 11 章「PDF 查看器」补「选字与复制」一节（文本光标、跨行跨页选择、快捷键、复制文字的词间空格规则）；第 18 章「知识库」重写导入一节（可导入格式、扫描版 / 乱码 / 加密 PDF 的处置、Word 无标题样式的章节切分、导入与建立索引两步）。
- **修复帮助章节副本不同步**：v0.6.7 期间第 8 章「研究报告」的插图宽度与交叉引用分组说明只更新了 `docs/help/` 副本、漏了 `assets/help/`（应用内嵌的是后者），本版已把两处补成一致。
- **README**：刷新硬数字（约 12.2 万行 Rust、1289 项自动化测试），「PDF 应用内预览」补选字复制，「知识库与仿写」补 Word / 电子版 PDF 导入。
