## 公文助手 v0.6.6

本版本把「版本变更与花脸稿」推到第 ④ 期、给加密 ZIP 多机往返补齐身份与版本图、并把公文要素的就地标注落到 TeX / Word / 预览三处同一套渲染。同一版里还包含研究报告新增「部分」与「不编号」两类标记、标准词库区分呈批与发函两类代字，以及一批界面与词表细节修正。

### 版本时间轴与可编辑对照的第 ④ 期

- **版本时间轴取代右侧抽屉**。起草页进版本对照模式后，左侧出一条可收起的**版本时间轴**：最上面是「当前未提交」，下面按版本号倒序列出各版（版本号、名称、提交时间、备注摘要，最新版带「最新」标记）；点行标题选中、点「载入编辑」切到起草页继续改，未提交修改时弹三选确认。功能区「视图」与状态栏的「版本历史」按钮统一改为**进入版本对照并展开时间轴**；右侧的旧版本抽屉连同其唯一调用方一并下线。
- **「对比：上一版 / 固定基准」开关**。历史版本的对照默认对**上一版**（v1 的旧侧是空白稿），点时间轴顶部开关可换成**固定基准**——选中行与某个固定版本比较。固定基准晚于所选历史版本时该行退回与上一版比并在界面明示，绝不偷偷把未来版本当旧版。
- **历史版本对照统一走同一只读视图**。把共享的「版本对」组件抽出来（`src/version_pair_view.rs`），起草页、稿件管理对照窗、AI 工作台之外的「从 vA 到 vB」对话框都用它，左只读统一 diff + 要素变化卡片、右花脸稿预览、F7 / Shift+F7、悬停联动、折叠未改动全部一致；按 `(稿件 id, 旧版本号, 新版本号)` 缓存全部计算结果（其中工作区新侧按内容哈希，缓存键冲突修正已合入）。
- **未改动文字也双向联动**。可编辑对照：编辑器光标换到没改动的行，右栏花脸稿标亮并滚到同一段；预览里点没改动的段，编辑器光标跳到那一段段首。只读对照：预览里点没改动的段，左栏展开折叠、滚到同一行并描边。花脸稿未按当前正文重算好时不联动，免得偏移错位。

### 离线稿件身份识别与版本合并

- **稿件身份、版本身份、内容相等是三件事**。标题与文号只用于提示候选；本机整数 `id` 不再跨库去重。新增持久的稿件 UUID（数据库唯一索引）、版本 UUID（双父关系）、按行文要素 + Markdown 正文 + 备注算的 SHA-256 校验值。同 UUID 却不同校验值时拒绝导入并报错；内容相同但历史不同（版本 UUID 不一致）则标为「内容相同、历史不同」。
- **版本历史从线性迁到图**。现有 `manuscript_versions` 全部迁入可记双父的版本图；同步检查点不显示为提交版本，让两台电脑各自修改后仍能找到共同基线。
- **加密 ZIP 升级到 v2**。新格式携带所选稿件的完整版本祖先 + 当前工作稿 + 资源（含图片 SHA-256）；v1 旧包仍可读。导出原子写（临时文件 + persist），导出前先保存打开标签的脏工作稿（草稿状态拒绝导出），收集活稿与全部历史版本引用的图片并按 SHA-256 校验，缺一张即拒绝导出。
- **导入预览逐篇判定**。八种关系：新稿 / 同一 / 等价 / 本机较新 / 导入较新 / 分叉 / 无基线 / 旧包 / 归档；共同基线用 LCA（多个候选时判无基线、不推测）。按关系给出动作按钮（跳过 / 新稿 / 采用导入版 / 合并为新版本 / 暂存分支 / 关联并暂存 / 另存副本）；分叉合并由用户逐项勾选 + 合并后全文预览 + 手工改写。
- **合并是保守三方**。Markdown 按保留空白与标记的逐行 diff 聚块，不重叠的进候选、重叠且结果不同标冲突；行文要素按 JSON 树三方合并，文种 + 方案、日期 + 自动开关两组成组。整包校验通过后才提交数据库与资源，SAVEPOINT 包裹全部写入，失败回滚并清理已落盘的图片（不会留下部分合并）。
- **暂存分支留痕**。合并冲突时可以选「暂存待处理分支」，稿件详情页列待处理分支可继续处理，合并确认时生成记录两个父版本的可见合并版本；归档稿不允许修改，导入合并走「另存为新身份」。
- **重名资源守门**。PDF 按内容去重只增不删、自动改名；图片同路径不同内容拒绝导入且不部分写入；同内容图片不触碰本机文件。

### 公文要素就地标注

- **版头 / 版记要素改了就在纸面原位画「旧值红删除线 + 新值蓝框」**。范围：主送机关（含红头呈批件呈报领导）、抄送机关、成文日期、发文字号、落款单位、密级（含保密期限）。**整字段替换、不做词级**；按部件拆标（成文日期 = 年 / 月 / 日、发文字号 = 代字 / 年份 / 序号、落款单位 = 每行一个部件）。
- **三处渲染接同一份标注**。显示值统一走 `src/export/element_display.rs`；标注走 `src/visual_diff/elements.rs` + `RedlineDoc.elements`。TeX、Word、预览各自接住——预览版留白（文号序号、日期「日」位）两侧都换占位后再比；TeX 里红头呈批件落款按标注后的总宽重算摆位（`\RedSignatureUnitWidth`），日期居中不偏。
- **清空标注不丢**。主送、抄送、密级、落款等路径在标注存在时保留版位（TeX 新增 `\CopiesToMarkedRow` 接缝宏；类里的 `\Recipient` / `\CopiesTo` 永远写未标注的新值，避免 `\CalculateTotalCopies` 的 `\StrCount` 把哨兵展开报错）。Word 端清空要素仍生成标注段（覆盖页眉 / 页脚所有 `word/*.xml` run 属性）。
- **三方一致性 + 逐字节回归**。`element_change_matrix_keeps_marks_in_tex_word_and_preview` 把六要素 × 清空 / 新增 / 修改的组合喂进公函 / 红头呈批件 / 电话通知 / 白头件 / 普通公文 / 会议议程共 24 个 case，逐项核对真实 TeX 宏、所有 `word/*.xml` 的删除线 / 边框 run、全页预览文字与删增片段序列。`unchanged_elements_keep_the_plain_output_byte_for_byte` 锁住「空标注 = 定稿」逐字节相同（TeX 文件、`word/document.xml`）。`element_only_changes_still_produce_a_redline` 验证正文一字未动只改密级也能出花脸稿。

### 研究报告：部分与不编号

- **mdx 新增「部分」与「不编号」标记**。研究报告的「部分」用 `<!-- [部分] -->` 起一段，按部分单独排目录、章节计数器按部分重置；「不编号」用 `<!-- [不编号] -->` 包一段，正文跳过自动编号、目录也不出现。图与表按部分编号时另起流水号；目录里的部分条目改用正文字号的引导线，长名称也能缩成一行。
- **预览与功能区**。`src/preview/research.rs` 与 `src/preview.rs` 都接住两类标记；功能区「研报」分区新增「部分」「不编号」两个按钮，光标在两类标记段落里按钮亮起。校验（`src/validator.rs`）按标记更新部分 / 不编号的标题合法性；起草与优化提示词说明同步记录两类标记的写法。
- **题名识别更稳**。报告题名只认正文区段的第一个 `#`，部分、摘要段里的 `#` 不再被当题名删掉；去编号规则把「部分」当成一个词，「第一部分」不会被剥成「第一分」。研究报告导出 PDF 时题名清晰展示。

### 标准词库：呈批与发函代字

- **名片区分呈批与发函两类代字**。同一单位可分别填「发函代字」（公函文号前缀，如「财函」）与「呈批代字」（红头呈批件文号前缀，如「财呈」）；下级单位未填写时沿上级单位继承。旧配置的单个「机关代字」保留为发函代字，呈批代字需单独补充。
- **拖动手柄不再显示缺字方框**。标准词库拖动手柄改用 grip 图标，列表不再夹着 tofu。
- **新建词条置顶**。新建校对词条立即出现在列表顶部并同步进入编辑状态，免去翻找与重复点开的步骤；列表宽度限制避免长名称把整行撑满。
