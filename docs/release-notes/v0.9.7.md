## 公文助手 v0.9.7

本版本的核心是**富文本粘贴转 Markdown**：起草页 `Ctrl+V` 把 Word / WPS / 网页 / Excel 复制来的富文本和多行纯文本直接转成公文助手 Markdown，编号、标题、列表、文框、图片各归各位；版式预览对横页附件同步切横纸，使用帮助改为一篇研究报告、按研究报告的版式排印。

### 粘贴：富文本与多行纯文本一键转 Markdown

- **第一期：接管 `Ctrl+V`**。剪贴板里有 HTML（Word / WPS / 网页 / Excel 富文本）时自动转成公文助手 Markdown，只有多行纯文本也走同一管线；`Ctrl+Shift+V` 始终原样粘贴，智能粘贴后可一键「改为原样粘贴」，块级与行内粘贴都是同一个撤销点。HTML 解析按容错口径做，不认识的花样降级而不是粘坏。
- **第二期：结构还原**。点分编号（1 / 1.1 / 1.1.1…）认到四级标题，ASCII 罗马数字（I. / II. 成组才认）与字母编号（A. / （A）/ (a)）接最浅层级，全角罗马数字（Ⅰ–Ⅻ）当最浅一层；孤立的一行「3.2.1 技术路线」和小数（1.5亿元、1.1倍）都不算编号，原文编号跳号（一、→三、）会报告并重新编号。样式标题按插入点所在章节整体定级，稿子里不再冒出 `#`；句中粘贴压成一行行内文字（表格除外），只保留加粗等行内格式。列表整理成紧凑两级，白头件与呈批件不收列表、自动拆成段落。导入旧材料与「整理结构」走同一套编号规则，导入结果逐字未变。
- **第三期：研究报告认文框，AI 侧栏材料保留表格**。网页的 `<aside>`、Word 的「文本框表格」、带边框或底纹的容器在研究报告里认成文框（首段加粗短标题作名称，取不到写「专栏」并在状态栏提醒）；AI 侧栏的大段粘贴成为临时材料时保留管道表，不再散成制表符，闸门照样拿材料全文核对，三条红线不受影响。
- **第四期：图片随文字入库**。剪贴板里的本地图片（data: / file:）随粘贴入库、原位插图，取不出的图留注释不阻断；网络图片一律不下载。宽高都不超过 32 像素的跟踪像素、图标与隐藏图略过，单行内容只在确有可入库图片时才接管——「复制一个词」不再变成块级粘贴。
- **验收修正**：点分编号不误删日期与数量（「10.1 国庆假期安排」「1.2 个百分点」保住了），行内粘贴保住字段分隔空格，文框名称不再吃掉标题里的字，会议议程拉平成一级连续编号，复制的现成 Markdown 粘进 AI 侧栏原样保留。
- 已知边界：只复制一张图片时剪贴板里没有文字、粘不进来（先存文件再插图）；Word 公式待真实样本再单独做。

### 版式与排版

- **版式预览同步附件自动横页**：预览对每份附件调用与导出相同的横页判定，判定为横页的附件整张纸切成横页几何（225mm 版心、左边距 35mm、上边距 28mm），并按 210/297 等比压缩到与竖页同宽，整篇预览共用一个缩放级别；表格按横版心列宽重排，附件标题仍按竖版心断行，与导出 PDF 一致。
- **修复公函 PDF 版记抄送与印数换行排版**。
- **Markdown 编辑器各主题垂直对齐统一**。
- **修复稿纸中 Markdown 标题偏上的问题**（v0.9.6 回归）。

### 研究报告

- **使用帮助改为一篇研究报告**：`assets/help/` 的一篇研究报告就是全部帮助（docs/help 副本删除），应用内直接用研究报告预览排、「生成 PDF」走研究报告 Typst 链，帮助不再有自己的渲染器；手册目录、发布技能与技能包同步。
- **预览认代码围栏**：研究报告预览识别代码围栏，行内代码里的引用与公式按字面排，不再误当公式与文献。
- **PDF 只给有表题的表编号**，代码不再排连字与全角括号。

### 文档

- **README**：新增「粘贴即转换」（编号定级、跳号报告、句中粘贴、图片入库、`Ctrl+Shift+V` 原样粘贴）；硬数字同步为约 **25.1 万行** Rust、**2325 项**自动化测试。
- **使用帮助**：第 6 章「编辑器」随四期补粘贴转换（点分编号、跳号提醒、按章节定级、两级列表、句中粘贴、文框、侧栏材料表格、图片入库）与已知限制。

### 安全

### 质量检查

- 两平台 CI 门禁（格式、clippy、2325 项自动化测试）全部通过。
- 新增覆盖：富文本粘贴四期的夹具测试（编号方案、章节定级、文框候选、材料表格、图片入库与跟踪像素略过），「整形后的列表经导出解析器读回仍是两级」的往返测试，横页附件预览的版心压缩对照测试。
