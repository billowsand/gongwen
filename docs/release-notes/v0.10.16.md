## 公文助手 v0.10.16

本版本把「清洗」与「标点」这两件最费手工的事交给程序：清洗分区只保留正向转换，不再反向拆散已成形结构；标点进入预览、导出与保存全链路，按整篇统一规范并可一次撤回。同时修掉加密工作区首次设密码后无法登录、词库单位下拉超长等一批问题。

### 清洗：只做正向转换

- **删掉三个反向操作**。清洗的目标改成「把一份可能不合公文助手 Markdown 标准的正文变成合规的正文」，原来「Markdown 退回公文编号、剥掉 Markdown 标记、清除全部编号」三个按钮连同实现一并删除——它们把已经成形的结构拆散，与这个目的正相反。
- **按钮重新分组**。结构标注（规范公文标注 / 规范标题 / 规范列表 / 规范表格）、文本格式（清理空格 / 规范标点 / 规范引号 / 删转换残留 / 清理空行）、一键规范。判据与 `skills/gongwen-markdown` 的《公文助手 Markdown 语法完整参考》及自检脚本 `check_gongwen_md.py` 对齐。
- **结构还原更准**。段首手打编号复用导入端的 `restructure`，并把标题与正文紧贴着的紧缩排版贴回去；六级标题降成五级免得整条不排丢内容，标题剥编号后不剩字就保留原文；研究报告分开处理，部分区与附录区允许多个一级标题，也不跑公文那套结构还原，免得误伤锚点、交叉引用、文框与公式；表格缺分隔行的补上，列数对齐复用导入端同一套规则。

### 标点：按整篇规范，不零敲碎打

- **预览与导出先规范**。中文语境里的半角标点（`工作,通知;时间:上午(附件)!`）转成全角，括号成对转中文全角，重复标点（`，，`、`。。`）收成一个，省略号统一成 `……`；预览、Word、PDF 共用同一份结果。
- **显式保存时整篇写回**。一并规范空格、列表末尾标点与发文字号的六角括号；**改动进撤销栈，一次 `Ctrl+Z` 整次撤回**。自动保存、失焦、切标签、复制全文都不动源码——这些不是编辑动作，源码不该变。功能区保存按钮此前走的是无编辑器上下文分支、规范写回撤不回，已与 `Ctrl+S`、标题栏保存统一。
- **网址与文件名受保护**。网址、邮箱、裸域名、文件路径与带扩展名的文件名一律跳过标点规整（`www.例子.中国`、`C:\目录\文件.文档` 不再被改）；代码围栏与行内代码里的标点原样保留。
- **标题标点不再一上来就判必错**。标题内多出的逗号、分号、句号改为按「疑似」提示并给一键删除；顿号「、」本就合法（「关于做好元旦、春节期间有关工作的通知」是常见写法），不再误报。

### 预览：长文档不再每帧全量规整

- **更正结果按文本帧间缓存**。起草页预览此前每帧对整篇文档跑一遍规整（多处正则全扫与文号识别，有差异时还算字符级映射）；改为按源码文本缓存更正结果，帧间文本没变只付一次字符串比较，长文档滚动不再逐帧重算。

### 修复

- **首次设密码后能登录了**。首次设置密码时只在目录「空白」才补默认配置，而 `workspace_has_existing_data` 把普通模式遗留的 `images/`、`ime/`、`pi/` 等应用目录与 `metrics.json` 当成既有工作区数据，导致跳过补配置；加密迁移后 `config.json` 缺失，环境闸门以「加密工作区的配置文件缺失」阻断且每次登录重复，用户进不去。现在应用自管目录（含 `alt-` 槽位变体）与密封名单里的非 `config.json` 文件不再视为既有工作区数据；稿件库、配置副本、`recovery/` 与未知条目仍阻断并走恢复。锁屏恢复按钮文案改为「验证密码并恢复默认环境策略」。
- **加密工作区能导入词库了**。`vault_locked` 表示应用锁已启用（解锁后的加密工作区同样是 `true`），不是「当前锁屏」；词库导入的两处门禁把它当成禁止条件，导致所有加密工作区导入标准词库都被取消并提示「工作区已变化或已有导入任务」。新增 `can_start_vocabulary_import`，只检查密钥 / 槽位 / 停写是否变化与是否已有导入。
- **词库单位下拉不再超长**。单位编码内联列表受 Excel 255 字符上限限制，88 个单位（如美国国防部样例）就达到 920 字符，导出直接失败、回导验证无法进行；人员「所属单位编码」下拉改为引用定义名称 `UnitCodes`，指向单位表隐藏 N 列。
- **解锁页密码框不再偏上**。密码框撑到控件高度后 `TextEdit` 默认按左上对齐排字，提示文字与密码点一起贴上沿；统一显式 `LEFT_CENTER`，并加了一个渲染层回归用例量框与文字的中心位置。
- **非 AI 版保存也能撤销标点规范**。`draft_page` 的 `replace_with_undo` 重导出此前被 `ai-workbench` 特性门控，而非 AI 版编译不过；去掉门控后，非 AI 版保存时的标点规范写回同样可一次 `Ctrl+Z` 撤回。

### 工程与维护

- **依赖漏洞扫描恢复绿灯**。`url` 2.5.8 命中 2026-11-20 新披露的 `RUSTSEC-2026-0592`（嵌套 `blob:` URL 调 `Url::origin()` 栈溢出，DoS），升到修复版 2.5.9（连带 `form_urlencoded` 1.2.3）。
- **标点处理另有设计文档**。新增 `docs/proofread-punctuation-design.md` 与 `docs/proofread-autofix-inventory.md`，把标点与自动更正在导入 / 粘贴 / 清洗 / 预览 / 导出 / 保存各环节的现状、缺口与处置口径拆清楚，标点类自动更正按「一进一出」还是「结构级改写」分两层推进。
