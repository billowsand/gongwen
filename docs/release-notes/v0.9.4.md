## 公文助手 v0.9.4

本版本打磨**锤子稿纸**主题的观感与源码视图布局，给普通公文加上**横页排版**；并修掉序号表、插图与长稿页数统计上的几处毛病，两平台 CI 恢复全绿。

### 界面：锤子稿纸按原图重校，源码视图收进一张稿本

- **锤子稿纸按锤子便签原图重新校准配色**：渐变顶栏改为暖烟草棕、底板改浅蜂蜜桦木、纸面抽成奶油色调常量，正文与标题的墨色加深到约 **8.7:1** 的对比度；顶栏与顶栏面板之间去掉分隔线。
- **源码模式的目录、正文与缩略图共用一张稿纸卡片**：目录空时收成只留图标的窄栏，标题层级加左侧标记，缩略图去描边并在锤子主题下淡化；顶栏纯图标按钮常态不再描边（悬停 / 按下改半透明白底与黑底），「菜单」按钮改用融入栏底的米白图标与文字；输出分区取消「文件导出 / 存放位置 / 最近导出」三组小标题，回到单行命令，组间只留短分隔线。
- **源码目录全主题统一**：236 宽的目录布局、当前章节左侧标记与低对比侧栏不再只给锤子稿纸，侧栏配色随主题深浅，无标题时收成窄图标栏；行号改为按 galley 行首基线对齐、字号与正文一致，行距加宽时字形、下划线与逻辑基线一起下移，贴合稿纸横线。

### 排版与导出

- **普通公文新增「横页排版」**：要素表单勾选后整份文件（含附件）排成横向 A4、左侧装订——版心 225×156mm、上下 28 / 26mm、订口 37mm、翻口 35mm，双面时镜像，页码单面居中、双面奇右偶左。PDF 仍落成竖向纸张加 `/Rotate 90`（双面打印选短边翻转），Word 走横向页面设置，预览纸张横放并按横向纸宽计算缩放与冻结层，三处一致。开关未勾时不写入快照，旧稿校验值不变。
- **序号表的分组行整格排楷体**（`（一）重点工作` 那一行），字号不变。判定口径单一来源：必须同时满足序号表、非表头行、首列、跨度铺满整行；普通表格里整行合并的「合计」之类不受影响。公文 PDF（Typst `kai` 标记）、研究报告 PDF（vendor mdx 同名标记）、预览（`table_cell_font` 走 `FONT_KAITI`）与 Word（楷体_GB2312 / FZKai-Z03）四条渲染路径同源。
- **插图按文件头识别格式**：Typst 原先按扩展名定格式，PNG 存成 `.jpg` 就解码失败，研究报告的插图尺寸也探不到；两支模板与 mdx 的尺寸探测都改成先读字节、由文件头定格式。
- 公文序号表的**预览列宽与 PDF 对齐**：序号列内容宽固定为两字，表头不再折行。

### 性能

- **页数改为按需计算**：状态栏的页数只在点它时才跑一次完整定稿排版，不再随停笔 650 ms 自动触发。实测三百多页的长稿此前这一次排版要 +543 MB 堆、峰值 818 MB（Windows 堆释放后还不还给系统），现在停笔不再占用；正文、要素、字体、编号、词表任一变化仍把旧页数作废、退回「未算」，但不自动排队重排。悬停说明写明按需计算的代价，这一行加了手型光标。

### 质量检查

- 两平台 CI 门禁（格式、clippy、2023 项自动化测试）全部通过。
- **修复 CI 报红**：序号表分组行与主题预览两处新增测试依赖随包字体度量，却漏了「本机没有 `runtime/fonts`（CI）时跳过」的守卫，使两平台 CI 失败；按仓库既有惯例补上守卫，本机有字体时仍照常断言。
- 本版新增的关键测试：公文与研究报告排版数据的 `kai` 标记、Word XML 的楷体字体名（含数据行负例）、`is_group_cell` 的四个条件、扩展名写错仍能出 PDF、页数统计「输入变化只作废不调度」等。
- `vendor/mdx` 补上此前遗漏的 `Cargo.lock`，避免 `--locked` 构建漂移。

### 文档

- **README**：自动化测试数同步为 2023 项。
- **使用帮助**：02 章补「页数按需计算」与锤子稿纸配色、源码目录布局的说明，05 章补「横页排版」选项，06 章补序号表分组行排楷体；`assets/help` 与 `docs/help` 两处副本逐字一致，25 章 = 正文 22 + 附录 3 的章节口径不变。
