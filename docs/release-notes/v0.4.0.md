## 公文助手 v0.4.0

本版本为公文预览加上右缘导航：一列细刻度映出全文结构，鼠标靠近即在刻度左侧铺开标题，指针最近的那条隆起放大，点一下直达该节。

### 预览导航

- 「公文预览」与「对照」两种显示方式的右缘常驻一列刻度，一条对应一个标题，按层级定长短；当前正在读的那一节用主色标出，随滚动实时更新。
- 刻度按标题在版面上的真实位置排布，因此刻度的疏密就是各节的真实长短——某一节明显长出一截，通常意味着结构还没拆开。
- 鼠标靠近右缘时，焦点附近的标题成列铺开：指针最近的一条最大最实，向外逐档缩小变淡，第五条之外隐去。底衬自右向左渐次化入纸面，没有边框也没有边界，标题看着是浮在公文之上。
- 点标题或点刻度即跳到对应章节，源码光标与版式预览同步就位。标题行之间的空档仍然穿透到正文，不影响在纸面右侧选字；滚轮也照常滚动页面。
- 导航里的编号与 DOCX、LaTeX 导出和版式预览共用同一套计数器，因此「一、」「（一）」「1.」「（1）」与成文逐字一致；附件区的独立编号、区段标记处的计数器重置也一并对齐。
- 可在「视图 → 导航」或设置页「录入与编辑器」一节随时开关，默认开启，该偏好跨稿件与会话保留。

### 工程与维护

- 发布流程改为从仓库内的 `docs/release-notes/<tag>.md` 读取版本更新说明，不再使用自动生成的占位正文；缺少说明文件时会在工作流中告警并回退。
- 新增导航相关的单元测试与界面集成测试，覆盖标题编号与层级、附件区计数器重置、预览与导航之间的定位契约，以及悬停铺开、点击跳转、开关生效等交互。

### 下载

- Windows x64 安装程序
- Linux ARM64 Debian 软件包（兼容 GLIBC 2.28）
- Linux AMD64 Debian 软件包（兼容 GLIBC 2.28）
- 面向 Arch / Omarchy 的 ARM64、AMD64 运行包与 `PKGBUILD`
- macOS ARM64 DMG

各安装包均附带 SHA-256 校验文件。
