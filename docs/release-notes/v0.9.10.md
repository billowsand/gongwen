## 公文助手 v0.9.10

本版本添了一件**新家伙**，补了**一件旧家伙**：主菜单多了「任务助手」——交办的事有三栏台账、有关系与完成依赖，还能把通知、纪要、领导交办的话粘进去让 AI 填表或拆成候选；分阶段写作则重新做了一遍，从「逐节重读原文、三百多次调用」改成**大块提炼、一次分配素材、短稿一次成文**，同批材料的真机耗时从 1 小时 40 分钟降到 55 秒。界面上跟着多一张「跟随 Omarchy」主题卡，表格支持多行表头与表头内合并，对照模式的预览上也有了跟随光标的那条竖线。

### 个人任务助手（新增）

主菜单「任务助手」。它管交办的事，不动公文正文与表单要素；数据存在稿件库同一个 `manuscripts.db` 的独立表里，随全量备份一起走。

- **三栏看板，不再整页滚动**：左边视图栏、中间列表、右边详情或表单，各栏自己滚。窗口窄于 900 时视图栏收成列表上方的下拉，窄于 650 时列表与详情单栏切换；宽窄三档都不出现双层滚动条。
- **视图表达状态**：今天与逾期、进行中的工作、等待 · 阻塞、待核对、待整理建议，其下是已完成 / 已取消 / 归档 / 回收站，再往下按分类过滤；每项右侧带计数，逾期数标红。原来重叠的「视图 / 状态 / 包含归档」三个筛选控件就此删掉。
- **关系与完成由程序判**：上级、前置、子任务、后续的循环、自引用与「子任务依赖上级」造成的死锁一律拒绝保存；进入进行中或完成前，前置必须已完成且已核对；重开前置会把进行中的后续标为阻塞，受影响的完成结果标「待核对」但**不撤销已经发生的事实**；删除不级联——子任务变独立，后续解除该前置并标待核对。
- **保存与放弃固定底栏**：表单分「要做什么 / 怎么安排 / 更多设置」三组，内容自己滚，按钮常在；两个期限配中文日历（可翻年月、点日即填、今天、清除），文本框照常能用输入法键入；前置任务改为「已选小标 + 搜索添加」。
- **提示就近、不再堆叠**：页顶的一次性提示几秒后自动消失，表单校验错误写在保存按钮上方，状态下拉切换失败写在它旁边；选「已取消」就地要求填理由。
- **界面数据有缓存、搜索只有一条查询**：按数据代号失效，不再每帧逐任务查库——此前搜索关键词非空时，N 个任务就是每帧 N 次 SQL。

### 任务助手：粘贴一段话，填一张表

- **「从文字填写」**：新建任务时表单顶部就能粘通知、纪要片段或领导交办的话。「识别并填入」只填**空白栏**；已有值的栏不覆盖，只给「AI 建议改为：…」并带原文摘录与「替换 / 忽略」；手改过的栏，AI 标记自动消失；底部汇总「AI 填了 5 栏，2 栏有不同建议」，可「全部撤销」——只恢复仍等于 AI 填入值的栏，人工改过的保留。
- **填什么、不填什么**：名称、完成条件、下一步与两个期限、协作分工、我的角色、分类、上级可以填；**状态、前置、待核对不由 AI 填**。角色只认「负责 / 配合 / 跟进 / 关注」，分类与上级只能取当前已有的（对不上就留空），不替人凭空造分类。
- **逐栏校验，不整批作废**：证据必须能在粘贴的原文里逐字找到、日期必须真实存在；核对不上的栏逐栏丢弃并计数（提示「n 栏因无法核对出处已丢弃」），而不是整段打回。
- **来源留痕在同一事务里**：保存时若用过 AI 填写，材料快照、任务与来源历史一次性落库，指纹带 `fill` 前缀，与批量整理的去重互不干扰；详情历史里点「原文」就回到当时的材料，不受原资料后来修改影响。
- **一段话里有多件事**：块底提示「这段文字里还有 2 件事」，点「转到批量整理」把同一段原文交给「待整理建议」，本表单内容保留。
- **「待整理建议」视图**：材料标题改为**选填**（留空取原文首个非空行，去首尾标点、截前 30 字；首行过短时用「粘贴材料 MM-DD HH:MM」），候选按来源材料分组，按类型只显示该看的字段，并排给「当前值 → 建议值」；新增任务候选可「编辑为新任务」在右栏打开预填表单。采纳前目标任务被改过就按过期拦下，卡片上这时才出现「以当前版本重新核对」。
- **迟到结果会被丢弃**：单任务填表走独立通道，与批量识别互不阻塞；草稿关闭、替换或数据库恢复后，晚到的识别结果不采纳。

### AI：分阶段写作重做

同批材料的真机实测：**1 小时 40 分钟、三百多次调用 → 55 秒、12 次调用**，交付前检查 0 条。

- **大块提炼**：按模型窗口成批投送（60k 窗口约一批 30k token），几份材料拼进同一次请求，观点按完整意思归纳。依据找得到原文就记精确位置，找不到如实标成「模型概括」，不再因逐字比对作废整批；交付前对全文关键事实的出处核对不变。
- **素材一次分配**：第四步改成一次调用把已提炼的素材分给各节，不再逐节重读原文；只重分改过的章节，保留手动移出与补入。
- **短稿一次成文**：目标 6000 字以内整篇一次写完，漏掉的章节退回逐节写；没分到素材的章节只写原则性表述。统稿限篇幅、去掉素材编号引用。
- **拟纲直接看逐条素材目录**：格式不对先提醒重试，仍不对就从「## 标题」认提纲。
- **全程关闭思考模式**，界面修掉输入即清空成果、单块失败不能续跑、统稿拼接丢人工稿等问题；入口从菜单移到起草页「开始」分区的第一组；页面模块按 2000 行规则拆成 `pages/` 下的若干文件。

### 界面主题：跟随 Omarchy

- **多一张卡片**：在 Omarchy 桌面上，设置页与菜单的「外观主题」多出一组「Omarchy 桌面」，其中只有「跟随 Omarchy」一张卡。程序找到 Omarchy 当前主题目录里的 `colors.toml` 就**现算**一套界面配色——按亮度排层级、按对比度兜底，所以二十几套内置主题与用户自装主题都能跟上。
- **只读**：不往用户的 Omarchy 配置里写钩子、不改模板。Omarchy 那边换了主题，回来再点一次卡片即重新读取；启动时读不到就本次退回默认主题，配置本身不改。
- **强调色实底上的字色**（`on_accent`）单列一项，原本六套主题的显示不变；23 套官方主题样本过了对比度与层级测试（样本 MIT，已登记第三方声明）。

### 表格：多行表头与按行高亮

- **多行表头**：分隔行之前连续的几行都算表头（MultiMarkdown 写法，单行写法的行为不变），表头内可用 `^^` 纵向合并，表头与正文之间不合并；各条表头行黑体居中，续页**整组重复表头**。公文（Word / PDF / 预览）与研究报告（vendor 的 mdx）同步支持。
- **序号表**：多行表头首列整列留空时，「序号」竖跨整组表头。
- **表格工具跟手**：光标在表头里插入 / 删除的是表头行，表头内可向下合并。
- **花脸稿**：分隔行写回在表头各行之后；顺手修掉表格改动段新行多于旧行时的越界崩溃。
- **按行高亮**：连续预览里的表格原先整张一起亮，现在每行表格对应一行 Markdown 源码——光标跟随、悬停、点击回跳与页边行号都按行走，光标停在分隔行上时亮表头。

### 排版细则

- **表格左对齐列改为两端对齐**：公文与研究报告的 PDF、Word 与预览三处同步，不再出现左对齐列右侧参差不齐。
- **附件说明前改空一行**：按 GB/T 9704「在正文下空一行」，原先留两行，现在 Word、PDF（Typst）与界面预览三处同步改一行。
- **会议纪要版头**：纪要标志与编号之间不再空行，标题与文号间距统一。
- **公函横向附件后的版记**：连续预览在最后一份附件自动横排时，不再把版记接到横纸里——附件画完恢复竖页几何、另起完整 A4 纸，按实际高度把版记推到纸面下方，与 PDF 的另页规则一致；最后一份附件是竖页时仍在附件后接排，不多添一页。

### 编辑与对照

- **对照模式的光标竖线**：源码光标复用选区的「源码字对纸面字」映射，在正文预览里对应的字前画出与编辑器同样式的竖线，光标所在段的底色随之调淡；光标停在 Markdown 标记或自动编号里时落在其后的第一个正文字前。表格、图片等整块元素与研究报告预览仍按整段高亮。推稿与闪烁定位一并增强。
- **标题聚焦能整节调序**：`Ctrl+Shift+H` 的对照编辑框里每条加上移 / 下移（`Alt+↑` / `Alt+↓`），连同子标题与正文整节搬动，编号跟着位置走；只在同一上级、首尾相接的节之间互换，区段标记挡住，紧贴标题的不编号标记随节走。改字与调序一次写回，光标跟着原节。

### Arch / Omarchy：pacman 离线安装包（新增）

发布页新增 **Linux x86_64 的 Arch 软件包** `gongwen-assistant-0.9.10-1-x86_64.pkg.tar.zst`（Omarchy 4 的 amd64 机器直接用）。下载后离线安装：

```bash
pacman -U ./gongwen-assistant-0.9.10-1-x86_64.pkg.tar.zst
```

- **在 Arch 里构建**：二进制链接的就是 Arch 自己的 glibc 与图形库（不是 Debian 的），文件选择框走原生 Wayland + XDG Desktop Portal（不依赖 GTK3）。
- **依赖不会写错**：包里的依赖列表由构建脚本从 pacman 数据库反查得出（`ldd` 出动态库 → 查归属包），再逐个核对包名确实存在；写错一个包名 `pacman -U` 会直接拒装，这类错误在发布前就被拦下。
- **离线可用**：应用与字体（PDF 由内置 Typst 引擎排版）都在包里，安装后不联网也能导出 Markdown、DOCX 与 PDF。
- **桌面集成**：菜单项、图标、稿件包 `.gwx` 的 MIME 类型一并登记。
