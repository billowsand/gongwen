## 公文助手 v0.9.6

本版本把**打印**收进程序自己：Windows、macOS、麒麟上是同一个对话框，从选打印机到页面预览、双面与手动翻面、按打印机记偏好，再到进度与取消；稿件包换成 **`.gwx`** 并登记了文件类型与文档图标，程序已开着时双击交给已开的窗口；主题默认跟随系统明暗、缩放改为预设档位。另有一轮**安全加固**：unsafe 用法收敛、崩溃面与资源上限、接口路径穿越与无上限响应一并堵上。

### 打印：三平台同一个应用内打印对话框

- **第一期：选打印机、份数、页码范围**。打印机清单带默认标记与状态（就绪 / 暂停 / 脱机 / 缺纸），默认选上次用过的那台；份数与「逐份打印」，页码支持全部、当前页或自定义（如 `1-3,5`，中文逗号、顿号、全角数字也认，`8-` 表示到末页），底部算出大概要几张纸。Windows 由 DEVMODE + `CreateDCW` 建设备上下文，**按实际大小与纸张方向出图**，修掉缩印约 4% 与横向附件被缩到七成的问题；macOS 与麒麟经 CUPS。PDF 查看器支持 `Ctrl` / `⌘P`。
- **第二期：双面、颜色、纸张、纸盒、缩放**。选中打印机后后台查能力（Windows 用 `DeviceCapabilitiesW`，CUPS 解析 `lpoptions -l`，不解析会被翻译的句子），对话框按打印机名缓存，只画能用的选项：没有双面单元的长边 / 短边置灰，单色机固定「黑白」，纸盒为空置灰。缩放分「实际大小（公文推荐）」与「适合纸张」，后者供纸型与版面不一致的外来 PDF 用。
- **第三期：按打印机记偏好、进度与取消、手动双面**。双面、颜色、纸张、纸盒、缩放按每台打印机分别记住，优先级是「用户动过的 > 文档默认值 > 这台打印机的偏好 > 打印机默认」，且只填用户还没动过的控件。打印中对话框不关，显示「正在送第 3 / 12 页…」与「取消」，页数多可「转到后台」；CUPS 结果带任务号回报在状态栏。**手动双面**让没有双面单元的打印机也能打双面：先打正面，按提示把整叠翻面放回，再点「继续打印反面」，奇数页会提示先取出最后一张，「反面倒序出纸」按打印机记住。
- **第四期：页面预览与按稿件给默认值**。对话框左侧按所选纸张的比例画出纸页并摆当前预览页，按实际大小换算毫米（放得下居中、放不下退回适合纸张），横页自动转向；纹理复用 PDF 标签已渲染的页，不为预览另起渲染线程，还没渲染的页显示占位并提示回到 PDF 滚动到该页。打开按双面排了页码的稿件或送批材料合并件时**默认长边双面**，整份横排默认短边；并给五条公文提醒（双面排却选单面、送批材料选单面、整份横排选长边、版面有红色却选黑白、所选纸张不是 A4 却用实际大小），只提醒不拦打印。
- **Windows「打印机首选项…」**：打开驱动自己的设置窗口（装订、打孔、水印等驱动独有选项），设过之后双面、颜色、纸张、纸盒四行以首选项为准并置灰，旁边「恢复」可以清掉，换打印机时自动清掉。
- **起草页功能区新增「打印…」**：只按当前覆盖策略导出一份 PDF，排好后自动在应用内打开并弹出同一个对话框，不用先导出、再切到 PDF 标签去点打印。排版失败时不会打开对话框，状态栏说明「PDF 没有排出来，无法打印」；本机没有打印服务时按钮置灰。
- 打印对话框代码拆成 `src/print/` 模块文件夹（`dialog.rs` 超 2000 行按约定拆分）；首选项逻辑去掉 `#[cfg(windows)]`，改为运行时按 `print::HAS_DRIVER_PREFERENCES` 决定画不画按钮，所有平台都可测。

### 稿件包：`.gwx` 后缀、文件类型登记与单窗口转交

- **稿件包改用 `.gwx` 后缀**，保存框删掉后缀时自动补上；明确手写 `.zip` 的仍然保留，批量导出 PDF 仍是 `.zip`，包内格式不变、**旧 `.zip` 照常导入**。
- **安装即登记文件类型**：新增 `.gwx` 文档图标（48 px 及以下用无字版），Windows 安装包在 HKCU 登记「双击用公文助手打开」并显示图标、卸载时清除，升级包同样生效；Linux 增加 `application/x-gongwen-package` MIME 定义、desktop 声明 `MimeType` 并接收 `%F`，deb 与 tar 包都装 MIME 定义与图标，`verify-deb-install.sh` 逐项核对。
- **程序已开着时不再另开窗口**：配置目录 `instance.lock` 独占锁 + inbox 收件目录（不开端口、不加依赖），后起进程把路径写成请求后退出，主实例每 300 毫秒取请求、唤到前台并把稿件包送进导入队列；收件目录里超过 10 分钟的请求启动时丢弃，锁不可用时照旧开独立窗口，`--new-window` 跳过检查。
- 启动参数与拖放进窗口的稿件包统一走 `receive_import_package`：先复制到缓存目录暂存再排队，前一个处理完自动弹下一个；窄屏单页详情时模态框照常绘制。

### 界面与主题

- **主题默认跟随系统明暗**：浅色系统用 Claude 奶油、深色系统用复古暗，系统切换深浅模式时界面主题、公文纸面与应用图标跟着换；设置页与菜单「外观主题」都能开关，手动点选任一配色即改为手动选择。
- **界面缩放改为预设档位**：80% / 90% / 100% / 110% / 120% / 150% / 175% 点选即用，旧配置里手填的自定义比例仍显示为选中档位。
- 稿纸主题收紧顶栏与纸签排布（顶栏高度 30、标题居中改为应用身份、稿名只留在纸签），输出区在宽窗下左右分栏；便签主题下的 AI 助手侧栏重新协调配色；预览栏的窄栏排版与空状态文字修好。

### 安全与稳定性

- **unsafe 用法收敛**：全 crate 默认 `#![deny(unsafe_code)]`，仅四个 FFI 模块在声明处放行；Win32 句柄与剪贴板改用 RAII 守卫，每块 `unsafe` 写 SAFETY 注释；去掉用切片首地址相减反推偏移的写法。
- **崩溃面**：用户数据可触发的 `unwrap` / `expect` / `unreachable!` 改为错误返回或降级，锁中毒不再连带崩溃，修掉兜底分支在 `while` 循环里跳过自增导致的死循环。
- **资源上限**：新增 `src/file_limits.rs`，读用户交来的文件先卡体积并限量读取；压缩包按实际解压字节累计上限，插图与同步导入共用单张图片上限。
- **外部调用**：调外部进程传绝对路径并加 `--`，SQL 的表名走白名单，Windows 保留设备名；数据接口地址里的路径变量拒绝 `.` / `..` 路径段（防模型被提示词诱导借规范化访问同主机的其他路径），单篇 PDF 编译改用 `tempfile` 随机独占目录，模型 / embedding / rerank 的响应体限 32 MB、流式单行限 16 MB、出错响应只读 64 KB；接口密钥原子写。
- 依赖侧升级 rustls、rustls-webpki、webpki-roots、quinn-proto 到修掉公告漏洞的小版本，CI 增加 RustSec 依赖漏洞扫描并补 `checks: write` 权限。
