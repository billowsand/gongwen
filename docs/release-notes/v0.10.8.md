## 公文助手 v0.10.8

本版本增加 AI 全版与非 AI 版的独立构建和 Windows 安装包，提供四类内容的一键清空入口，并修复公文两行标题的折行优先级；品牌图标与发布文档同步更新。

### AI 全版与非 AI 版

- **同一源码可一次构建两个版本**。`scripts/build-editions.py` 分别产出 `gongwen-assistant`（AI 全版）与 `gongwen-assistant-no-ai`（非 AI 版），构建后校验实际版本，避免二进制与安装包混用。
- **非 AI 版保留完整离线办文底座**：起草、九种文种、预览、稿件库与搜索、版本对照、送批、导入导出、打印、输入法、应用锁、规则校对和手工任务继续可用；不编译 Pi、模型服务、资料库、维基知识库、AI 作业与数据接口工作台，并使用独立简明手册。
- **两版数据与安装入口相互独立**。非 AI 版使用独立配置目录、单实例通道、安装标识、安装目录和桌面入口；两版都能打开普通稿件并继续编辑、查看版本和导出。
- **Windows 发布流水线分别组装两版安装程序**。AI 全版继续携带校验过的 Pi 运行时与写作技能包，非 AI 包明确排除这些 AI 运行资源；两个安装包均附 SHA-256 校验文件。

### 数据清理

- **设置页新增「清空数据」**。入口位于「文件与现场 → 数据备份」，二次确认后永久清空标准词库、全部文稿（含归档）、资料库与维基库，包括历史版本、送批关系、附件、插图、图表缓存与检索索引。
- **保留范围写清楚**：应用设置、公文词库、校对词表、输入法词表和任务助手数据不删除。数据库内容在一个事务中清理，归档稿件不再成为整库清空的障碍。
- **清理后工作区立即复位**：当前稿件和 PDF 标签关闭，稿件、资料、维基与任务表单里的失效缓存一并清除，防止旧内容被自动保存回库；后台任务运行时拒绝执行清理。

### 排版与品牌

- **公文两行标题优先上宽下窄**。需要折成两行时，先寻找上行不短于下行的断点，避免标题排成上窄下宽的倒三角；找不到合适断点时仍保留完整折行与原有字号、行距规则。
- **应用与稿件包图标统一为单色品牌标识**。更新系统图标、各主题应用图标和 `.gwx` 文档图标，并补齐 macOS `icns` 资源。

### 工程与维护

- CI 与 Release 当前只启用 Windows x64 和 RustSec 依赖漏洞扫描；其他平台的构建与启动冒烟作业保留在工作流中，可按需恢复。
- 双版本冷构建需要两轮编译与测试，Windows CI 和 Release 的作业上限统一提高到 180 分钟，避免沿用单版时限导致构建被中途取消。
- 新增《网络安全等级保护第五级要求检索与差距分析报告》，记录第五级要求检索、产品现状与差距，供后续安全建设核对。

### 文档

- README 增加双版本构建与双 Windows 安装包口径，补充「清空数据」入口；硬数字重新统计为约 **33.6 万行 Rust、3106 项自动化测试、24 章 + 3 附录**。
- 使用帮助第 21、22 章补充四类内容的清理范围、保留范围与不可恢复提示，并将全量备份格式统一写为加密 7z。

### 下载

- Windows x64 AI 全版安装程序：`gongwen-assistant-0.10.8-win-x64-setup.exe`。
- Windows x64 非 AI 版安装程序：`gongwen-assistant-no-ai-0.10.8-win-x64-setup.exe`。

两个安装包均附带 SHA-256 校验文件。本次只发布 Windows x64；macOS 与 Linux 的打包作业保留在发布工作流里（当前停用），需要时再启用。
