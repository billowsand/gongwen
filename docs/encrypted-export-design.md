# 独立密码加密导出（2026-11-07）

本轮用户确认：优先采用文件自身加密，无需自动创建 VeraCrypt 临时盘；导出密码必须在设置中独立设置，不能与应用登录密码一致。
本文更新 `encrypted-resource-lifecycle.md` 中 PDF/Word/源码包作为明文输出的旧口径。

## 产品规则

- 「设置 → 导出格式」提供“加密导出文档”可选项，默认开启。开启后需要独立导出密码，不显示输出风险确认；关闭后生成普通文件，每次先明确确认明文泄露风险，取消不输出。未启用应用锁时文档明文导出也每次确认。
- 选择加密时，没有设置密码、设置损坏或失去解锁密钥均导出失败，不自动降级。关闭加密不删除独立密码，旧加密 PDF 仍可在应用内解密预览。
- 新设导出密码对两套登录验证器做只读匹配，命中任一个就拒绝，不提示哪个命中；修改登录密码时也拒绝与当前工作区保存的导出密码相同。密码规则沿用导出密码强度，额外限制 UTF-8 长度不超过 127 字节，避免 PDF 口令截断后与 Word/7z 产生差异。
- 设置页「随机生成」按音节拼读生成三个词（辅音 + 元音 + 可选尾辅音），词与词之间插符号与 2～3 位数字，每个词首字母大写（形如 `Varen#Millu72Tako`），整体再过一遍导出密码强度校验；不生成十六进制随机串，便于口述、手抄与记忆。
- PDF：AES-256，标准安全处理器 V5/R6，正文与元数据加密，打开密码和所有者密码均为非空的独立导出密码。不以复制、编辑、打印权限限制代替保密。
- Word：Office Agile Encryption，AES-256-CBC、SHA-512、100000 次密码派生，完整 OOXML 包加密；仍是 `.docx`，不使用限制编辑或普通 ZIP 加密冒充 Word 原生加密。
- Markdown/Typst 源码包：`.zip` 改 `.7z`，AES-256、文件头加密，显式设置 `2^19` SHA-256 派生次数。份号清单、单独的写作成果 Markdown 也使用独立 7z。
- 覆盖正常/快捷导出、重新导出到指定位置、花脸稿、签收单、传发任务单、送批材料合并 PDF、稿件库 PDF 附件另存，以及内存 PDF 的“另存并系统打开”。主文与附属文件使用本次读取的同一导出密码。
- 普通工作区保持原有导出行为。稿件包、批量 PDF 集合、全量备份保持现有独立包密码，不与此设置混用。词库、风格等其他普通文件出口仍走现有明文风险确认。
- 只有明文文档导出逐次确认；加密文档不提示。打印、剪贴板及其他明文出口保留各自确认，不因加密开关而免除。文件名与大小可见，解密、解压、外部另存、打印队列、纸件与系统缓存仍是应用外边界。直接打印/预览继续内存处理，不要求设置导出密码。

## 实现

`src/export/protection.rs` 提供独立口令加载、内存加密、原子写出和 PDF 内存解密。
`export_artifacts` 与花脸稿先捕获完整内存产物，对全批格式加密成功后才逐个原子写出；源码 ZIP 在内存逐条转换为 7z。单文件另存只写所选成品；普通导出同时保护份号清单。
签收与传发 PDF 原先直接 `fs::write` 的出口改用统一内存输出。
送批材料先合并再加密，不对中间单件重复加密。

设置页在后台验证口令并保存，避免 Argon2 验证阻塞 GUI；输入草稿和传递的口令用 Zeroizing，在锁定/切槽丢弃工作区时释放。
开关和密码一起存储为槽位独立的 `.export-password` GWA2 JSON 文件（兼容之前的纯口令密文，按开启处理），绑定槽位/用途/路径，不进入 `AppConfig` 或配置历史。此文件登记进迁移、备份、擦除名单；停用应用锁时直接清除保存的密码，不解成普通文件。后台任务检查槽位及密钥上下文，错误状态拒绝输出。

PDF 查看器在后台使用当前保存的导出密码解密到内存，再交 hayro 渲染；打印同样先在后台解密，不写临时 PDF。更换导出密码后，旧成品不会自动改密，应用内无法打开时提示用系统阅读器输入旧密码。

## 边界

- 导出密码不由登录密码派生。将导出密码交给收件人，不会同时交出登录密码。
- 为支持设置后日常导出，导出密码保存在由本地 DEK 加密的密文文件中。因此，取得本机解锁权限/DEK 的人仍可能取出保存的导出密码。这不是两套互不解封的密钥系统；界面明确说明这个边界。
- 已有输入原件、历史导出、SSD 残留和系统快照不会自动处理。启用此功能不会删除旧明文成品。
- 全批加密成功后才开始写出，但多个成品之间不是文件系统事务：磁盘写入失败时可能只写出部分**加密**文件。单个已有目标不会被半写文件截断。
- 当前加密导出不写普通导出的隐藏清理清单，避免清单中包含标题；历史名称不自动清理，用户原有文件不受影响。
- Office/WPS/阅读器的恢复文件、交换文件、休眠、系统缓存、外部模型服务与打印机不在应用可控范围。
