# 输入法展开找字

2026-10-30。针对只记得前两码、需要浏览候选的场景，替换逐批增加上限的翻页方式。

## 最新提交审阅

`dc24ceb` 修好了逐码提示只显示 18 条的问题，但没有独立找字入口：逐码提示默认关闭时无法查前缀；打开后候选总页数随补批变化。每批都从头查询、去重并重建布局，后续翻页成本递增。普通候选选择与大范围查找共用一套隐含状态，难以理解。

## 交互与确定性规则

- 平时保持精确候选条；逐码提示仍是可选的前 18 条预览。
- 打到两码以上时，按向下、下一页（设置的翻页键或 PageDown）或点候选窗表头右侧的向下箭头，进入找字面板。第一次展开停在第一页，不跳过任何候选；不依赖逐码提示开关。
- 只打一码时不能展开，也不补逐码提示：候选条只列编码正好是这一码的字词，翻页键照常翻候选条。随包词表里 `y` 开头约 3,700 条（每行 5 格也有七百多行），`yi` 开头约 350 条，一码浏览没有实用价值。
- 横排候选向下就展开；竖排候选向下先在本页逐个挪，挪到本页最后一个再展开，向上照常回挪。能展开时候选条表头不标页码，下一页就是展开。
- 展开后是仿 macOS 的滚动网格：每行与候选条一样多格（设置里的「每页候选数」，默认 5），露 `VISIBLE_ROWS`（4）行，其余用滚轮或滚动条翻。只画看得见的行（`ScrollArea::show_rows`），几百条候选也不拖慢。
- 列宽按全部候选里最长的词（最多 5 字，再长截断加省略号，悬停看全词）与最长的词后小字量，各列等宽，滚动时不跳。辅码（逐码提示还要打的码、更短的简码）跟在字后，与候选条一样。
- 上下每次挪一行，左右每次一格；翻页键一次翻四行、停在同一列，边界停住、不循环。高亮挪出可见区时网格自动滚到刚好露出它（`follow_highlight`），鼠标滚过的位置由界面回写 `top_row`。
- 序号只标在高亮所在的那一行，别的行留出同样宽度不画；数字键选的是这一行。点击上屏按点中的那一格算，与高亮在哪一行无关。
- 表头只有编码串、全部／单字／词组筛选与收起箭头。展开、收起用项目自带的 Lucide `chevron-down` / `chevron-up` 图标，不用文字或字符；不画下一码筛选、翻页按钮、页码与快捷键提示。筛选只是浏览条件，不写入组码。
- 网格宽度按「格宽 × 列数 + 滚动条」算，不取滚动区量到的宽度：表头按网格宽度把箭头顶到右边，取量到的会与表头互相撑大（实测撑到五百多像素）。
- Esc 首次收起，第二次清码；继续输入或退格重新精确组码并收起。回车仍明确上屏原始编码。
- 精确码候选在前；后续编码按码长、编码字母顺序排列；同码严格保持词表人工顺序；同词异码只展示第一个，屏蔽词不出现。不自动调频、不引入拼音或模型。
- 只在主动展开时一次收集当前前缀的全部有效候选，后续翻页仅修改索引；按键普通预览仍有限额。筛选先于同词去重，避免一个词的其他编码被误过滤。页数稳定，筛选后回第一页。
- 点击面板控件或面板里的空白处（编码串、格间空隙、滚动条）都把焦点要回编辑框：egui 点在编辑框外就交出焦点，下一帧 `begin_frame` 见焦点变了会清码。面板跟随光标、受视口约束。
- 面板里右键置顶、调序、屏蔽（含 `Ctrl+Delete`）后，个人层存盘走 `reload_candidates`：面板不收起，筛选保留，高亮跟着原来那个词，词被屏蔽就停在原位附近。

## 验证

覆盖默认关闭逐码提示时两码展开、超过 18 条的浏览、同词异码与隐藏条目、单字／词组筛选、末行数字越界、方向键、Esc 和继续组码。用 egui 测试检查面板控件与点击流程；真实系统焦点和不同缩放下的边缘位置仍需 GUI 验收。

## 本次实施结果

已实现上述规则；`Browser` 缓存未去重候选，筛选先于去重，翻页与筛选都不重新查词表。
生成概念图使用内置 image_gen，图与完整提示词保存在生成物目录
`output/ime-design/candidate-browser.png`、`output/ime-design/prompt.txt`，不提交生成物。
图中的字码仅为示意；实际界面使用当前词表与应用主题。

验证：`cargo test --locked ime:: -- --nocapture`：47 通过、3 忽略；
`cargo fmt --all -- --check`、`cargo clippy --locked --all-targets -- -D warnings` 通过。
全量 `cargo test --locked --all-targets`：2545 通过、39 失败、80 忽略；
失败逐项检查均为 `PermissionDenied / Operation not permitted`（本机端口或文件访问），
没有调整相关测试。全量之后又完成了浏览候选缓存收敛，并重跑输入法测试与 clippy 通过。
真机焦点、屏幕边缘与 125%／150%／200% 缩放的目视验收尚未完成。
