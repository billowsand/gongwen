# 日常使用体验：第一步交接

实施日期：2026-09-30。范围为快捷查找、配置保存可靠性和关键逻辑回归测试。

## 已完成

- 顶部「快捷查找」及 `Ctrl+K` / `⌘K` 打开同一个浮层，支持中文、全拼、拼音首字母、文号和词库别名。原文精确匹配优先，最多显示 50 项；方向键选择、回车打开、Esc 关闭。
- 对象范围包括当前工作稿、稿件库、标准词库和常用页面。当前工作稿使用实时标题，重复稿件按数据库 ID 排除；打开时按稳定标识定位，归档稿进入只读详情。
- 搜索只读取稿件列表元数据与文号需要的两个要素字段，不载入正文。索引在打开浮层时建立，本期未引入后台常驻索引。拼音由已有 `pinyin` 库生成，采用逐字读音，多音字不保证全部读音都可命中。
- 配置与记住的 ZIP 密码复用已有 `tempfile`：同目录暂存、文件刷盘、原子替换，Unix 下限制文件权限并刷目录。写入或替换失败不先删除旧文件；目录刷盘失败发生在替换之后，此时新文件可能已经生效。主题、纸面、图表样式与字号保存失败会显示提示。
- 引入运行依赖 `nucleo-matcher`，以及仅用于开发的 `proptest`、`insta`、`egui_kittest`。新增 20 项测试，覆盖检索排序及界面操作、输入法提交、空输入收起与固定位置、关闭浮层、配置写入失败、中文修订锚点与撤销、三方合并和 Markdown 解析快照。
- 两份快捷键帮助同步更新。MPL-2.0 许可证放在 `runtime/licenses/`，便携包脚本单独复制，避免外部 runtime 清单缺少它。

## 经确认的快捷查找外观改造

参考 imagegen 设计稿，采用紧凑的搜索浮层。打开时只显示搜索框并自动聚焦，不显示默认结果、标题、说明段落或单独的关闭按钮；空白输入不触发打开。输入后结果向下展开，清空后收起。浮层按顶边锚定，结果数量变化不改变搜索框位置。

搜索框使用 64px 高度、14px 圆角、细边框和轻投影；框内保留 Esc 提示，也可点击它或浮层外关闭。条目采用 64px 两行结构，包含图标、标题、文号或文档类型、状态和日期；已打开及只读标记独立展示。选中项使用当前主题的淡强调色与左侧标线，原文命中的词在标题中强调。长标题和次要信息省略显示，悬停可看完整内容。

浅色、深色均使用现有主题色；次要文字由主题的柔和文字色与提示文字色混合，提高文号、日期的可读性。搜索图标、普通文稿图标和回车箭头直接绘制，其他图标复用已有资源；回车箭头不依赖字体是否包含该字符。

已在本机实际应用中检查空输入、输入结果、无匹配、清空收起及奶油／德古拉主题，核对后恢复原主题。8 项快捷查找测试通过，涵盖鼠标、键盘、输入法、固定位置及关闭方式。
