- calamine：0.30.1 → 0.36.1；移除 quick-xml 0.37.5，复用已有 quick-xml 0.41.0 与 zip 8.6.0；根 ZIP 仍为 4.6.1。
- 新增业务契约测试：共享/内联字符串、Strict/Transitional 工作簿、xml:space、ASCII 与全角空白、人员编码、内部空格、5000 个唯一属性和截断 ZIP。业务解析代码不变。
- Excel 导入相关测试 8 项全部通过；格式、全目标检查、clippy 零警告均通过。
- 正常权限完整串行测试：1490 通过、0 失败、37 忽略，38.83 秒。新增一个默认忽略的 release 性能探针，不计入普通测试耗时。
