# 加密工作区的光盘交付

起草页导出可以选择密码加密文件、已认证 IS903 虚拟光盘或实体光盘。IS903 和实体光盘共用内存中的 ISO 9660 / Joliet 数据镜像。普通文件导出须当次输入设置中保存的独立导出密码；稿件包、批量 PDF 包和备份使用各自的密码对话框。词库、校对表和其他含工作区数据的辅助导出用文件名加密的 7z 保留内部原格式。

## 设备与权限

- IS903 在「设置 → 导出格式」认证。记录按工作区加密保存，不随新全量备份移机。介质选择和写入前均检查当前工作区授权；后端另行绑定设备连接。白名单根据硬件上报的 USB 标识、序列号和版本，不能防御能仿造这些标识的设备。
- macOS 的 IS903 写入需要独立安装签名的 `gongwen-is903` 和同架构 libusb 1.0.30 或以上。发布时用 `scripts/package-macos-is903.sh` 从可信构建产物生成签名并公证的安装包，系统负责安装到 `/Library/PrivilegedHelperTools/org.gongwen.is903`。普通公文助手以当前用户运行，写入时系统授权启动专用助手。
- Linux 的 Debian 和 Arch 包安装专用助手并声明可选运行依赖。IS903 需要 `sg` 内核模块、`usb-storage` 驱动、`pkexec`，已挂载介质的卸载还需要 UDisks。实体光盘依赖 `libburn.so.4`、带 `diskseq` 的内核和刻录机的访问权限。
- Windows 的 IS903 走系统 SCSI 直通。实体光盘走 IMAPI2。是否可用取决于终端设备和访问策略。
- 实体盘目前支持空白 CD-R、DVD-R、DVD+R，单会话封盘。三平台均要求回读验证成功才报告完成。

## 数据边界和验收

应用把稿件成品和镜像保留在内存，在写入前检查容量，刻录过程不经明文临时文件。IS903 写入会覆盖先前的卷，短镜像覆盖长镜像无法证明未覆盖区域已清除。介质写入开始后失败时应按可能已有明文处置。系统交换空间、休眠、崩溃转储、接收端自动索引，以及既有的打印或剪贴板操作需要结合终端管理策略。应用内打开或导入光盘文件使用原有文件和稿件包入口。

发布验收用非敏感稿件验证中文文件名、Word / PDF / 源码包和随行单据。逐平台验证未认证和撤销、授权取消、连接更换、写入失败、容量不足、宿主机文件写入跟踪和最终回读。IS903 另做断电拔插后的只读回读；实体盘回读要用实际参与部署的刻录机和盘片。aiburn 真机记录是 IS903 协议的依据，产品的签名安装包和实体刻录机组合需单独验收。
