更新时间：2026-11-05。本文件是当前进度入口；各阶段 TASK、原始报告和模型产物保留历史，不用它们的“尚未实现”或单次成功覆盖当前结论。审查依据见 [退役审查](ai-agent-retirement-audit-2026-11-05.md)，本轮修复与验证见 [收尾记录](pi-implementation/retirement-fixes-2026-11-05.md)。

## 已实现的当前产品

- 新写作任务统一由 Pi 执行，常规/分阶段共用 Durable Harness；旧流程没有生产新建入口。
- 按实际部署窗口使用材料，优先整篇，超限按大章节/段落切分；提供日期/星期/时区与标准组织背景。
- 内置技能 7 个：6 个写作/提炼技能、1 个设置页风格学习技能。全面审校、事实核查与政策核查退出新任务，不迁回 Pi。
- 正文、清单、风格 JSON 分别走 document/report/style 通道。正文由界面线程直接写入，保留基线、选区、引用、只读及精确撤销保护；已入库非空稿写入前按需要自动提交版本。
- 设置页风格学习走 Pi，结果只进编辑器，用户保存才更新风格库；写作只读风格。
- 模型主调用收敛为写作模型与文字复核；问答、检索重排、数据接口 AI、任务助手识别使用写作模型，一次性调用不因此变成多轮 Pi 任务。
- 2026-11-05 收尾已修复领域工具 60/84 额度及常规转分阶段追加；已选 Pi 的新调用不再借隐藏旧起草备用。未挂载的旧技能管理器已删除，数字解析与提问校验已从旧编排解耦。
- Pi 可用 api_search/api_call/api_read 调只读接口，长结果按运行目录缓存、恢复后可续读。停止后的慢请求结果丢弃，在途槽位限制为 4；底层请求仍可能运行到结束。
- 固定 Node/Pi 依赖、运行时 manifest、打包及多平台 CI 骨架已接入。

实现不等于业务与目标机验收通过。真实模型和安装版验证以带版本、输入哈希的实际记录为准。

## 历史兼容与取消项

旧写作页是只读查看/导出/复制；旧侧栏轮次在过渡期仍可恢复原执行，提案与字段建议仍按原人工采纳权限处理。这两类“旧任务”不可混称全部只读。

5D 达标后按顺序退出：停止旧恢复/重跑 → 退旧检查点写入与执行 → 退 skill_job → 退 engine/router/ops。删除前先解耦共享引用；旧 JSON、历史成果、提案权限和必要 DTO 仍可读，不把旧检查点解释为 Pi 检查点，不自动删除用户技能或数据库历史表。

数据接口工作台及 agent::api/api_import/apidef、ai_services、知识库与确定性检查是现役共享能力，不随旧引擎退役删除。

以下旧设计不再继续实施：旧 DSL 内核第 5 期预算/算子并行、goto/loop/子图、固定清单确认与证据取舍流程、字段抽取生成链路。当前需求由 Pi 阶段/预算/ask_user 承担；要素抽取按已确认决定直接退役，保留旧回放与采纳。
