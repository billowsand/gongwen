# 公文引用：方案与交接

## 结论

公文引用就是正文里的普通文字 `《名称》（发文字号）`，不另存标记、注释或 ID。程序按
确定性规则识别，按文号与名称实时比对稿件库和公文登记簿，给出规范写法、改为来源写法、
登记等操作。原先的 `{{公文:UUID}}` 标记 + 文末 `<!-- gongwen-reference JSON -->` 快照
定义已整体移除，旧格式不兼容（用户确认：旧格式不需要兼容）。

改为纯文字的理由：源码可读；从 Word、记事本或外部 AI 粘贴进来的文字直接能识别；合并、
同步 ZIP、导出、花脸稿、复制粘贴里针对引用的特判全部删除，引用跟其他文字一样处理。

## 识别规则（`src/document_reference.rs`）

1. **有文号**：`《…》` 紧跟一对括号（全角半角、可嵌套），括号内经 `normalize_number`
   规范后符合「代字〔四位年份〕序号号」（`is_document_number`），就认作引用。
   `（试行）`、`（征求意见稿）`、`（2026年版）` 不符合，不会误认。
2. **无文号**：单独的 `《…》` 只有与稿件库或登记簿里某份无文号文件同名才认，避免把法律、
   书名当公文。识别时由调用方传入判断函数；不查库的地方（校对、AI 闸门）只认有文号的。
3. 代码围栏、行内代码、公式、反斜杠转义里的书名号不算；引用不跨行。
4. 规范写法：外层全角括号、年份六角括号、序号不编虚位（GB/T 9704）。`Citation::standard`
   判断正文写法是否已规范。名称里套的书名号按规范改为〈〉（`clean_title`）。

`normalize_number` 接受方括号、圆括号、方头括号、不写括号、空格或横线分隔、「年」「第」
字样、全角数字；认不出四位年份时只去空白，交给用户看预览核对。

## 公文登记簿（`src/manuscript/registry.rs`）

表 `document_registry`（名称、规范后文号，无文号为空串）与 `document_registry_aliases`
（更正前的写法），幂等建表不占 `user_version`。名称与文号都相同的再次登记直接复用。
更正登记时旧写法记为别名，引用了旧写法的文稿据此提示「来源已变」；改回旧写法时别名
随之换掉。删除登记不影响正文文字。登记簿暂不进离线同步 ZIP：对方机器上只是显示未登记。

## 比对（`src/draft_page/references.rs` 的 `CitationIndex`）

来源清单：登记簿在前，稿件按已发布 / 已归档优先；稿件取最新提交版的名称与文号，没有
提交版时取工作稿并说明。比对顺序：名称与文号都对上 → 一致；对上登记簿别名 → 来源已变；
文号对上 → 与来源不一致；名称对上（来源有文号）→ 与来源不一致；否则未登记。
未登记不是错误，只给「登记」入口。稿件只比当前取用的版本，不翻历史版本：名称或文号
单独变化已能由「与来源不一致」发现，两者同时变化的情形少，暂不处理。

## 界面

- **选择来文**：列表只显示插入后的样子，登记簿条目标「登记簿」；手工填写默认存入登记簿；
  选中登记条目可更正或删除。插入的就是纯文字。
- **本篇引用**：正文里识别出的引用按（名称，规范文号）合并成一条，有问题的排前面；
  操作有定位、再次插入、改为规范写法、改为来源写法、登记、打开来源，以及「全部改为规范
  写法」「全部登记」。改写不关弹窗，冻结的正文与插入点随之更新。正文里有引用、又没选中
  文字时，打开面板直接进「本篇引用」。
- **源码编辑框**（`src/draft_page/citation_marks.rs`）：识别出的引用画细虚线，有问题的画
  橙色；指针停留 0.35 秒弹出卡片，给出状态与同样的操作，操作交回编辑器执行（一次撤销）。
  来源清单缓存在 `DocState::citation_index`：第一次用到时读库，引用面板关闭或在卡片里
  登记后换新。别的标签页改了来源稿件，要重新打开面板才会反映。

## 闸门与校对

- `proofread_rules`：写法不规范报必改（RULE-CITATION-NUMBER），带一键改法；其余规则与
  词表校对在屏蔽引用后的文字上跑（`masked`，字节长度不变），引用名称里的字不会被改。
- `ensure_preserved`：AI 整篇提案、起草结果、规则修订采纳前比较有文号引用的规范写法计数，
  改名、改号、增删都拒绝；只把括号改规范不算改动。
- `ai_guard`：有文号引用的规范写法作为 `FactKind::Document` 事实锁定；提示词要求逐字保留。

## 已知局限与后续

- 登记簿不随同步 ZIP；需要时再设计合并规则（按名称 + 文号去重）。
- 预览、导出里的引用不做特殊标示（就是普通文字）。
- 编辑框之外的对照编辑器（版本对比）不画引用标记。
- 来源清单在稿件很多时首次读库会有可感知的耗时，目前只在打开面板与编辑框第一次显示时读。
