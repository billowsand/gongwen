# 公文助手使用帮助

<!-- [目录] -->

<!-- [摘要] -->

公文助手是一台离线运行的中文公文写作桌面应用：大语言模型只起草 Markdown 正文，行文要素、版式规则与导出结果由本地程序控制。本手册按“走进公文助手、写一篇公文、AI 能力、词表与知识、稿件、任务与设置”五个部分组织，另附快捷键、常见问题与术语表三篇附录。

第一次使用，先读第一部分；想尽快出第一份稿子，直接看第{@chap:quickstart}章“五分钟出第一份稿子”。本手册本身就是一篇研究报告，与你在起草页写的研究报告走同一套预览与排版，书中的示意图都用 Mermaid 写成，左侧大纲可以跳到任意章节。
