## 模型与连接

### 模型连不上怎么办

1. **服务起了吗**：LM Studio 要启动 Local Server；Ollama 要执行 `ollama serve`；
2. **端口对吗**：LM Studio 默认 1234，Ollama 默认 11434；
3. **路径带 `/v1`**：OpenAI 兼容协议要 `/v1` 结尾；
4. **防火墙**：本机回环（127.0.0.1）一般不拦，改过防火墙规则要检查；
5. **三个接口独立**：对话、Embedding、Rerank 分别配，不用的留空。

点「测试连接 / 刷新模型」诊断，能列出模型名就算通。

### Ollama 的重排怎么配

Ollama **不提供 rerank 专用端点**，重排方式选「**用对话大模型重排**」，不能选「专用端点」。用对话模型打分同样可用。三个接口地址都填 `http://127.0.0.1:11434/v1`。

### 换了 embedding 模型，检索不准了

**必须重建索引**。不同模型的向量空间不同，旧向量在新模型下没意义。程序在换模型后会提示，点「重建索引」即可。

## 导出与版式

### PDF 导不出来

检查：

1. 设置「导出格式」里 **PDF 有没有勾**（或直接点功能区「仅 PDF」）；
2. 正文是否为空（唯一导出闸门）；
3. 排版是否失败（审校抽屉红色提示框写明错误）。

排版失败**不阻断导出**：`.md` / `.docx` 照常生成，只是 PDF 缺失。修好后重新导出。

### 排版失败的常见原因

| 原因 | 排查 |
| --- | --- |
| 本机字体被删 | 勾了「使用本机字体编译」但字体文件没了，程序自动退回内置并提示 |
| 随包字体缺失 | 程序目录下 `runtime/fonts` 不完整；研究报告另需 TeX Gyre Termes 与 JetBrains Mono，缺了只挡研究报告 |
| 图片路径失效 | 手改过 `images/` 相对路径；找不到的图会略过并提示，不会让整份失败 |

研究报告的公式写错不会让 PDF 失败：排不出的公式按源码印出，导出结果里提示是哪一条。

### 生僻字排不出来

内置字体（方正系列）全部覆盖 GBK，「喆」「赟」「堃」这类字直接就能排，**不必配置**。

要排 GBK 以外的字（如「𠮟」这类扩展区汉字），在「设置 → 编译字体 → 兜底字体」另选字库更大的本机字体。所选字体也漏的字，仍由内置兜底接着兜。

### 字体集合（.ttc）为什么不可选

`.ttc` 一个文件装多个字面（如 `simsun.ttc`、`msyh.ttc`），按文件加载必须额外指定是哪一个，因此**不可选**。请找单字面的 `.ttf` 版本。列表只收 `.ttf` 与 `.otf`。

### Word 导出后字体变了

`.docx` 嵌的是字体名引用。目标机器上装了**同名字体**才有一致效果。否则 Word 按字体名回退。要绝对一致，导出 PDF。

### 页码位置不对

双面打印的页码位置在要素表单「双面页码」开关里配。单面/双面的页码规范不同，开关切一下。

## 稿件与版本

### 归档后还能改吗

**不能**。归档是唯一终态，正文与要素全部冻结。唯一还能改的是**盖章扫描 PDF 附件**的增删。想改内容，「基于此公文新建」另起一篇。

### 退回草稿会不会丢版本

**不会**。版本历史原样保留，随时可以再回退到别的版。退回草稿只是状态回到可编辑。

### 回退把当前改动覆盖了

版本切换时若当前有未提交改动，弹**三选**：丢弃当前 / 先提交再载入 / 取消。选「先提交再切换」是安全路径。已覆盖了就到版本历史里找回——版本都在。

### 找不到稿件了

1. 筛选条件清空重查（状态、文种、时间都可能筛掉了）；
2. 检查是不是归档了（归档不在「草稿」列表里）；
3. 看「新建」状态——历史遗留状态，一般不会有。

### 删除的稿件能恢复吗

**不能**。删除是硬删，没有回收站。不确定就先导出 ZIP 备份再删。

## 词表与输入法

### 涉密词进了码表怎么办

**拒绝**它。拒绝是永久的，重扫不再冒头。导出前扫一眼列表，敏感词（项目代号、人名、文号）都拒绝掉再导。

> **警告** 导出的码表是明文文件，导入输入法后**不再受本应用管控**。

### 码表重码太多，翻页很频繁

**重码太多**。看导出的**重码报告**，冲突对里删掉不常用的那条。另外：

- 二字词省 0 键默认不导出，别硬加；
- 条数上限是刻意的——编码空间有限，宁少勿滥。

### 新词的编码怎么定

不用自己算。正文选中后按 `Ctrl+Shift+A`（或右键「加入词表」），程序按基础表推算的构词规则
自动出码；多音字列出其他可能，点一下即换。手改的码不符规则时会提醒。

### 应用内输入法打不出词表里的词

词表里**已接受且为四码**的词才会进输入法。加词、接受、改读音、扫描完成之后几秒内会自动同步到输入法候选；还是打不出来就到「输入法词表」页右上角点「同步公文词表」手动补一次。

### 词表输入法没有候选

在「输入法词表 → 查码」输入编码，看该码的全部候选（含已屏蔽的）。确认词条没有被屏蔽、
对应的公文表已启用。公文词表中只有已接受且为四码的词会加载；缺词按 `Ctrl+Shift+A` 加入。

### 界面字太小/太大

界面字体在「设置 → 字体 → 界面字体」换本机字体。源码编辑器字号用 `Ctrl` + `+` / `-` / `0` 或 `Ctrl`+滚轮。

### 主题切了没生效

主题即点即换并保存。若没生效，看是不是只切了纸面明暗（那只是屏幕预览的纸色，不影响界面主题）。

### 屏幕预览和导出不一样

**正常**。纸面明暗只影响屏幕，导出一律白纸黑字红头。研究报告的数学公式预览与导出用同一个排版器，字形一致；含行内公式的段落预览里按左对齐显示，PDF 里仍两端对齐，**版式以导出为准**。

## 数据

### 卸载重装会丢数据吗

**不会**。数据在**用户配置目录**，不在安装目录。除非主动删配置目录。

### 换机器怎么搬

见 [数据、备份与迁移](chapter:21-data)。核心：源机导出 ZIP（含词库），目标机导入（勾合并词库）。

### 稿件 ZIP 的密码忘了

密码记在 `config_dir()/.zip-password`（若勾了记住）。忘了就**解不开**——密码保护是真加密。建议导出时记下密码。

## 启动与崩溃

### 一打开就闪退

程序崩溃时会把原因写进配置目录下的 `logs/`，文件名形如 `crash-20260923-101500-123.log`，里面有版本、系统、出错位置和调用栈。下次启动时状态栏会提示这份日志的路径（只提示一次）。

| 平台 | 日志目录 |
| --- | --- |
| Windows | `%APPDATA%\LocalTools\GongwenAssistant\config\logs\` |
| Linux | `~/.config/gongwenassistant/logs/` |

把最新那份日志发给维护者即可。Linux 上也可以在终端里运行 `gongwen-assistant`，出错信息会直接打在终端里。

日志只记得住程序自身的错误；显卡驱动内部的崩溃不会留下日志，这时请在终端里运行并把输出发来。
