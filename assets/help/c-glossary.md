## 术语表 {#chap:glossary}

### 文种

| 术语 | 含义 |
|---|---|
| 公函 | 平行行文（商洽、征求意见、告知、答复），有文号、有份号位 |
| 电话记录单 | 接听来电的记录表，含来电信息、首长批示空栏和人工拟办建议 |
| 电话通知 | 沿用函稿版式的简式通知，**无文号**、无版记 |
| 普通公文 | 无红头、无发文单位、无主送、无落款、无版记的纯正文公文 |
| 会议议程 | 会议时间地点、参会人员、议程安排 |
| 白头件（呈批件） | 内部情况报告、请示、领导呈批，无红头 |
| 红头呈批件 | 带红头、文号、首页批示栏的内部呈批件，承办条目上限 4 条 |
| 研究报告 | 按研究报告规范出 PDF 与 Word，含封面元数据、交叉引用、文献、数学公式 |

### 版面部位

| 术语 | 含义 |
|---|---|
| 版头 | 红头、发文单位、文号、密级标注所在部位（纸面上部） |
| 主体 | 主送、标题、正文（纸面中部） |
| 版记 | 抄送、承办、落款、成文日期（纸面下部） |
| 红头 | 发文单位名称 + 反线，公文的视觉标识 |
| 反线 | 红头下那条横线，分隔版头与主体 |
| 版记 | 版记区的分隔短线 |
| 份号 | 公文印制份数的顺序编号 |
| 机关代字 | 文号前缀，如「办函」 |
| 函号 | 机关代字〔年〕序号号，如「办函〔2026〕12 号」 |

### 要素字段

| 术语 | 含义 |
|---|---|
| 主送单位 | 主要受文对象 |
| 抄送单位 | 抄送对象 |
| 承办单位 | 具体承办部门 |
| 呈报领导 | 白头件、呈批件的呈报对象 |
| 落款单位 | 署名单位 |
| 成文日期 | 文件署名日期，中文数字写法（二〇二六年三月十五日） |
| 密级 | 不标注/内部/秘密/机密/绝密 |
| 保密期限 | 密级标注的期限，受密级规则上限约束 |
| 指人专办 | 特殊处理标注 |
| 行文方式 | 内部/外部；单独发文/联合发文 |
| 紧缩样式 | 正常/全局紧缩/节内紧缩，压行距的范围 |

### 写作与校对

| 术语 | 含义 |
|---|---|
| 审校稿 | 起草页中央的 Markdown 正文 |
| 审校提示 | 校验命中条目，分必错/疑似/提示三级 |
| 必错 | 确定性错误，可一键替换，签发前必须清零 |
| 疑似 | 可能有问题，人判断 |
| 提示 | 风格建议，可整组关掉 |
| 待核实占位 | `【待核实】`，拿不准处先占位，落实后销掉 |
| 存疑清零 | 所有待核实占位都落实，抽屉里那条提示消失 |
| 标准词库 | 单位与人员的唯一权威来源 |
| 校对词表 | 错误写法与建议写法的规则表 |
| 公文词表 | 从稿件收词、导出输入法码表的词库 |
| 省键数 | 词进用户码表比正常敲法省下的键数（`2n-4`） |

### 版本与痕迹

| 术语 | 含义 |
|---|---|
| 保存 | 写回稿件库当前内容（`Ctrl+S`） |
| 提交版本 | 固化成带名称与备注的快照 |
| 版本对照 | 任选两版比增删 |
| 花脸稿 | 送审用改稿痕迹版：删字画红色删除线、增字套蓝色方框 |
| 回退 | 把某版内容回到起草页，**不清历史** |
| 盖章扫描件 | 归档后唯一还能改的 PDF 附件 |
| 基于此公文新建 | 要素连同版式带过去，另起一篇 |
| 送批材料 | 随呈批件一起送批的独立稿件清单，可合并成一个 PDF |
| 随行件 | 送批材料里的一件（函稿、普通公文、研究报告等），不同于正文附件 |
| 钉版 | 呈批件归档时把各件固定在某一版，以后导出都用这一套 |

### 办文流程

| 术语 | 含义 |
|---|---|
| 六步办文 | 立稿→拟稿→核稿→送签→印发→归档 |
| 拟稿 | 六步之二：写正文（Markdown 源码） |
| 核稿 | 六步之三：处理审校提示、要素校验、待核实占位 |
| 表达复核 | AI 文字复核：小模型逐句查语病、称谓、标点 |
| 状态机 | 草稿→发布→归档，归档为唯一终态 |

### AI

| 术语 | 含义 |
|---|---|
| 三条红线 | 正文只经程序检查后改写 / 不碰要素 / 必过闸门 |
| 事实材料 | 当作本文事实依据的材料（数字、日期、单位、责任与要求） |
| 写法样稿 | 只学句式与语气的样稿，其中的事实不作本文依据 |
| 结构范文 | 只学章节组织的范文，其中的事实不作本文依据 |
| 来函 | 起草复函时据以识别来意与待答事项的原文 |
| 待决事项 | 正文里留下的 `【待核实】`，在侧栏顶上逐条处理 |
| `/` 技能 | 在侧栏输入框行首或空格后敲 `/`，光标处弹出技能列表，按名称、id、拼音首字母过滤 |
| `@` 引用 | 在侧栏输入框敲 `@`，从稿件库与知识库选一篇；默认当证据，仿写当基准稿、复函当来函 |
| 自主步骤 | 技能里的 `agent` 步骤：模型自己决定调哪些工具，程序执行、限次数、判定是否完成 |
| 风格档案 | 从样稿学来的写法与结构参考，只存本机，可导出给同事 |
| 输出契约 | 程序内置约束的模型输出形态，用户不可改 |
| 温度锁 0 | 小模型复核用 0 温度，同输入同输出 |
| 数据接口 | 技能可调用的内网查询接口，配置在配置目录 `apis/` 下的 OpenAPI 文件里 |
| 接口用例 | 一条典型用法加一组期望，跑一遍就是这个接口可用的证明 |
| AI 用例 | 一句用户可能的问法加期望的参数，用来证明模型挑对了接口、填对了参数 |
| 只查询，不改数据 | 接口「性质」里的勾选项；只有勾了的才给 AI 调与自动试调，会改数据的接口发送前要人工确认 |
| 两级访问 | 工具或接口太多时，模型先按关键词搜再调用，不是把清单全塞给它 |

### 应用锁

| 术语 | 含义 |
|---|---|
| 应用锁 | 启动密码 + 闲置自动锁定 + 全库加密的一整套保护 |
| 主密码 | 进入程序要输的那把密码；忘记无法恢复数据 |
| 诱饵系统 | 输第二密码进入的空白系统，界面相同、数据独立，磁盘上看不出区别 |
| 闲置自动锁定 | 没有任何键鼠输入超过设定时长就退回锁屏 |
| AI 写入前版本 | Pi 覆盖正文前自动提交的快照，用于找回与看差异 |

### 检索与知识

| 术语 | 含义 |
|---|---|
| 知识库 | 历史成稿与参考资料的可检索库 |
| RAG | 检索增强生成：向量检索 + 重排 + 全文兜底 |
| Embedding | 文本向量化模型 |
| Rerank | 精调排序：None / 专用端点 / 用对话大模型 |
| FTS5 | SQLite 全文索引，服务不可达时的降级路径 |
| 知识库问答 | 对话式检索，回答带引用标注 |

### 导出

| 术语 | 含义 |
|---|---|
| 文件名主干 | 导出文件名的前半段，由文类、机关代字与标题组成（盖章件再带〔年份〕序号与「盖章版」后缀），整名不超过 42 字符，超长时标题中间省略 |
| 源码包 | Markdown 正文 + 图片（研究报告另带 references.bib）的 ZIP，导入即可复现 |
| 孤行探针 | 排版后实测坐标找孤行，生成可点击提示 |
| 成品入口 | PDF / WORD / Typst 包图标，点一下即导出这一种并打开 |
| 同名文件 | 同一稿件使用固定输出目录，重复导出直接替换同名文件，不生成 `-2`、`-3` 副本 |

### 输入法

| 术语 | 含义 |
|---|---|
| 公文四码表 | 导入的编码与文字记录，使用四码 |
| 基础表 | 单字、词组、简码和四码的初始词表，可动态维护 |
| 重码 | 同一编码的多个候选词 |
| 词表输入法 | 按编码查询基础表与公文四码词表，顺序稳定 |
