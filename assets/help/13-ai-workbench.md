## 智能写作与技能 {#chap:ai-workbench}

### 一个写作入口

起草页功能区点「智能写作」，在右侧输入要求，按 **Ctrl+Enter** 或点圆形箭头发送。
先选中正文的一段再打开侧栏，可以锁定选区；本轮修改不能超出选区。运行中点停止按钮中断。

新任务统一由 Pi 执行。模型既可以按需直接成文，也可以分批提炼材料、形成提纲、逐节写作、合稿后交付。
无需按模型参数量选择另一套写作流程。模型地址与模型在「AI 管理」中的智能写作设置选择；
安装包包含运行依赖，安装时无需在线下载，但写作时必须能够访问所选本机或内网模型服务。

### 材料与用途

输入要求时可以粘贴材料；长文本会收成独立材料标签。输入 `@` 并从弹出列表选择稿件库或知识库文章，
选中的文章在发送时读取全文并保存本轮快照。单纯手打一个文章标题不能保证已经引用。

每份材料或引用分别选择用途：

| 用途 | 如何使用 |
| --- | --- |
| 事实材料 | 本次事项的数字、日期、单位、责任和要求依据 |
| 写法样稿 | 参考句式与语气，其中的事项和数字不能移入新稿 |
| 结构范文 | 参考章节组织，其中的事实不能移入新稿 |
| 来函 | 起草复函时据以识别来意和需要答复的事项 |

发送前检查每篇用途，避免把范文当成本次事实。材料标签上的关闭按钮只取消本轮引用，不删除原文章。
未发送的粘贴材料只在当前打开期间保留；已运行任务按工作区快照恢复，不受原材料后来改动影响。

### 技能、知识库与风格

输入 `/` 可选择已启用的标准技能，也可保持自动选择。内置技能覆盖起草、修改、审核、仿写、研究报告、
复函、提取和政策核对。自定义技能在技能管理中导入、启用或停用；任务开始时保存当次技能快照。

Pi 可按需检索知识库、读取稿件、查询标准词库和读取已启用的风格档案。知识库沿用本地已有配置，
不另建一份索引。长资料按范围读取；过程记录可帮助确认实际用过哪些资料。工具返回的出处是核对线索，
不是事实一定正确或政策仍适用的保证。

风格档案只提供表达与结构参考。Pi 的风格读取不会自动保存新档案，也不会把样稿里的事实作为本次依据。
这里的 `/` 用来选技能，不等同于 Pi 终端的全部命令；`/compact` 也不要求用户手动管理写作上下文。

### 自动安排写作步骤

默认「自动」，可选择「倾向分阶段」。程序结合实际窗口、材料和任务规模选择策略；
上下文以 token 计，不能直接换算成相同数量的汉字。窗口未知时会保守估计，并注明来源。

常规任务按需读材料、起草和检查。分阶段任务会显示材料提炼、提纲、分节与合稿的进度，
每步保存工作文件。阶段默认连续执行，只有关键信息或取舍确需用户决定时才提问。
小任务通常采用常规策略；分阶段会增加调用和耗时，不能保证每个模型都更快或写得更好。

「测试写作能力」会在后台用程序自造通知、临时 SQLite 知识库和稿件库，做两组同题自动 / 分阶段对照；
不会读取当前稿件或真实知识库，也不会写正文。结果按服务地址、模型、实际加载窗口、思考设置和技能版本匹配；
服务或窗口变化后旧结论不会套用。校准档案只存策略摘要，合成输入、模型成品和机器判据单独保存在本机 Pi 校准证据目录，
可按摘要中的哈希核对。短测试不能证明长上下文工作预算，人工质量评价也不会被程序自动标成通过。

### 完成、撤销与恢复

生成或修改任务必须明确提交一份完整 Markdown。程序检查后直接写入正文，保留修改前后文本，
可用 **Ctrl+Z** 或结果卡的「撤销本次写入」整次撤回。事实来源疑点只作提示，不需要勾选事实后才能写入。
表单中的密级、文号、份号、签发人等授权要素仍由用户填写，AI 不得改写。

运行期间用户改过正文、稿件变成只读或无法保存撤销记录时，成品保留，程序不会自动覆盖正文。
审核、提取或找资料可以只交侧栏清单，不改正文。

停止或程序中断后，可从任务卡继续。分阶段会核对已登记文件及依赖，成果被改动时相关后续步骤须重新执行，
不能把半稿当成品提交。版本不兼容或输入身份不一致时会说明原因；原文件和历史记录继续保留。

### 旧任务历史

旧六步写作和旧技能任务属于历史兼容记录。查看或导出已有成果后，可将要求、材料和适用成果显式复制到
新的 Pi 任务；旧检查点不会转换成 Pi 检查点，旧选区也不会套用到当前正文。
历史中的待接受提案仍按其原有权限处理，不代表新任务恢复为人工确认后写入的流程。
