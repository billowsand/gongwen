## 全局快捷键

| 快捷键 | 功能 | 备注 |
|---|---|---|
| `Ctrl+S` / `⌘S` | 保存 | 写回稿件库 |
| `Ctrl+N` / `⌘N` | 新建空白文档 | |
| `Ctrl+K` / `⌘K` | 快捷查找 | 稿件、单位人员、常用页面；↑↓ 选择、Enter 打开、Esc 关闭 |
| `Ctrl+W` / `⌘W` | 关闭标签 | 未保存先确认 |
| `Ctrl+Tab` | 下一个标签 | macOS 保留 Ctrl（⌘+Tab 给系统切应用） |
| `Ctrl+Shift+Tab` | 上一个标签 | |
| `Ctrl+1..9` | 直达第 N 个标签 | `9` 固定指最后一个 |
| `F1` | 打开使用帮助 | |

## 快捷查找

- 顶部「快捷查找」按钮与 `Ctrl+K` / `⌘K` 使用同一入口。
- 打开时只显示搜索框并自动聚焦；输入后向下展开结果，清空后收起。可按 Esc、点击框内 Esc 或点击浮层外关闭。
- 输入标题中的几个字、拼音、首字母或文号，点击结果即可打开；单位人员打开标准词库对应条目。
- 已打开的稿件使用当前工作稿标题，不重复列出；归档稿打开只读详情。
- 拼音与首字母请用英文输入，应用内输入法可按 Shift 切换。最多显示前 50 项，可继续输入缩小范围。

## 编辑器

| 快捷键 | 功能 |
|---|---|
| `Ctrl+B` / `⌘B` | 加粗（焦点在正文编辑框时） |
| `Ctrl+F` / `⌘F` | 查找替换 |
| `Ctrl+Shift+H` / `⌘⇧H` | 标题聚焦编辑（Markdown 与 Markdown 对照模式） |
| `Ctrl+Shift+X` / `⌘⇧X` | 把正文选区移入候选区（焦点在正文编辑框时） |
| `Ctrl+Shift+A` / `⌘⇧A` | 造词：把选区或最近用输入法上屏的字加入词表，自动出码 |
| `Ctrl+Delete` | 输入法组码时屏蔽高亮候选 |
| `Ctrl+Enter` / `⌘↩` | 候选区：把右栏选中的部分插回正文光标处；AI 侧栏输入框：发送 |
| `/` · `@` | AI 侧栏输入框：弹出技能列表 · 弹出文章列表；`↑` `↓` 选，`Enter` / `Tab` 确认，`Esc` 关闭 |
| `Enter` / `Shift+Enter` | 查找下一个 / 上一个 |
| `Ctrl` + `+` | 源码编辑器字号放大 |
| `Ctrl` + `-` | 源码编辑器字号缩小 |
| `Ctrl` + `0` | 源码编辑器字号复位 |
| `Ctrl` + 滚轮 | 源码编辑器字号 |
| `Esc` | 关闭查找条 / 审校抽屉 / 确认框 |

## 说明

- `Ctrl` / `⌘` 按平台自动切换（Windows / Linux 用 Ctrl，macOS 用 ⌘）。
- 快捷键要在各文本框处理输入**前**消费，避免保存/查找被当前聚焦的编辑控件吞掉。
- `Ctrl+B` 必须确认焦点在**审校稿编辑框**上，避免焦点在要素表单或查找框时改到正文。
- 其余操作（导出、提交版本、AI 起草等）走功能区按钮，未设全局快捷键——避免与输入法、系统快捷键冲突。
