# 词表资源

本项目的初始基础词表是 `quan.txt`，记录格式为 `编码,位置=文字`。
程序只查询编码，不区分任何拼音方案；基础表支持 1–4 码，公文词表使用四码。
打包脚本把该文件复制为 `runtime/ime/base.txt`，Windows 安装包、Linux ARM64 deb
与 macOS 应用包统一随包携带，用户装完即可直接启用内置输入法。
首次载入复制到用户目录，之后动态维护 `ime/base.txt`，不会被重新安装覆盖。
词表不编进二进制，可随时更新后随新版本发布。

  术语与成语典故保留。口径与统计见 `docs/table-ime.md`。
- 2026-10-24 第二轮清理：用本机 LM Studio 的 `qwen/qwen3-4b-2507` 对 40,970 个
  多字词逐个判「收不收录」，模型判删 6,800 个，人工复核救回 1,208 个，最终删
  5,798 个词（单字 205 个为表情符号与带声调拼音字母，多字 5,589 个，另 4 条
  `#$` 日期时间模板），全表 57,874 → 51,269 条。删的是日常动作短语、程度副词组合、

- 维护约定：只收公文可用词，不收口语、方言、网络语、表情符号与亲属口头称谓；
  新增或删改后跑 `cargo test --locked ime:: -- --ignored`（真实词表往返、
  四码首选命中率、全表体检）与 `cargo fmt --all -- --check`。

## quan/：五个分表（改词表改这里）

`quan.txt` 由 `assets/fuma/quan/` 下五个按字数分表的文件合并生成，改词表请改分表：

| 文件 | 内容 |
| --- | --- |
| `quan/danzi.txt` | 单字（1 字） |
| `quan/shuangzi.txt` | 双字（2 字） |
| `quan/sanzi.txt` | 三字（3 字） |
| `quan/sizi.txt` | 四字（4 字） |
| `quan/siziyishang.txt` | 四字以上（5 字及以上） |

五个文件都是 UTF-8 + LF，行格式与 `quan.txt` 相同（`编码,位置=文字`），位置沿用原值
不重编号；字数必须与分表对上，跨表的同 `(编码,文字)` 不允许重复。改完在仓库根目录跑：

```bash
python scripts/merge-ime-tables.py           # 合并回 quan.txt（UTF-16 LE + BOM + CRLF）
python scripts/merge-ime-tables.py --check   # 只比对现有 quan.txt 是否与分表一致
```

`quan.txt` 仍是唯一随包运行时文件，打包脚本与加载器都只认它。`assets/fuma/danzi.txt`
是已下线的旧辅码单字资源，与这里的 `quan/danzi.txt` 不是同一个文件。
