# 词表资源

本机初始基础词表支持 `quan.txt` 与 `mabiao.txt`，记录格式为 `编码,位置=文字`。
Windows / Linux 优先 `quan.txt`，macOS 优先 `mabiao.txt`，缺少首选时使用另一份。
程序只查询编码，不区分任何拼音方案；基础表支持 1–4 码，公文词表使用四码。
打包脚本存在该文件时复制为 `runtime/ime/base.txt`。
首次载入复制到用户目录，之后动态维护 `ime/base.txt`，不会被重新安装覆盖。
不再使用 `danzi.txt`、`xiaohe.txt` 等辅码资源，也不再把词表编进二进制。

## 入库范围与授权

- `quan.txt` 自 2026-10-24 起纳入版本管理：删除了聊天应答、方言、亲属称谓、
  拟声象声、网络俚语与表情符号等口语词条，单字表与公文用语保留（口径见
  `docs/table-ime.md`）。改动直接提交本文件，删除清单见 `docs/table-ime.md`。
- `mabiao.txt`、`danzi.txt` 仍不入库：权利归方案作者、只限私人使用，只能由
  使用者自行导入本机。
- 词表来源 flypy.cc。码表权利归原作者，再分发范围以原作者授权为准；仓库
  保留来源与清理说明，便于追溯与撤回。
