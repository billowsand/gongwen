# 更新规则

## 什么时候值得改

- 资料库新入了与页面主题直接相关的文档（新文件、新通知、新数据）；
- 页面引用的口径已被新资料取代（旧数字、旧提法、旧机构名）；
- 维基里新建了相关页面，旧页正文可以补上 `[[链接]]`；
- 用户明确说要改什么。

无关的新资料不要为了改而改；`change_note` 里说不清依据的改动不要交。

## 改写姿势

1. **保留页面骨架**：标题层级、条目顺序、导览页/条目页分工尽量不动；
   新内容并进相应段落，不把页面推倒重写。
2. **口径以新资料为准**：与旧正文冲突时按新资料改，冲突点在
   `change_note` 里点名（「按 E12 改为××口径」）。
3. **链接维护**：正文里的 `[[页面名]]` 保持有效；新出现的相关概念，
   已有页就补链，没有页就写成待建红链。
4. **依据清单随版本走**：本版实际参考的文档都进 `doc_refs`，
   旧版本依据不再成立的可以撤下。

## 审核台会发生什么

程序先复核：UUID 对应页面存在、标题未改、类型未改、正文非空且有变化、
依据文档真实。复核过进审核台：用户看到旧正文与新正文的逐行 diff，
可直接改；点「采纳」才写库（产生新版本，`review_edited` 记录是否人工改过）。
