# 拆题与成页口径

## 一页一个主题

- 一页讲透一个工作主题：是什么、依据什么、怎么干、注意什么。资料里多个文档
  讲同一件事的，合并成一页，不要按文档拆页。
- 页面是**综述**不是摘抄：按事理组织行文，资料原文只作依据；
  不要整段复制材料，也不要写成「文档3说……文档7说……」的台账体。
- 跨主题的内容写 `[[链接]]` 指向相关页，本页只保留一两句引子。

## 导览页

- 每个分类一篇导览页（`kind: "guide"`）：一段综述本分类管什么、依据哪些资料，
  然后逐个链向本分类的其它页面（`[[页面名]]`）。
- 导览页也受同样的审核：内容同样只能来自资料。

## 链接用法

- 已有页面：先用 `wiki_search` 查准确标题再链；改名跟随由程序保证，照标题写即可。
- 待建概念：资料里出现、维基还没有的，写 `[[概念名]]` 红链即可，程序会登记为缺口，
  不要给不存在的页面编造内容。
- 框架节点（主题/分类）也可以链：`[[分类名]]` 会指向该分类的导览页。

## 依据清单

- 每页至少一篇依据文档；`note` 写「这文档支撑了本页哪个要点」，一两句话。
- 没有直接支撑的资料不要塞进 `doc_refs`；用户审核时逐条对照，错配会被退回。
