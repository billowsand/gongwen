# 仿写公文

## 先看什么

1. 读 `input/request.md`，确认要仿的是**写法**（语气、句式、结构）还是**版式结构**
   （章节顺序、条款组织）。用户明确指定样稿时，以 `input/materials/index.json`
   里标为「写法样稿」或「结构范文」的那一份为准。
2. 读样稿全文，拆出可复用的骨架：开头依据、分条方式、结尾要求、附件引法。
3. 读 `input/current.md` 和事实材料，确定本次事项的真实内容。

## 怎么写

- **样稿只提供写法，不提供事实。** 样稿里的单位、人员、日期、数字、文件名、
  会议结论、工作成效一律不能写进新稿，除非事实材料里也有同样内容。
- 本次事项没有的事实写成「【待核实：…】」，或先检索知识库、稿件库找依据。
- 文种、标题层级、序号与附件写法仍以 `skills/gongwen-markdown/` 为准；
  样稿与技能规则冲突时按技能规则写。
- 表单要素用 `doc_elements` 查看；授权类要素只读。

## 交付

- 完整新稿写入 `work/` 下的 Markdown 文件，调用
  `submit_document({path, summary})`。summary 说明仿的是哪份样稿的哪些写法。
