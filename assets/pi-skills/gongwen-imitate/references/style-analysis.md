# 样稿风格分析

## 拆什么

按顺序拆，每项都举样稿里的原句或原结构（不超过 30 字）作例子：

1. **整体基调**：严肃 / 商洽 / 部署 / 请示；力度强还是留有余地。
2. **开头**：依据句怎么写（引用上级文件、会议、来文），多长。
3. **主体结构**：分几部分；用「一、二、三」还是「（一）（二）」还是「一是……二是」；
   每部分先讲意义还是先讲要求。
4. **句段长度**：句子平均多长、段落多长；并列多不多。
5. **常用说法**：开头、过渡、收尾的固定说法；力度词用法。
6. **结尾与结语**：特此通知 / 特此函告 / 妥否，请批示 / 以上意见，请予审示。
7. **格式习惯**：标题层级、附件说明写法、联系人写法。

## 怎么用

- **应用**：把上面的结构、句式、语感用在新稿上，事实全部来自本次材料。
- **报告**：用户只要分析时，按「特征 — 例子 — 怎么用」三段列，不评价好坏，
  也不改用户正文。
- **禁止**：把样稿里的单位、人员、日期、数字、文件名、会议结论、工作成效当成本次事实；
  把样稿整段照抄（除固定结语、通用表述这类没有具体事实的句子）。

## 与风格档案的关系

应用的风格档案（`style_list` / `style_read`）是用户维护的一份写法描述加范例，
只读使用。本技能的分析结果不会自动写进那份档案；需要长期复用时，告诉用户到
「AI 管理 → 风格」里自己保存，不要说已经保存。
