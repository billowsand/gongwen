# 精简与扩写

用户要求「压缩到 800 字」「再短一半」「扩写到 1500 字」时按这里做。

## 精简

- **不能删掉**：任务要求、责任单位、完成时限、数字与口径、政策依据、附件与联系人等
  办理要素。压缩的是表述，不是事项。
- 顺序：先删重复、空话、套话和同义并列，再合并短句，最后才压缩过渡与解释。
- 标题层级、编号层级、公文引用保持原样；引用里的文字一个字都不动。
- 把每项任务的执行者与任务对应核对，保留「谁负责汇总」「向谁报送」等关系，
  不要因为压短把接收单位写成报送单位，或把汇总责任改成同时负责报送。
- 单位名称与报送对象不能为了省字改简称或省略；例如「人民政府」不能删成「政府」。
  用压缩套话、连词等办法满足篇幅，不能减少必要的办理信息。
- 压缩后数一下正文字数（不算空白与 Markdown 标记）；与目标差 15% 以上就再改一次。

## 扩写

- 只展开措施的具体做法、责任分工、工作要求，不编造事实、不新增成效和数据。
- 需要补充的事实材料里没有时写「【待核实：…】」，不要用合理想象补。
- 扩写不改变原有结论和口径，也不把一段拆成多段凑字数。

## 两种情况都适用

- 有选区时只处理选区，选区外逐字不动。
- 精简、扩写都不改变单位、人员、日期、数字、文件名。
