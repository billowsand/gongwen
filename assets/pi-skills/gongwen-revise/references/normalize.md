# 规范化

用户要求「全文规范一下」「统一数字用法」「单位用全称」时按这里做。

## 规范什么

1. **标点**：中文全角标点；引号、书名号、括号成对；顿号与逗号不混用；
   句子之间不用空格代替标点。
2. **数字**：公历年月日、计量与统计数字用阿拉伯数字；约数、成语、序数词按惯例用汉字；
   同一篇里同一类数字的写法统一。
3. **用语**：去口语和网络用语，不用生造简称；同一对象前后称呼一致。
4. **单位与人员名称**：需要确认标准写法时用 `vocab_search` 查词库。**词库只给写法，
   不给事实**：不要因为词库里有个单位就把它写进正文，也不要改变单位口径
   （把「市应急管理局」改成别的单位、把处室改成单位）。

## 不改什么

- 事实、数据、时间、责任分工与结论；
- 公文引用里的原文（书名号内、引号内的引文按原文，不按规范改）；
- 授权类要素的值。

## 交付

规范化是修改正文，最终交完整 Markdown，不交「改了哪些字」的清单。
