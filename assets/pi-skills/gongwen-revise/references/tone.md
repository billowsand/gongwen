# 语气与行文方向

用户要求「改成上行文语气」「对下级再明确些」「太生硬了」时按这里做。

## 三种方向

- **上行文（请示、报告）**：谦恭得体，不用命令口吻。请示结语「妥否，请批示」；
  报告结语「特此报告」，报告里不请求批示，也不给上级派任务。
- **平行文（函）**：商洽有礼，用「请予支持为荷」「特此函告」「请予函复」一类结语；
  不写「要求贵单位」。
- **下行文（通知、意见）**：明确有力，用「要」「务必」「切实」，要求写清做到什么程度、
  什么时候完成、谁负责。

## 边界

- 只改语气和措辞，不增删事项；时间、数字、单位、人员、文件依据一律不动。
- 语气不靠加感叹号、加形容词实现；力度来自责任和时限写得清楚。
- 当前文种决定方向：拿不准文种时先看 `input/request.md` 和表单里的文种，不要自己换文种。
