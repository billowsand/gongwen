# 政策依据核对

流程：认出正文里引用的政策文件（书名号里以法、条例、规定、办法、意见、通知、方案等结尾的）→ 按标题到
知识库找原文（步骤里写了 `apis:` 的也查数据接口）→ 比对名称、文号、引文。

- 名称只差几个字、文号与原文不同、文号年份没用六角括号〔〕：程序比，给出改法，进审校抽屉逐条采纳；
- 引号里的话在原文里逐字找得到就算一致；找不到时把原文里最接近的一段交模型判，不一致的报出原文表述，
  只提示，不替你改引文；
- 知识库里没有原文的报「未找到原文」，请人工核对。

## 表述比对

公文里引用了《{title}》的一句话，判断它是不是原文的意思与表述。

【引文】
{quote}

【原文里最接近的一段】
{passage}

只输出一行：
- 引文与原文说的是同一件事、关键用语一致（标点、个别虚词不同也算），输出：一致
- 否则输出：不一致｜原文里对应的原话
