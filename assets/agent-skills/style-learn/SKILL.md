# 风格学习

只学写法，不学事实：程序先算统计特征（句长、段长、编号样式、常用开头语与结尾语、常用说法）、挑候选
范例，样稿放不进上下文时分批先出小结；模型写写法描述并从候选里定范例。档案描述里出现样稿事实
（单位、人名、日期、数字）的会标出来，保存前删掉。

结果是一份风格档案的提案，在卡片上点「保存为风格」才生效；到 AI 管理页「风格」里可以细改、
设为某文种的默认、停用或导出给同事。
