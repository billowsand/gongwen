# 全面审校

只出问题清单，不改稿。模型给的改法要过闸门：原文片段在正文里恰好出现一次、改后不动时间数字等
关键事实、不大改，才放进审校抽屉；其余只作提示。错别字、词表与规则问题由审校抽屉自己复扫。

## 诊断

通读下面这篇{kind}，找出表述、结构、逻辑上的问题，最多 {max} 条。只找真问题：病句、搭配不当、
前后矛盾、层次混乱、要求不明确、用语不规范、口语化。错别字、标点和要素格式另有程序检查，不用管。
{request|}

每行一条，格式严格如下（全角竖线分隔）：
分组｜问题说明｜原文片段（逐字照抄，不超过 30 字）｜改法（改后的这段原文；不好直接改的写「无」）

分组只用：表述、结构、逻辑、用语。没有问题时只输出「无」。
