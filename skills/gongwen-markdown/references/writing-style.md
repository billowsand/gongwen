# 行文规范：让正文像公文

格式对了只是能排版；这一篇解决“像不像公文”。条文来自对大量真实公文的统计，挑的是
模型初稿最常偏离的地方。风格偏好不是普遍规范；公文助手的词频提示默认关闭，按模板选用。
事实、要素与文种检查仍运行。会议议程有专用模板，研究报告、电话记录也有各自的写法。

## 1. 事实红线

- 只写用户给的事实。**不得编造**文件号、领导批示、机构名称、人名、日期、数据、联系方式、
  引文原文、上级文件表述。
- 用户提供的单位名称、人名、职务原样照抄，不自作主张改简称。
- 拿不准就占位：`【待核实：具体事项】`；需要示意量级写 `【待核实：示意约××，须核实替换】`；
  引文拿不准写 `【待核实：核对原文】`。宁可占位，绝不杜撰。
- 不掌握真实数据就不写数据，靠事项和逻辑撑起段落。

## 2. 日期与时间

- 自写日程和期限里的相对日期（今天、明天、下周三）宜明确为绝对日期，写成“2026年8月20日（星期四）”。
  电话原话、直接引文与历史材料保留原有语境；按材料基准日期核对，不直接按导出当天换算。无法确定基准日期时写
  `【待核实：日期】`。
- “本周”指星期一至星期日；“下周”指紧接着的下一个星期一至星期日。
- 时间用 24 小时制：“14:30”，不写“下午14:30”“下午2点半”。
- 用户给的公历日期与星期冲突时，不擅自取舍，写 `【待核实：日期与星期不一致】`。
- 年份写全，不写“26年”；数字用阿拉伯数字。

## 3. 句子与标点

1. **句子靠并列成分撑起来**。一句话里把依据、事项、责任、成效挂在一起，用顿号枚举
   平行成分，不要拆成一连串二十字以内的短句。

   > 短句版：任务分到村、组、户。攻坚期间清运陈年垃圾若干吨。
   >
   > 公文版：逐村逐巷划片包干，镇干部包村、村干部包组、党员包户，攻坚期间集中清运
   > 陈年垃圾【待核实：吨数】吨，确保主干道、背街小巷和河塘沿岸同步过关。

   反过来，任务分解类段落一句里并列不超过三层，别把工作写成器材清单。
2. **标点按表达关系使用**。冒号可提示下文、列举或总结上文，破折号可解释或表示转折。
   不设全篇数量上限，不把正确的冒号机械改成逗号。
3. 不写“其实是”“说到底”“归根到底”这类元评论，直接说结论。
4. 全角标点：“”‘’（）《》、，；：。？！……——。不混用半角引号和括号
   （英文缩写外的括号一律全角）。

## 4. 力度词与行文方向

力度词由权力关系决定，不由礼貌决定：

| 行文方向 | 典型文种 | 用词 |
|---|---|---|
| 上行 | 请示、报告（白头件、红头呈批件仅为版式） | 对上级用“建议”“请”“恳请”；请示用请求性结语，报告按报告收束 |
| 下行 | 电话通知、通知、批复 | 对下级用“要”“切实”“确保”；对不隶属的对象改用“希望”“请”；结尾交代谁督促落实、有问题向谁反映 |
| 平行 | 公函 | 一律“请贵单位”“希望”“请予支持”，不用“要求”“责成”“务必”“严禁” |
| 不明 | 普通公文、研究报告 | 按对象选，对象不明时宁弱勿强 |

“必须”“应当”“不得”“严禁”按职责、条款和行文对象使用，不设全篇配额；保留必要的
强制要求。语料偏好不能代替制度、通知、研究材料各自的用途。

## 5. 开头与结尾

- 开头不以“高度重视”起句，不堆“根据……，为……”式套语，第一句就进入事由。
- 结尾收在最后一条事项或规范结语上，不写“以上”“综上所述”“总之”做总结升华。
- 结语示例：公函“特此函告/函复/函商”，审批函可请求批准；通知“特此通知”；请示可用
  “妥否，请批示。”“妥否，请指示。”或“特此请示。”，报告不附加请示结语。

## 6. 成绩与问题

- 成绩写“在……领导（支持）下”，不自我归功。
- 问题归客观条件，或加“个别”“部分”限定；“根本原因”落在思想认识上。
- 摆问题要带单位、行为和数字，不用无主语的四字排比撑段落。

## 7. 称谓与名称

- 第一次出现用全称，需要简称时写“（以下简称“××”）”，此后统一用简称。
- 平行文称对方“贵单位”“贵局”，自称“我单位”“我局”，不用“你们”“我们”。
- 领导姓名、职务照用户提供的写，不补不改。
